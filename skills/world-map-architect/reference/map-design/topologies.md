# 맵 위상(topology) 카탈로그 — 스테이지를 잇는 8가지 진행 구조

> [`world-map-architect`](../../SKILL.md) 워크플로 **2) 이론 적용**에서 *어떤 모양의 여정*인지 고르는 처방전.
> 각 위상은 공통 원칙([principles.md](./principles.md)의 `MAP-*`)을 *특정 진행 모양으로 구체화*한 것이다.
> 위상은 단독보다 **조합**한다(예: 선형 베이스 + 가벼운 분기 + 무한 모드 별도). 구현은 [build-patterns.md](./build-patterns.md).

각 아키타입 = **정의 · 언제 쓰나 · 게이팅 · 내비 · 거시 페이싱 · 영속 한 줄 · 사례(기법만) · 모바일 적합도 · 적용 MAP-***.

---

## 0. 위상 선택 결정표

먼저 게임 유형·세션·리플레이 목표로 1차 후보를 좁힌다.

| 게임/세션/목표 | 1순위 위상 | 보완 조합 |
|---|---|---|
| 캐주얼 퍼즐·매치3, 학습 곡선 통제, 누적 진행 | **선형 체인 / 사가맵**(§1·§2) | + 별 그리드(§3) + 데일리(§8) |
| '컬렉션·완성주의' 재방문(별 3개 채우기) | **에피소드 그리드**(§3) | + 별 게이트 보너스 |
| 매 판 다른 전략·선택의 미학, 높은 리플레이 | **분기 노드맵(로그라이크)**(§4) | + 시드/메타 해금(§8) |
| 테마 변주·서사·마일스톤 보스가 있는 캠페인 | **액트/챕터 월드맵**(§5) | + 선형 내부 + 별 게이트 |
| 탐색·소속감·비선형 자유, 진척=공간 변화 | **허브앤스포크**(§6) | ⚠️ 모바일은 정적 2D 허브로 축소 |
| 상호연결 탐험·능력 게이팅·백트래킹 | **개방형/루프(메트로배니아)**(§7) | ⚠️ 모바일은 노드맵 하이브리드로 |
| 무한 콘텐츠·짧은 세션·점수 자기경신 | **무한/엔드리스/절차**(§8) | + 데일리 + 메타 해금 |

> **모바일 웹뷰 기본값:** 잘 모르겠으면 **'선형/사가 베이스 + 가벼운 분기 + 무한·데일리 모드 별도'**. 초반은 선형으로
> 핵심 메카닉을 강제 학습시키고(이탈 방지), 중반부터 분기/액트로 주도성을 연다. 풀 허브·메트로배니아는 작은 화면·짧은
> 세션에서 비싸고 길 잃기 쉬우므로 노드맵/정적 허브로 축소한다.

## 1. 선형 체인 + World-Stage 넘버링 (MAP-LINEAR)

- **정의:** 스테이지를 정해진 한 줄로 줄세워 'N-M'(예: 1-3, 2-4) 2단 좌표로 묶는 가장 단순한 위상. 각 노드는 직전 클리어로
  열리고 플레이어는 '다음 한 칸'만 본다. 진행이 단조 증가 1차원 좌표로 완전히 표현된다.
- **언제 쓰나:** 캐주얼 온보딩, 학습 곡선을 정밀 통제하고 싶을 때, 디자이너 통제력(저작권)이 최대로 필요할 때. 누적 영속 진행.
- **게이팅:** 직전 클리어 = 다음 해금(소프트). localStorage 1차원 정수 1개. 그래프 자료구조 불필요.
- **내비:** '이어하기' 단일 CTA + 'W-S' 칩으로 '내가 어디쯤'을 즉시. 분기·허브 없이 항상 '다음 1칸'만 강조.
- **거시 페이싱:** 곡선이 곧 절대 권력 — `MAP-MACRO` 톱니·`MAP-REST`·`MAP-BOSS`를 엄격 검증(우회 없어 벽 1개=이탈).
  월드 경계에서 살짝 낮춰 '리셋된 자신감'으로 새 메카닉을 받게.
- **영속 한 줄:** `progress: <int>`(도달 인덱스). 가장 가벼움.
- **사례(기법만):** Super Mario Bros.(1985)의 8월드×4스테이지, World 1-1이 텍스트 없이 가르치는 온보딩(구조·기법만, 레이아웃
  복제 금지) — 1차 디자인=Miyamoto/1985, 'learning through play' 정전화=비평가(Jeremy Parish 등).
- **모바일 적합도:** ✅✅ 1차원 정수 1개만 저장하면 서버 없이 완벽. 한손·작은화면에 이상적. 절차생성과도 궁합(seed=월드, index=난이도).
- **적용 MAP-*:** `MAP-MACRO` · `MAP-REST` · `MAP-BOSS` · `MAP-GATE`(소프트) · `MAP-PROGRESS` · `MAP-PERSIST`.

## 2. 사행 경로 사가맵 (MAP-SAGA)

- **정의:** 선형 시퀀스를 직선 리스트가 아니라 화면을 구불구불 휘감는 '뱀(snake) 길'로 시각화한 레벨 선택 맵. 위상적으로
  100% 선형이지만 보드게임 말판 같은 '여정' 메타포로 진행감·정서 보상을 키운다.
- **언제 쓰나:** 선형인데 진행감·소속감을 더 주고 싶을 때, 캐주얼 퍼즐의 누적 진행을 '여정'으로 보이고 싶을 때.
- **게이팅:** 선형과 동일(직전 클리어). 곡선 경로는 **순수 표현 레이어**로 분리(좌표 배열/절차 곡선).
- **내비:** 현재 노드를 화면 중앙 근처로 오토스크롤, 클리어/잠금/현재를 3색+형태로 구분. 지나온 길은 '채워진' 상태로 남겨 누적 성취 표시.
- **거시 페이싱:** `MAP-MACRO`(난이도 리듬·pinch 레벨) + `MAP-PROGRESS`(목표 구배). **단 '실패해도 다시 하면 된다'는
  코어에서만** — 순수 실력 게임이면 막힘 노드가 좌절 벽(Woodbury 경고, `MAP-STAR` 참조).
- **영속 한 줄:** `progress: <int>` + per-node `stars`. 곡선은 무저장(표현).
- **사례(기법만):** Candy Crush Saga(2012)의 세로 굽이치는 길 위 레벨 점·아바타 전진(구조만; 고유 레이아웃·아트 복제 금지) —
  '보드게임처럼 보이는 saga map' 아이디어는 Sebastian Knutsson(2011경), 작동 원리(difficulty rhythm) 해설은 Dylan Woodbury.
- **모바일 적합도:** ✅✅ 세로 사행 + 오토스크롤 + 큰 탭 타깃이 한손 엄지에 최적. 곡선은 절차적(베지어/사인)으로 그려 CC0 의존↓.
- **적용 MAP-*:** `MAP-LINEAR` 기반 + `MAP-PROGRESS` · `MAP-NAV` · `MAP-MACRO` · `MAP-A11Y`.

## 3. 에피소드 그리드 레벨 선택 (MAP-GRID)

- **정의:** '에피소드(상위 탭) → 레벨(그리드 셀)' 2계층으로 나눠 격자/리스트로 펼쳐 보여주는 선택 화면. 셀마다 잠금/완료 +
  별점(0~3) 배지. '여정 메타포'보다 '한눈에 펼쳐 보기·되돌아가 다시 하기'를 우선한다.
- **언제 쓰나:** 재방문(replay)·완성 욕구(별 3개 채우기)를 강하게 자극하고 싶을 때. 컬렉션/체크리스트형 진행.
- **게이팅:** **진행 게이트(클리어=1성)와 점수 게이트(별)를 분리** — 진행은 클리어만, 별은 도전 과제. 에피소드 단위 메타
  보상(전 레벨 3별 → 보너스).
- **내비:** 큰 정사각 타깃(엄지 44px+), 셀 안엔 번호+별+자물쇠만(정보 과밀 금지). 에피소드 탭으로 한 화면 ~15셀 이내.
- **거시 페이싱:** 그리드는 '여정'이 아니라 '컬렉션'이라 곡선 강제력이 약함 — 별 임계로 숙련 곡선을 분기(`MAP-STAR`).
- **영속 한 줄:** `stars: { 'e1l3': 2, ... }`(노드별 0~3) + 에피소드 메타.
- **사례(기법만):** Angry Birds(2009)의 에피소드 그리드·레벨당 1~3별·전 레벨 3별 시 Golden Egg(구조만). 콘솔 'Stage Select' 계보.
- **모바일 적합도:** ✅ 에피소드 탭 + 격자 셀이 페이지네이션에 잘 맞음. 자유 재진입이 짧은 세션 '한 판 더 별 노리기'를 만듦.
- **적용 MAP-*:** `MAP-STAR` · `MAP-PROGRESS` · `MAP-A11Y` · `MAP-GATE`(진행≠숙련).

## 4. 분기 노드맵 (로그라이크) (MAP-DAG)

- **정의:** 한 런(run)의 진행 전체를 '아래→위로 흐르는 방향성 비순환 그래프(DAG)'로 모델링한다. 각 층(floor)에 노드가
  흩어지고 인접 층으로만 단방향 연결, 되돌아가기 불가. 한 번의 절차생성으로 만들어진 그래프가 그 런의 '맵' 전체 —
  런마다 새로 태어났다 사라지는 일회용 위상이다.
- **언제 쓰나:** 매 판 다른 전략·'선택의 미학', 높은 리플레이성, 위험-보상 라우팅이 핵심일 때. 런 기반(`MAP-RUN`).
- **게이팅:** act 끝마다 모든 경로가 단일 보스로 수렴(분기-병목 다이아몬드, Ashwell 2015), 보스 격파 시 다음 act 새 생성.
  보스 직전 층은 '준비 노드'(휴식)로 통일.
- **내비:** 세로 스크롤로 층을 위로 따라감(모바일 정합). 탭 가능 노드는 다음 층 인접 2~4개로 제한. 노드 타입은 색·아이콘
  픽토그램(텍스트 라벨 없이). 맵 전체(또는 앞 N층) 사전 공개로 경로 계획(`MAP-AGENCY` 입력 무작위성).
- **거시 페이싱:** 노드 타입 다양성(전투/엘리트/상점/이벤트/휴식/보물)이 위험-보상 축(`MAP-BRANCH`). 전진 압박(추격자/소모
  자원/되돌아가기 금지)으로 '전부 먹기' 차단해 매 갈림길에 기회비용(`MAP-MACRO`).
- **영속 한 줄:** `seed` + 진행 포인터(현재 층·노드·HP·자원). **맵 무저장**(시드로 재현, `MAP-SEED`).
- **사례(기법만):** Slay the Spire의 7×15 비정형 격자 DAG(경로 비교차·유일 도착지·도달불가 노드 제거) — 이 맵 규칙·확률은
  게임 바이너리(Mega Crit)를 역설계한 커뮤니티 자산[Steam 가이드, GitHub sts_map_oracle]이 1차 근거(공식 GDC 2019
  강연은 밸런스 주제). FTL(Subset, 2012)의 섹터 비콘 그래프 + 출구 비콘 병목 + Rebel Fleet 추격.
- **모바일 적합도:** ✅✅ 추상 노드맵은 타일맵 렌더 부담 0, 작은 화면·한손 탭에 자연스러움. 시드 1개만 저장하면 런 복원.
  단 모바일은 분기 2~3갈래 상한.
- **적용 MAP-*:** `MAP-BRANCH` · `MAP-AGENCY` · `MAP-GATE`(보스 게이트) · `MAP-MACRO`(전진 압박) · `MAP-SEED` · `MAP-RUN` · `MAP-NAV`.

## 5. 액트/챕터 월드맵 (MAP-ACT)

- **정의:** 전체 진행을 시각·정서적으로 구별되는 '월드(테마 묶음)'로 쪼개고, 스테이지 선택을 추상 메뉴가 아니라 '걸어다니는
  지도(오버월드 노드맵)'로 만든다. 각 월드가 고유 배경 팔레트·BGM·기믹·테마를 갖고, 월드 끝에 마일스톤 보스를 둔다.
- **언제 쓰나:** 테마 변주·서사·마일스톤 보스가 있는 캠페인, 분량을 '월드 단위'로 확장하고 싶을 때.
- **게이팅:** 월드 경계에 하드 게이트(보스/별 N개), 월드 내부는 소프트(난이도). 잠긴 다음 월드를 실루엣으로 미리 보여 기대감.
- **내비:** 스테이지=노드, 진행=엣지. 클리어 시 맵 상태를 시각 변형(다리·문 열림)해 '내 손으로 세상을 바꿨다' 피드백.
  현재 위치(핀) 항상 표시, 1~2개 랜드마크 실루엣으로 앵커링.
- **거시 페이싱:** 각 월드 = 자체 톱니(도입→상승→보스 정점→하강). **챕터 단위 난이도 리셋·재상승**(새 월드는 직전 피크보다
  낮게 시작해 새 메카닉을 안전 학습 — `MAP-MACRO`·`MAP-CLOSE`). 정점 직후 falling action으로 act를 닫음.
- **영속 한 줄:** `worldId` + per-node 진행. 'act별 클리어 플래그'.
- **사례(기법만):** Super Mario Bros. 3의 월드별 테마 오버월드(풀밭→사막→군도→어둠) + 월드 끝 성/비행선 — 이 '오버월드=메인에
  연결된 미니 레벨' 분석은 Radek Koncewicz(Significant Bits, 2010~2011)의 2차 해설(Nintendo 공식 설계 진술과 구분).
  Candy Crush의 에피소드 6개=1월드 재편.
- **모바일 적합도:** ✅ 월드를 localStorage `worldId` 1개로, 진입 시 전화면 타이틀 카드(탭 1회). 색 팔레트 swap + 절차 파라미터
  프리셋으로 서버 없이 무한 테마 변주. ⚠️ BGM 꺼져있을 확률 높으니 정체성을 '색+실루엣'에 몰기.
- **적용 MAP-*:** `MAP-ACT` · `MAP-MACRO` · `MAP-CLOSE` · `MAP-BOSS` · `MAP-GATE` · `MAP-PROGRESS` · `MAP-NAV`.

## 6. 허브앤스포크 오버월드 (MAP-HUB)

- **정의:** 모든 스테이지로 가는 출입구가 모이는 중앙 허브에서 스테이지(스포크)가 뻗어 나가고, 클리어/중단 후 다시 허브로
  돌아오는 왕복 루프가 기본 박자. 허브는 (1) 안전한 휴식·연습처, (2) 탐색·미스터리, (3) 진척 가시화, (4) 다음 기대감 형성을 겸한다.
- **언제 쓰나:** 탐색·소속감·비선형 자유가 중요할 때, '진척=공간 변화'를 체감시키고 싶을 때.
- **게이팅:** 누적 수집 게이트(별 N개로 새 구역 해금) — '필요 < 접근 가능 총량'의 잉여 마진으로 비선형 자유 보장(`MAP-STAR`).
  Mario 64 Big Star Door(8/30/50/70)식.
- **내비:** 유일한 랜드마크 + 성격 다른 구역(district)으로 방향 상실 방지(Lynch 5요소). 동시 진입 가능 스포크 2~3개. 패스트
  트래블/즉시 복귀로 왕복 피로 억제(`MAP-NAV`).
- **거시 페이싱:** 여러 곡선 병렬, 자기 곡선 조립(`MAP-TOPOLOGY-CURVE` 허브). 복귀 시점에 '새로 열린 것' 1개 이상 노출.
- **영속 한 줄:** `meta:{ stars, unlocked:[...] }` + per-node 진행. 변하지 않는 허브는 의미 없음.
- **사례(기법만):** Super Mario 64 Peach's Castle(그림=스테이지 입구이자 예고편, 성 자체가 이동 연습장), Banjo-Kazooie의
  jiggy 해금. **왕복 피로·인지 과부하의 반례는 Banjo-Tooie** — 이 비판은 Mark Brown(GMTK)이 해설했고, 그 안에서 Rare의
  Banjo-Kazooie 시리즈 창작자 겸 디렉터 Gregg Mayles의 '첫 작에서 균형을 맞췄는데 속편에서 더 크게 만들려다 흔한 실수를
  했다'는 자기 인정을 인용한다(해설자=Brown, 1차 진술자=Mayles 구분).
- **모바일 적합도:** ⚠️ '걸어다니는 3D 허브'를 흉내내지 말 것 — 2D 한 화면 노드 배치 정적 허브로 축소. 진척 가시화(켜지는
  문)+기대감(잠긴 구역 실루엣)만 살리면 허브 효용 대부분 취득. '클리어→자동 복귀→다음 입구 1탭'을 2탭 이내로.
- **적용 MAP-*:** `MAP-HUB` · `MAP-STAR` · `MAP-NAV` · `MAP-PROGRESS` · `MAP-AGENCY` · `MAP-PERSIST`.

## 7. 개방형 상호연결 / 루프 (메트로배니아) (MAP-LOOP)

- **정의:** 가지(branch) 대신 **사이클(cycle)**을 기본 단위로 짜, 멀리 돌아온 길이 거점/출발점으로 폴드백(접힘)되며
  데드엔드를 줄인다. 진행은 열쇠 아이템이 아니라 **능력(이동기)**으로 잠그고(더블점프=수직 통로 등), 게이트를 능력 획득
  전에 먼저 보여줘 '나중에 다시 오자'는 약속을 만든다.
- **언제 쓰나:** 상호연결 탐험·백트래킹·'아하' 폴드백·능력 게이팅이 핵심 재미일 때.
- **게이팅:** 능력 기반 게이팅 + 선노출 약속(못 넘는 벽/물/간극을 미리 보여줌). 락앤키를 미션/공간 그래프로 분리 설계
  (`MAP-LOCKKEY` — Dormans 2010). 짧은 경로에 락, 긴 경로 끝에 키를 둬 '키 획득→짧은 복귀' 흐름.
- **내비:** 구역마다 강한 시각 정체성(랜드마크·색·실루엣) + 미니맵(미탐험/게이트/지름길 마커). '미니맵 OFF 테스트'(랜드마크
  만으로 길찾기 가능한지). 능력 게이트 위치를 미니맵 마커로 남겨 다음 세션에도 '못 넘은 곳' 기억.
- **거시 페이싱:** 지름길은 '반대편에서만 열리는 하드 게이트'로 한 번 열면 영구 단축. 되돌아온 옛 구역에 새 보상을 둬
  백트래킹을 패딩이 아닌 보상으로(`MAP-MACRO`). 소프트 게이팅으로 시퀀스 브레이킹 허용(`MAP-AGENCY`).
- **영속 한 줄:** 능력 비트마스크 + 지름길 개방 비트 + 탐험/핀 상태.
- **사례(기법만):** Metroid의 Morph Ball/Ice Beam, Hollow Knight의 단계적 능력 해금(Team Cherry는 하드 게이팅을 줄여 다수
  능력을 선택형으로). **사이클 우선 생성**의 1차는 Joris Dormans 'Cyclic (Dungeon) Generation'(『Procedural Generation
  in Game Design』, CRC 2017 / Unexplored 2017). Dark Souls 1의 월드 폴드백(사다리/엘리베이터 지름길)은 Miyazaki/
  FromSoftware의 독립 실천(Dormans 이론과 별개).
- **모바일 적합도:** ⚠️ 연속 공간 메트로배니아는 모바일에 버거움 → **노드맵 하이브리드**(노드맵을 메타 진행층으로, 능력
  게이팅을 노드 잠금조건으로)가 현실적. 사이클 길이를 한 세션(1~3분)에 한 바퀴 돌 수 있게 짧게.
- **적용 MAP-*:** `MAP-LOOP`(사이클·지름길) · `MAP-LOCKKEY` · `MAP-GATE`(능력 게이팅) · `MAP-NAV` · `MAP-AGENCY`.

## 8. 무한 / 엔드리스 / 절차맵 (MAP-INFINITE)

- **정의:** 명시적 노드/월드맵 없이 '얼마나 멀리/오래 갔는가'라는 단일 1차원 축을 진행도이자 점수로 삼는다. 화면 밖에서
  콘텐츠가 끝없이 이어 붙고 '맵'은 UI가 아니라 거리 카운터 그 자체다. 진행=점수=난이도가 한 변수에 묶인다.
- **언제 쓰나:** 무한 콘텐츠·짧은 세션·점수 자기경신이 목표일 때, 유한 캠페인 졸업 후 '숙련 곡선' 모드로.
- **게이팅:** 게이트 없음(거리 자체가 진행). 신규 위협을 임계 거리에서 단계적 해금해 학습 곡선을 만든다.
- **내비:** 진행은 단일 스칼라(거리/시간/깊이), 입력은 1~2개 제스처(탭/스와이프). 메타 맵 UI 불필요.
- **거시 페이싱:** 명시적 맵 없는 무한 난이도 램프 — 난이도를 거리의 단조 증가 함수로(선형보다 로그/계단형으로 완만, 후반
  절벽 방지). 휴지(rest beat) 삽입, 고속 구간일수록 장애물 최소 간격을 속도 비례 보장(`MAP-MACRO`). 데일리는 DDA 끄고 곡선 고정.
- **영속 한 줄:** `best`(거리/점수) + (데일리면 날짜별 기록). 맵 무저장.
- **사례(기법만):** Canabalt(Adam Saltsman, 2009, Flash)가 '거리=점수=진행' 단일축과 원버튼 엔드리스 러너를 **대중화·정형화**
  (창시는 아님 — Ovenbreak 2009-06·Doodle Jump 2009-04가 앞서고, 절차 무한 지형은 SkiFree 1991, 강제 전진은 Speed Race
  1974·Moon Patrol 1982까지). 절차 청크 합성·풀이가능 경로는 Spelunky 방식(`MAP-PCG`). DDA 1차 정식화는 Hunicke &
  Chapman 'AI for Dynamic Difficulty Adjustment in Games'(AAAI 2004, Hamlet).
- **모바일 적합도:** ✅✅ 서버·맵 UI·복잡 저장 모두 불필요, 한손·1~3분에 정확히 맞음. requestAnimationFrame 컨베이어 +
  오브젝트 풀 + best만 저장. 데일리 시드(`MAP-DAILY`)와 결합하면 '오늘의 맵' 비공식 경쟁 성립.
- **적용 MAP-*:** `MAP-INFINITE` · `MAP-MACRO`(무한 램프) · `MAP-PCG` · `MAP-SEED` · `MAP-DAILY` · `MAP-RUN`.

## 위상 진화 경로 (점진 확장 권장)

평평한 선형(`MAP-LINEAR`)이 그래프의 특수형이므로 기존 게임을 깨지 않고 점진 확장한다(데이터는 [build-patterns.md](./build-patterns.md)의
`MAP-SCHEMA` 한 모델로 전부 표현):

```
선형(현 runeburst/is-rule)
  └→ + 사가 화면(MAP-SAGA)          : 데이터 그대로, 표현만 여정으로
  └→ + 별 그리드(MAP-GRID)          : per-node stars 추가
  └→ + 가벼운 분기/액트(MAP-ACT)     : next 다수·worldId 추가, 톱니 분산
  └→ + 무한·데일리 모드(MAP-INFINITE) : 별도 네임스페이스, 시드 기반
  └→ + 분기 노드맵(MAP-DAG)          : 런 기반 위상, 시드+포인터만 저장
  └→ + 메타 해금/NG+(MAP-META)       : meta 섹션 + cycle 차원
```

> 모바일 캐주얼의 현실적 종착점은 보통 **'사가/액트 캠페인(영속) + 데일리·무한(런) + 별/메타 해금'** 의 하이브리드다.
> 풀 허브(§6)·메트로배니아(§7)는 작은 화면·짧은 세션 비용이 크니 노드맵/정적 허브로 축소해 차용한다.
