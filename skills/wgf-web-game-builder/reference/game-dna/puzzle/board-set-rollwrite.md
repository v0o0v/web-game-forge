> WebGameForge `puzzle-game` 템플릿 레퍼런스(퍼즐 심화 35종 중 일부 — 디지털 퍼즐 20종에 더해 물리 보드게임 15종이 추가된 확장의 일부다). 아래 게임들의 **메카닉·재미요소만** 분석한 자료다(저작물 미사용 — 각 IP 안전 메모 참고). 이 파일은 **물리 보드게임의 메카닉을 디지털 단일플레이 웹 퍼즐로 번안하는 관점**으로, 테이블 위 멀티플레이 인터랙션을 솔로 로컬(휴리스틱 AI 경쟁자·남김 비용 변형·날짜 시드 데일리·localStorage 베스트)로 축소하는 길을 함께 적는다. 새 퍼즐 설계 시 **퍼즐 코어 1개 + 다른 게임의 재미요소를 조합**한다. 퍼즐 재미요소 태그 정의·조합 플레이북은 [fun-elements.md](./fun-elements.md), 색인은 [INDEX.md](./INDEX.md). 전역 게임 DNA는 [../INDEX.md](../INDEX.md).

## Rummikub (1977)
**왜 많이 플레이됐나:** 럼미(rummy) 카드 게임의 세트 만들기를 타일로 옮기면서, "이미 테이블에 놓인 모든 타일을 내 차례에 마음껏 부수고 다시 조립해도 된다 — 차례가 끝날 때 모든 세트가 합법이기만 하면"이라는 단 한 줄의 규칙(manipulation)이 게임을 폭발시켰다. 고정돼 보이던 판이 사실은 유동 자원이라는 깨달음이 가능한 수를 천문학적으로 늘리고, 한 손의 골칫거리 타일을 남의 세트를 헐어 끼워 넣는 '연쇄 재배열'의 쾌감을 만든다. 규칙은 5분이면 배우지만(런=같은 색 연속, 그룹=같은 수 다른 색) 재배열의 깊이는 끝이 없어 가족 게임이면서 두뇌 게임이고, 언어 의존이 없는 숫자 타일이라 국경을 넘어 5천만 세트 이상 팔린 스테디셀러가 됐다. 1980년 Spiel des Jahres(독일 올해의 게임)를 수상했다.
**장르 / 시점:** 세트 컬렉션 + 타일 재배열(rummy / tile-laying manipulation) 보드게임 / 정면에서 내려다보는 2D 평면 — 가로로 긴 공용 테이블(놓인 세트들)과 내 거치대(손패 랙)를 한 화면에 둔다. 스크롤 없음, 정적 카메라. 타일은 색·숫자로 구분되는 직사각 조각이고 위치는 자유롭게 끌어 옮긴다.
**코어 루프:** 내 차례에 (a) 손패에서 새 타일을 테이블에 내거나, (b) 이미 놓인 세트를 헐어 내 타일과 섞어 재배열하되 — 차례 종료 시 테이블의 모든 묶음이 유효한 런/그룹이어야 한다. 내지 않으면(또는 못 내면) 풀에서 타일 1장을 뽑고 차례를 넘긴다; 재배열을 시도했다가 합법 상태로 되돌리지 못하면 테이블을 원상 복구하고 페널티로 3장을 뽑는다(디지털 번안에서는 자유 undo로 완화 가능). 첫 등장(initial meld)은 반드시 합산 30점 이상의 세트(들)로만 가능하다. 손패를 가장 먼저 모두 내려놓으면 라운드 승리.
**핵심 재미요소:**
- `FE-REARRANGE` 판 재구성 — Rummikub의 심장. 테이블 위 모든 세트는 '최종이 합법이기만 하면' 마음껏 분해·재조립할 수 있다. 4·5·6 런에서 4를 빼 다른 그룹에 주고 5·6에 7을 붙여 살리는 식으로, 고정돼 보이는 판이 유동 자원임을 깨달을 때 가능한 수가 폭발한다. 우리 엔진에서는 `puzzle-game` 보드모델을 '자유 좌표 타일 풀 + 묶음(meld) 리스트'로 두고, 드래그로 타일을 묶음 간 이동시킨 뒤 차례 확정 시점에 `validateAllMelds()`(모든 묶음이 런/그룹인지 1패스 검사)를 돌려 합법일 때만 커밋, 불법이면 스냅샷 undo로 되돌린다.
- `FE-SET-LOGIC` 같음·다름 세트 — 런(같은 색 연속 숫자 3+)과 그룹(같은 숫자, 서로 다른 색 3+)이라는 두 교차 조건을 동시에 만족시키는 묶음을 식별·구성한다. 한 타일이 런에도 그룹에도 들어갈 수 있어 '이 7을 어느 세트에 쓸까'의 조합 판단이 깊이를 만든다. 묶음 검증은 정렬 후 연속성/동수-이색 판정으로 순수 로직 구현.
- `FE-PLANNING` 선계획·멀티스텝 — 한 번의 재배열이 테이블 전체를 건드리므로, '이 그룹을 헐면 저 타일이 떠서 다시 어디에 붙여야 하나'를 여러 단계 앞서 시뮬레이션해야 한다. 손패의 골칫거리(연결 안 되는 외톨이 타일)를 어느 세트를 헐어 끼울지 머릿속으로 경로를 그리는 체스적 수읽기다. undo 풀개방으로 가설검증 비용을 낮춰 재배열 실험을 권장한다.
- `FE-OPTIMIZE` 최적화 — 단순히 한 장 내려놓는 걸 넘어 '이번 차례에 손패를 최대한 많이 터는' 최적 재배열을 노린다. 30점 initial meld를 어떤 세트로 깔끔히 넘길지, 마지막 한 장을 어떻게 끼워 라운드를 끝낼지의 효율 도전. 솔로 변형에서는 '차례당 내려놓은 타일 수'와 '잔여 손패 감점'을 점수로 노출해 최적화 동기를 만든다.
- `FE-AHA` 통찰·아하 — 막혀 보이는 손패가 테이블 한 세트를 헐자 갑자기 술술 풀리는 순간의 발견감. 외톨이 타일 하나가 재배열 한 번으로 두 세트를 동시에 살리는 '딱 맞는 수'를 찾았을 때의 쾌감이 강하다. 힌트는 '둘 수 있는 합법 수 1개만' 강조해 아하를 빼앗지 않는다.
**핵심 메카닉:**
- 타일 구성: 1~13 숫자 타일이 4색(예: 파/빨/주/검), 각 색·숫자 조합이 2장씩 = 104장 + 조커 2장. 조커는 어떤 타일도 대체(런·그룹의 빈자리), 점수는 30점(initial meld 계산 시 대체 타일의 면값으로 산정). 풀(주머니)에서 무작위로 뽑아 손패를 채운다.
- 세트 정의: **런(run)** = 같은 색의 연속하는 숫자 3장 이상(예: 빨강 4-5-6), **그룹(group)** = 같은 숫자에 서로 다른 색 3~4장(예: 7 빨강·파랑·검정). 한 묶음에 같은 색·숫자 중복은 불가.
- initial meld(최초 등록): 처음 테이블에 내는 세트(들)의 합산 면값이 30점 이상이어야 등록 가능 — 그 전에는 재배열 참여 불가. 조커는 대체한 타일의 값으로 계산. 이 게이트가 초반 손패 관리 긴장을 만든다.
- 재배열(manipulation): 차례 동안 테이블의 어떤 타일도 끌어다 묶음 간 이동·분해·병합 가능. **유일한 제약은 차례 종료 시 모든 묶음이 유효 런/그룹**이고, 내 손패에서 최소 1장은 새로 테이블에 추가됐어야 한다(순수 재배열만으로 차례를 넘길 수 없음). 재배열 실패 시 전체 원상 복구 + 페널티 3장 draw(아예 안/못 내고 넘길 때는 1장 draw).
- 점수 체계: 라운드 종료(누군가 손패 소진) 시 각 패자는 **잔여 손패 면값 합을 감점**(조커는 -30), 승자는 패자들의 감점 총합을 양수로 획득. 누적 점수로 여러 라운드를 진행.
- 검증 로직: `validateAllMelds()`는 각 묶음을 정렬해 (런: 동색·연속·길이≥3) 또는 (그룹: 동수·이색·길이 3~4)인지 판정, 조커는 와일드로 어느 자리든 채울 수 있게 후보 탐색. 모든 묶음 통과 + 손패 1장 이상 추가 시에만 커밋.
**난이도·진행 곡선:** 외부 레벨이 없는 라운드 반복형. 초반은 손패에 자연 세트가 적어 30점 게이트를 넘기 빡빡하고(긴장), 중반부터 테이블 세트가 쌓이면 재배열 가능성이 폭증해 한 차례에 여러 장을 터는 콤보가 열린다(FE-REARRANGE 절정). 솔로 축소판의 난도는 (a) AI 경쟁자 수·기량(탐욕 1수 vs 2수 탐색), (b) 풀에 남은 타일과 draw 운, (c) 시간/차례 제한 모드로 조절한다. level-designer로 '특정 시드의 손패에서 N차례 안에 손패를 다 털어라' 같은 퍼즐형 챌린지 레벨도 만들 수 있다.
**게임필·연출:** 손맛의 핵심은 '타일을 끌어 묶음 사이를 오가게 하는' 드래그의 촉각성과, 차례 확정 순간 모든 묶음이 합법으로 '딸깍' 정렬되는 만족이다. 타일을 들면 살짝 떠오르고(scale·shadow), 유효한 묶음에 가까이 가면 슬롯이 하이라이트(스냅 가이드), 불법 상태면 해당 묶음이 붉게 펄스. 차례 커밋 시 새로 완성된 세트가 가벼운 글로우 스윕 + ChipAudio 'coin', initial meld 달성은 상위 톤 팡파르, 손패 소진(라운드 승리)은 화이트 플래시 + 점수 롤업. 불법 확정 시도는 둔탁한 'die' 변형 + 흔들림으로 즉시 피드백. juice-fx는 '적게, 정확하게' — 재배열 자체가 시각 정보가 많으므로 셰이크는 라운드 승리에만.
**끈끈함(리텐션):** 같은 손패라도 테이블 상태와 재배열 실력에 따라 결과가 천차만별이라 '내 수읽기가 부족했다'는 공정성 귀인이 재도전을 부른다(FE-FAIRNESS 성격). 한 차례에 손패를 와르르 터는 대형 재배열의 쾌감이 강한 기억으로 남고, 라운드가 짧아 즉시 재시작이 자연스럽다. 솔로에서는 AI를 이기는 맛 + '차례당 최다 타일 털기' 자기 기록 경신 + 날짜 시드 데일리(같은 손패·같은 풀로 모두가 도전)가 장기 동기를 만든다.
**우리 엔진 재현도:** ⚠️ · 스킬 `puzzle-game` · 엔진 Phaser 4(물리 미사용, 자유 좌표 드래그 + 순수 묶음 로직), 보드모델은 '타일 풀 + 묶음 리스트 + 손패 랙' 3구역(단일 상태원), renderBoard()는 재배열/커밋 시점에만 호출, PixelForge 또는 VectorForge(숫자 타일·조커·4색 팔레트 절차 생성), ChipAudio(타일 픽업·스냅·세트 완성·라운드 승리 SFX), MobileHarness(드래그 픽업·스냅, 좁은 화면 랙 스크롤·DOM 가드), juice-fx(스냅 하이라이트·불법 펄스·완성 글로우·점수 롤업), game-ui-hud(점수·잔여 타일 수·차례 표시·undo 버튼·힌트), level-designer(시드 손패·AI 기량·챌린지 레벨), localStorage(누적 점수·데일리 베스트·고스트). 코어(런/그룹 세트 + 재배열 검증)는 충실 재현 가능 — 물리 불필요한 순수 로직이고 `validateAllMelds()`가 결정론적이다. ⚠️인 이유는 **멀티플레이 인터랙션이 코어 재미의 큰 축**이기 때문: 원작의 긴장은 '남이 헐기 전에 내가 먼저', '상대가 못 내고 draw하는 걸 보는' 대인 견제에서 상당 부분 나온다. 솔로 변환: (1) **휴리스틱 AI 경쟁자 1~3인** — 탐욕 1수 평가(가능한 합법 수 중 손패를 가장 많이 터는 수 선택)면 충분한 상대가 된다, (2) **남김 비용 변형** — 'AI가 다음 차례에 활용할 외톨이를 테이블에 남기면 페널티' 같은 솔로 규칙으로 견제 심리를 단일플레이로 번역, (3) **날짜 시드 데일리** — 모두 같은 시드 손패·풀로 '최소 차례 손패 소진'을 겨루고 결과를 이모지로 공유, (4) **localStorage 베스트·고스트** 셀프경쟁. 충실 재현: 런/그룹 정의, initial meld 30점 게이트, 자유 재배열 + 차례말 합법 검증, 조커 와일드, 잔여 손패 감점. 대체/단순화: 실시간 대인 견제·서버 랭킹은 ❌ → AI/데일리/로컬로 축소. 자유 좌표 드래그는 격자 스냅(묶음 슬롯)으로 단순화해 모바일 정밀도를 확보한다.
**조합 훅:** 2048/Threes 슬라이드와 결합 — 손패를 방향 슬라이드로 정렬하면 닿은 같은 색 연속이 런으로 자동 묶이는 '슬라이드 럼미'(FE-REARRANGE+FE-CONSTRAINT); Sudoku 연역과 결합 — 테이블에 '이 칸은 빨강 5만 합법' 제약을 깔고 재배열로 유일해를 맞추는 연역형 타일 배치(FE-SET-LOGIC+FE-DEDUCTION); arcade-classic 스코어어택으로 축소 — 제한 시간 안에 '한 차례 재배열로 최다 타일 털기'만 노리는 순수 점수 모드(FE-OPTIMIZE+FE-JUST-ONE-MORE 로컬 리더보드); topdown-shooter에 이식 — 처치한 적이 숫자 타일을 떨구고 하단 랙에서 런/그룹을 완성하면 그 색 광역기가 발동하는 '세트 장전' 슈터(FE-SET-LOGIC+FE-COMBO); Qwirkle과 교차 — 런/그룹을 '라인'으로 확장해 보드에 펼치는 하이브리드 타일 레이잉(FE-REARRANGE+FE-SPATIAL).
**IP 안전 메모:** 금지: 'Rummikub' 게임명·로고·서체, 원작 특유의 타일 디자인(상아색 바탕·특정 색조의 숫자 폰트)·거치대(랙) 외형, 조커 타일의 고유 스마일 심볼, 원작 패키지 아트·구성물 디자인을 그대로 쓰지 말 것. 메카닉(런=동색 연속, 그룹=동수 이색, 자유 재배열 후 차례말 합법 검증, initial meld 30점, 조커 와일드, 잔여 손패 감점)은 럼미 계열 보편 규칙 + 게임 시스템이라 자유롭게 구현 가능 — 표현물만 100% 자체 제작하면 안전하다. IP-safe 환기: 타일은 PixelForge(픽셀) 또는 VectorForge(둥근 벡터)로 자체 팔레트·서체를 절차 생성, 조커는 자체 와일드 심볼로, 사운드는 ChipAudio 8비트 자체 생성. 고유 타이틀(예: 'Runlay', 'Tileshift', 'Meld') 부여, 'Rummikub'은 메카닉 설명 맥락에서만 표기. 최종은 ip-license-guard 스킬로 점검한다.

## SET (1991)
**왜 많이 플레이됐나:** 유전학자 Marsha Falco가 1974년 자신의 코딩 표기에서 출발해 만든 게임으로, 1991년 Set Enterprises가 출시했다. "차례가 없다 — 모두가 동시에 테이블을 노려보며 누가 먼저 유효 세트를 외치느냐"는 실시간 패턴 인식 경쟁이 핵심이다. 규칙은 한 문장("네 속성 각각이 셋 다 같거나 셋 다 달라야 한다")인데, 그 한 문장이 만드는 인식의 깊이가 끝이 없어 7세 아이부터 수학자까지 같은 테이블에서 겨룬다. 속성이 4개라 조합 공간이 폭발하고, '보이는 사람에게는 순식간에 보이고 안 보이는 사람에게는 영원히 안 보이는' 뇌의 패턴 록인이 중독을 만든다. 1991년 American Mensa의 Mensa Select를 수상했고, 신문·온라인 데일리 퍼즐로도 정착해 수십 년째 사랑받는다.
**장르 / 시점:** 실시간 패턴 인식 / 세트 식별 카드 게임 / 정면 2D — 12장(3×4) 카드 그리드를 한 화면에 펼친 정적 레이아웃. 스크롤 없음. 카드는 수·모양·음영·색 네 속성을 가진 추상 기호 카드다.
**코어 루프:** 테이블에 12장을 펼친다 → 플레이어는 그 안에서 '유효 세트'를 이루는 3장을 찾아 즉시 집는다(솔로/디지털은 탭) → 유효하면 그 3장을 치우고 풀에서 3장을 보충, 무효면 짧은 페널티 → 12장 안에 세트가 하나도 없으면 3장을 추가(15장) → 풀이 바닥나고 더 이상 세트가 없으면 종료. 가장 많은 세트를 모은 쪽이 이긴다.
**핵심 재미요소:**
- `FE-SET-LOGIC` 같음·다름 세트 — SET의 정의 그 자체. 수(1·2·3)·모양(다이아·물결·타원)·음영(꽉참·줄·빈)·색(빨·초·보) 네 속성 각각이 '셋 다 같거나 셋 다 다름'을 동시에 만족해야 유효. 한 속성이라도 '둘 같고 하나 다름'이면 무효. 속성이 4개라 조합 공간이 폭발하고 인식 속도가 곧 실력이다. 검증은 각 속성에서 세 값의 집합 크기가 1(모두 같음) 또는 3(모두 다름)인지만 보면 되는 순수 로직 — `valid = attrs.every(a => new Set(three.map(c=>c[a])).size !== 2)`.
- `FE-DEDUCTION` 연역·소거 — '이 두 장으로 세트가 되려면 세 번째는 반드시 이것'이라는 수학적 확정(어떤 두 장이든 유일한 세 번째가 존재)을 머릿속에서 계산해 테이블에서 그 카드를 찾는다. 운이 끼지 않는 결정적 추론이라 '보면 반드시 있다/없다'가 확정된다. 우리 엔진은 두 카드로부터 세 번째를 즉시 산출하는 `thirdCard(a,b)`(각 속성: 같으면 그 값, 다르면 남은 한 값)로 힌트·자동 검증을 구현.
- `FE-FLOW` 몰입 흐름 — 차례·대기 없이 계속 노려보다 세트가 '딱' 보이는 순간 즉시 집는 끊김 없는 리듬. 사고와 입력 사이 지연이 0에 가까워 몰입이 깊다. 솔로 타임어택에서 '연속으로 빠르게 찾기'가 플로우를 극대화한다.
- `FE-AHA` 통찰·아하 — 한참 안 보이던 세트가 시야에서 갑자기 튀어나오는 시지각의 '딸깍' 순간. 같은 12장을 보고도 남은 못 보는 걸 나는 본다는 인지적 우월감이 강한 보상이다.
- `FE-JUST-ONE-MORE` 한 판 더 — 한 세트가 1~5초, 한 판이 짧고 '세트 N개·소요 시간'이 자기 기록으로 남아 즉시 재도전을 부른다. 날짜 시드 데일리(모두 같은 보드)는 결과 공유로 '한 판 더'를 사회적 자극으로 증폭한다.
- `FE-FAIRNESS` 공정함 — 세트의 존재는 100% 결정적이라 '못 찾은 건 운이 아니라 내 인식 부족'으로 납득된다. 무효 선택 페널티가 명확하고, 12장 안 세트 없음 판정도 결정론적이라 억울함이 없다.
**핵심 메카닉:**
- 덱 구성: 4속성 × 각 3값 = 3^4 = 81장. 각 (수,모양,음영,색) 조합이 정확히 1장씩 유일. 카드는 4자리 3진수로 인코딩(예: `[2,0,1,2]`) — 비교·검증·세 번째 산출이 전부 정수 연산.
- 유효 세트 판정: 3장 각 속성에서 값 집합 크기가 1 또는 3(2가 아님). 네 속성 모두 통과해야 유효. O(4) 상수 시간.
- 세 번째 카드 산출: 두 장 a,b로부터 세트를 완성하는 유일 카드 — 각 속성에서 a==b면 그 값, 다르면 0/1/2 중 남은 한 값(`3 - a - b`). 힌트·솔버·"세트 없음" 전수 검사(12장 C(12,3)=220 조합)에 사용.
- 테이블 운영: 12장 펼침 → 선택된 유효 세트 3장 제거 후 풀에서 3장 보충(12장 유지) → 12장 안에 세트가 0개면 3장 추가(15·18…) → 풀 소진 + 잔여에 세트 없음이면 종료.
- 점수: 유효 세트 1개당 +1(또는 시간 가중). 무효 선택은 짧은 락아웃/감점. 솔로는 '총 세트 수 + 소요 시간'이 단일 지표.
- "세트 없음" 콜: 플레이어가 '현재 보드에 세트 없음'을 선언할 수 있고(디지털은 버튼), 전수 검사로 참이면 3장 추가, 거짓이면 페널티 — FE-DEDUCTION 깊이를 더한다.
**난이도·진행 곡선:** 외부 레벨 없는 자가 점증. 보드에 세트 후보가 많을 땐 쉽고, 잔여 카드가 줄며 후보가 희소해질수록 인식 난도가 오른다. 솔로 모드 난도 조절: (a) 속성 수 축소(3속성=27장 입문 → 4속성=81장 정식 → 변형 5속성 챌린지), (b) 타임어택 vs 무제한 사색, (c) '세트 없음 콜' 가산점 모드. level-designer로 '특정 시드 보드에서 모든 세트를 N초 안에' 같은 퍼즐 챌린지를 만든다. FE-ESCALATION 강제 가속은 사고형 인식과 충돌하므로 압박은 '자기 시간 기록'으로만 준다(타임어택은 옵션, 사색 모드와 분리).
**게임필·연출:** 손맛은 '딱 보고 즉시 집는' 즉응성. 카드 선택 시 살짝 떠오르며 테두리 글로우, 3장 선택이 완성되는 순간 유효면 세 카드가 함께 밝게 펄스하며 사라지고(ChipAudio 상승 'coin') 새 카드가 톡 등장(Back.out), 무효면 세 카드가 붉게 흔들리며 선택 해제(둔탁한 변형음). 카드 자체는 깔끔한 벡터 기호(VectorForge) — 음영(꽉참/줄/빈)은 패턴 채움으로 또렷이 구분. 데일리 클리어·신기록은 화면 가장자리 컨페티 절제 버전 + 결과 격자 이모지 자동 복사. juice-fx '적게, 정확하게' — 인식 게임이라 화면 정보를 흐리는 과한 파티클·셰이크는 피한다.
**끈끈함(리텐션):** 결정적 공정성 + 짧은 루프 + 명확한 단일 지표(세트 수/시간)가 자기 기록 경신을 끝없이 부른다. '나는 보는데 남은 못 본다'는 인지적 자부심이 반복을 유도하고, 날짜 시드 데일리는 '모두 같은 보드'라 시간 비교·이모지 공유로 사회적 끈끈함을 만든다(Wordle 모델). 속성 수 토글로 입문~고수가 같은 게임을 다른 난도로 즐겨 진입장벽이 낮다.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 Phaser 4(물리 미사용, 카드 그리드 입력·순수 정수 로직), 보드모델은 '81장 풀 + 펼친 보드(12~18) + 선택 버퍼' (단일 상태원), renderBoard()는 선택/제거/보충 시점에만 호출, VectorForge(4속성 추상 기호 카드 절차 생성 — 음영 패턴 포함), ChipAudio(선택·유효·무효·신기록 SFX), MobileHarness(탭 선택·세로 스케일·DOM 가드), juice-fx(선택 글로우·유효 펄스·무효 흔들림·신기록 컨페티), game-ui-hud(세트 수·타이머·세트없음 버튼·힌트·데일리 표시), level-designer(속성 수·시드 보드·챌린지), localStorage(베스트 타임·데일리 결과·연속 일수). 코어가 단일플레이로 손실 없이 성립 — SET은 원래 차례가 없는 동시 인식이라 '솔로 = 모든 세트를 혼자 찾기'가 그대로 자연스럽다(멀티는 '먼저 외치기' 속도 경쟁일 뿐 규칙은 동일). 충실 재현: 81장 인코딩, 유효 판정, 세 번째 산출 힌트, 12→15 보충 규칙, 세트 없음 콜, 속성 수 변형, 타임어택/사색 모드, 날짜 시드 데일리. 멀티의 '먼저 집기' 속도 경쟁은 (a) **AI 경쟁자**(랜덤 지연 후 유효 세트 1개 자동 선택 — 반응 시간 파라미터로 난도 조절)로 '동시에 노리는 긴장'을 재현하거나, (b) **순수 솔로 타임어택**(혼자 전 세트를 빠르게)으로 대체. 대체/단순화: 서버 랭킹·실시간 멀티 대전은 ❌ → AI/데일리/localStorage 베스트로 축소. 거의 축소 불필요 — 단일플레이 웹 기준 사실상 100% 재현.
**조합 훅:** Bejeweled 매치3와 결합 — 보드에서 유효 세트를 집으면 그 자리가 캐스케이드로 무너지며 점수가 연쇄하는 '세트 캐스케이드'(FE-SET-LOGIC+FE-COMBO); Sudoku 데일리와 묶기 — 하루 한 번 같은 시드로 '모든 세트 찾기'를 풀고 격자 이모지로 공유하는 데일리 인식 퍼즐(FE-DEDUCTION+FE-JUST-ONE-MORE); endless-runner에 이식 — 질주 중 상단에 떠오르는 3카드가 유효 세트면 탭해 부스트, 무효 탭은 감속하는 '세트 러너'(FE-FLOW+FE-TIMING); topdown-shooter에 이식 — 적이 속성 카드를 들고 등장, 유효 세트를 이루는 3적을 연달아 조준 처치하면 보너스 폭발(FE-SET-LOGIC+FE-RISK-REWARD); arcade-classic 스코어어택 — 제한 시간 안 최다 세트 식별, 로컬 베스트·시드 공유(FE-FLOW+FE-OPTIMIZE).
**IP 안전 메모:** 금지: 'SET' 게임명·로고, 원작 카드의 고유 기호 디자인(특유의 '물결(squiggle)' 모양 곡선·다이아·타원의 정확한 형태와 비율), 원작 색조합·음영 패턴의 정확한 그래픽, 패키지 아트. 메카닉(81장 4속성 3값, 모두같음-모두다름 판정, 두 장→유일 세 번째, 12장 펼침·세트 없음 시 보충)은 수학 규칙·게임 시스템이라 자유롭게 구현 가능 — 저작권 보호 대상이 아니다. IP-safe 환기: 네 속성은 일반 개념(개수·도형·채움·색)만 차용하되 도형은 VectorForge로 자체 디자인(예: 별/육각/링 — 원작 다이아·물결·타원과 다른 형태), 색·음영 팔레트도 새로 고른다. 사운드는 ChipAudio 자체 생성. 고유 타이틀(예: 'Trio', 'Match-Three-Attributes', 'Spot')을 부여하고 'SET'은 메카닉 설명 맥락에서만 표기. ip-license-guard 스킬로 최종 점검한다.

## Qwirkle (2006)
**왜 많이 플레이됐나:** "도미노처럼 쉬운데 스크래블처럼 깊다"는 평을 받는 추상 타일 레이잉 게임이다. 글자가 없는 색·모양 타일이라 언어 장벽이 없고, "한 줄에는 색 하나로 모양을 모두 다르게 / 모양 하나로 색을 모두 다르게, 중복은 금지"라는 단 하나의 라인 규칙이 누구나 1분 만에 배울 직관성과 끝없는 배치 최적화 깊이를 동시에 준다. 한 타일이 가로·세로 두 라인에 동시에 점수를 내고 6완성 'Qwirkle' 보너스가 한 방을 만들어 '어디에 놓아 최대 라인을 만들까'의 공간 최적화가 중독을 만든다. 2007년 Mensa Select, 2011년 Spiel des Jahres(독일 올해의 게임)를 수상하며 가족 추상 게임의 대표작이 됐다.
**장르 / 시점:** 추상 전략 타일 레이잉(line-building tile placement) / 정면에서 내려다보는 2D 평면 — 무한히 확장되는 공용 격자판(놓인 타일들)과 내 손패(6타일)를 한 화면에. 보드가 커지면 카메라 팬/줌. 타일은 색·모양으로 구분되는 정사각 조각.
**코어 루프:** 손패(6장)에서 타일을 공용 보드에 놓되 — 한 차례에 놓는 모든 타일은 같은 행 또는 같은 열에 일직선이고, 그 라인은 '같은 색(모양은 모두 다름)' 또는 '같은 모양(색은 모두 다름)'을 만족하며 중복이 없어야 한다 → 놓은 만큼 점수(접한 모든 라인의 타일 수 합) → 손패를 풀에서 6장으로 보충. 풀이 비고 누군가 손패를 다 쓰면 종료, 최고 점수가 승리.
**핵심 재미요소:**
- `FE-SET-LOGIC` 같음·다름 세트 — 라인 규칙의 본질. 한 라인은 한 속성(색 또는 모양)이 모두 같고 다른 속성은 모두 달라야 하며, 같은 (색,모양) 타일이 한 라인에 두 번 오면 무효. 어떤 타일이 어느 라인에 합법인지 교차 판단하는 게 매 수의 사고다. 검증은 라인을 모아 (한 축 동일 + 다른 축 전부 상이 + 중복 없음) 1패스 검사.
- `FE-SPATIAL` 공간 추론 — 한 타일을 어디에 놓으면 가로 라인과 세로 라인을 '동시에' 잇는지, 6완성 자리를 어떻게 여는지를 격자 위에서 미리 그려본다. 같은 손패라도 배치 위치에 따라 점수가 배로 갈리는 위치 최적화가 깊이를 만든다. 고스트 프리뷰(놓기 전 합법/점수 미리보기)로 공간 시뮬레이션을 시각 보조한다.
- `FE-OPTIMIZE` 최적화 — 단순히 한 장 놓기를 넘어 '이 차례 점수를 최대로' 뽑는다. 교차 라인을 동시에 잇고 6완성 Qwirkle(+6 보너스)을 노리며, 손패 6장을 어느 순서·방향으로 깔지 최적 배치를 계산한다. 차례 점수·누적 점수·달성 Qwirkle 수를 HUD에 노출해 동기를 만든다.
- `FE-DRAFT` 드래프트·시장 선택 — 풀에서 무작위로 뽑은 손패 6장이 내 '시장'이고, 차례마다 '무엇을 놓고 무엇을 손에 남길지(다음 차례·상대에게 줄 자리를 고려)'를 저울질한다. 솔로/AI전에서는 '지금 점수 vs 다음 큰 한 방을 위한 보류'의 이중 가치 판단으로 작동한다.
- `FE-AHA` 통찰·아하 — 꽉 찬 보드에서 한 타일이 두 라인을 동시에 6완성으로 잇는 '딱 맞는 자리'를 발견하는 순간의 쾌감. 손패의 애매한 타일이 의외의 위치에서 큰 점수가 되는 발견감.
**핵심 메카닉:**
- 타일 구성: 6색 × 6모양 = 36조합, 각 3장씩 = 108타일. 풀(주머니)에서 무작위로 뽑아 손패 6장 유지. 게임 시작은 손패에서 같은 속성으로 가장 많이 놓을 수 있는 플레이어/배치부터.
- 라인 규칙: 한 차례에 놓는 타일은 같은 행 또는 열에 연속(중간 빈칸 없이 기존 타일과 접해야), 그 라인은 (모두 같은 색 + 모양 전부 다름) 또는 (모두 같은 모양 + 색 전부 다름), 같은 (색,모양) 중복 불가. 라인 최대 길이 6(6색 또는 6모양 한 벌).
- 점수: 놓은 타일이 속한 **모든 라인의 타일 수 합**(이미 놓인 타일 포함). 한 타일이 가로·세로 두 라인에 닿으면 두 라인 모두 가산(교차 동시 득점). 길이 6 라인 완성 = 'Qwirkle' +6 보너스(최소 6+6=12점). 한 차례에 여러 라인을 만들면 각각 합산.
- 보드 모델: 무한 확장 격자라 `Map<"r,c", tile>` 희소 표현(또는 동적 2D 배열). 놓을 후보 칸은 기존 타일 인접 빈칸만. 합법성·점수는 놓은 타일들의 가로/세로 라인을 추출해 검사·합산하는 순수 함수.
- 종료·보너스: 풀이 비고 한 플레이어가 손패를 모두 소진하면 게임 종료, 그 플레이어 **+6 보너스**. 최고 누적 점수 승리. (손패를 못 놓으면 일부/전부를 풀과 교환하고 차례 넘김.)
**난이도·진행 곡선:** 라운드 없는 단일 게임이 보드 성장과 함께 깊어진다. 초반은 빈 보드라 라인이 짧고 점수가 작지만, 보드가 커지며 교차·6완성 기회가 늘어 후반 한 수의 점수 폭이 커진다(FE-OPTIMIZE 절정). 솔로 난도: (a) AI 경쟁자 기량(탐욕 1수 최대 점수 vs 6완성 세팅 2수 탐색), (b) 풀 draw 운, (c) '점수 목표 달성' vs 'AI보다 높은 점수' 승리 조건. level-designer로 '주어진 보드+손패에서 한 수 최대 점수를 찾아라' 퍼즐 챌린지도 가능.
**게임필·연출:** 손맛은 타일을 격자에 '딱' 스냅해 놓을 때의 정렬감과, 라인이 길어질수록 커지는 점수 팝업이다. 손패 타일을 들면 떠오르고, 합법 칸은 초록 하이라이트 + 예상 점수 고스트, 불법 칸은 회색/적색. 놓는 순간 접한 라인이 끝에서 끝으로 글로우 스윕(라인 길이만큼 점수 카운트업), 6완성 Qwirkle은 라인 전체 무지개 플래시 + 상위 톤 팡파르 + 미세 스크린셰이크. 손패 소진 종료는 화이트 플래시 + 누적 점수 롤업. ChipAudio: 배치 'bump', 라인 완성 'coin' 스택(라인 길수록 피치 상승), Qwirkle 특별음. juice-fx '적게, 정확하게' — Qwirkle 같은 의미 있는 순간에만 강하게.
**끈끈함(리텐션):** 단순 규칙 + 깊은 위치 최적화 + 6완성 한 방의 천장이 '더 잘 놓을 수 있다'는 숙련 동기를 유지한다. 같은 손패라도 배치로 점수가 갈려 '내 배치가 부족했다'는 공정성 귀인이 재도전을 부른다. 솔로에서는 AI를 이기는 맛 + 자기 최고 점수 경신 + 날짜 시드 데일리(같은 풀·손패 순서로 모두가 도전, 결과 공유)가 장기 동기를 만든다. 한 게임이 적당히 짧아 즉시 재시작 마찰이 낮다.
**우리 엔진 재현도:** ⚠️ · 스킬 `puzzle-game` · 엔진 Phaser 4(물리 미사용, 격자 스냅 드래그 + 순수 라인 로직), 보드모델은 '희소 격자 Map + 손패 6 + 풀'(단일 상태원), renderBoard()는 배치 시점에만 호출, PixelForge 또는 VectorForge(6색×6모양 타일 절차 생성 — 모양은 또렷한 추상 기호), ChipAudio(배치·라인 완성 피치 스택·Qwirkle 특별음), MobileHarness(드래그 스냅·보드 팬/줌·DOM 가드), juice-fx(합법 하이라이트·라인 글로우 스윕·Qwirkle 플래시·점수 롤업), game-ui-hud(점수·손패·풀 잔량·Qwirkle 수·undo), level-designer(AI 기량·시드·챌린지 레벨), localStorage(베스트·데일리·고스트). 코어(라인 빌딩 + 교차 점수 + Qwirkle 보너스)는 충실 재현 가능 — 물리 불필요한 순수 로직이고 라인 검증·점수가 결정론적이다. ⚠️인 이유는 **멀티 인터랙션(상대가 열어둔 6완성 자리를 가로채거나 막는 견제)이 코어 재미의 한 축**이고, 무한 확장 보드의 카메라/입력 처리가 격자 퍼즐보다 까다롭기 때문. 솔로 변환: (1) **휴리스틱 AI 경쟁자 1~3인** — 탐욕 1수(최대 점수 수) + 가끔 6완성 세팅 2수 탐색이면 충분한 상대, (2) **남김 비용 변형** — 'AI가 다음 차례에 6완성할 자리를 열어두면 그 점수만큼 페널티'로 견제 심리를 솔로로 번역, (3) **날짜 시드 데일리** — 같은 풀·draw 순서로 '최고 점수'를 겨루고 이모지 공유, (4) **localStorage 베스트·고스트** 셀프경쟁. 충실 재현: 108타일 구성, 라인 규칙·중복 금지, 교차 동시 득점, Qwirkle +6, 종료 +6 보너스, 손패 교환. 대체/단순화: 실시간 대인 견제·서버 랭킹은 ❌ → AI/데일리/로컬로 축소. 무한 보드는 일정 크기 상한(예: 화면+팬 범위) 또는 부드러운 오토팬/줌으로 모바일 입력을 단순화한다.
**조합 훅:** Tetris/낙하와 결합 — 위에서 색·모양 타일이 떨어지고 같은 속성 라인에 중복 없이 6완성하면 소거되는 'Qwirkle 낙하'(FE-SET-LOGIC+FE-SPATIAL+FE-ESCALATION, 가속은 완만히); Sudoku 연역과 결합 — 격자에 '이 칸은 같은 색/모양 라인 제약'을 깔고 유일 배치를 연역하는 라인 연역 퍼즐(FE-SET-LOGIC+FE-DEDUCTION); arcade-classic 스코어어택 — 주어진 손패·보드에서 '한 수 최대 점수'만 노리는 퍼즐 모드, 시드 공유(FE-OPTIMIZE+FE-JUST-ONE-MORE); Rummikub과 교차 — 라인을 자유 재배열 가능하게 풀어 놓인 타일을 헐어 더 긴 라인을 만드는 하이브리드(FE-SET-LOGIC+FE-REARRANGE); topdown-shooter에 이식 — 처치한 적이 색/모양 타일을 떨구고 하단 보드에서 라인을 완성하면 그 속성 광역기 발동(FE-SET-LOGIC+FE-COMBO).
**IP 안전 메모:** 금지: 'Qwirkle' 게임명·로고·서체, 원작의 고유 6모양 디자인(특유의 원·사각·다이아·클로버·별·꽃 비례와 스타일), 원작 색조합·나무 타일 외형·주머니 구성물 디자인, 패키지 아트. 메카닉(색/모양 라인 빌딩, 같은 속성·중복 금지, 라인당 타일 수 점수, 교차 동시 득점, 6완성 보너스, 손패 6·풀 보충·종료 보너스)은 추상 게임 시스템이라 자유롭게 구현 가능 — 저작권 보호 대상이 아니다. IP-safe 환기: 6모양은 일반 도형 개념만 차용하되 VectorForge로 자체 디자인(원작과 다른 기호 세트), 6색 팔레트도 새로 고른다. 사운드는 ChipAudio 자체 생성. 고유 타이틀(예: 'Linecraft', 'Hexline', 'Sixmatch')을 부여하고 'Qwirkle'은 메카닉 설명 맥락에서만 표기. ip-license-guard 스킬로 최종 점검한다.

## Ganz schön clever / That's Pretty Clever (2018)
**왜 많이 플레이됐나:** Wolfgang Warsch 디자인, Schmidt Spiele 발행. "주사위를 골라(드래프트) 다섯 색 시트에 기입하면, 그 기입이 또 다른 기입·보너스·리롤을 부르는 콤보 체인"이 도파민의 핵심이다. 한 칸을 채우면 다른 색 칸이 열리고 그게 또 다음을 열어 '연쇄 기입'이 줄줄이 터지는 순간이 롤앤라이트(roll-and-write) 장르의 쾌감을 정점으로 끌어올렸다. '내가 고른 주사위보다 낮은 주사위는 은쟁반(silver platter)에 남아 다음 사람이 쓴다'는 규칙이 '내가 가져가는 것 vs 남기는 것'의 드래프트 긴장을 만들고, 1~4인 + 공식 솔로가 모두 성립해 어디서든 켤 수 있다. 2018년 Kennerspiel des Jahres(전문가 올해의 게임) 후보에 올랐고, 디지털 앱(USM/Steam 'That's Pretty Clever')으로도 큰 인기를 끌어 '한 판 더'의 대명사가 됐다.
**장르 / 시점:** 주사위 드래프트 롤앤라이트(dice-drafting roll-and-write) / 정면 2D — 다섯 색 점수 영역이 그려진 시트 한 장 + 주사위 풀/은쟁반을 한 화면에. 스크롤 없음, 정적 레이아웃. '판'이 아니라 '기입 시트'가 상태의 무대다.
**코어 루프:** (활성 차례) 주사위 6개를 굴린다 → 1개를 골라 같은 색 영역에 기입하고, **고른 것보다 낮은 눈의 주사위들은 은쟁반에 치운다**(다시 못 굴림) → 남은 주사위로 최대 3회까지 재굴림·선택 반복(총 3개 기입 또는 굴릴 주사위 소진까지) → (수동 차례) 다른 플레이어들은 은쟁반에 남은 주사위 중 1개를 골라 자기 시트에 기입. 인원수별 라운드(4인=4·3인=5·1~2인=6) 동안 반복 — 본 문서의 솔로 번안 기준은 6라운드 — 각 영역 점수 합이 최종 점수.
**핵심 재미요소:**
- `FE-LUCK-TAME` 운 길들이기 — 주사위 눈은 통제 밖이지만 '그 눈을 어느 색 영역 어느 칸에 쓸지'는 온전히 내 재량이다. 같은 굴림을 받아도 배치 실력이 점수를 가른다. 특히 다른 플레이어와 같은 굴림(은쟁반)을 공유하므로 **모두가 같은 무작위를 받는 구조 = 날짜 시드 데일리 경쟁의 원형**. 우리 엔진은 시드 RNG로 굴림을 생성해 '같은 시드=같은 주사위'를 보장, 데일리 모드의 공정 비교를 만든다.
- `FE-COMBO` 연쇄·콤보 — Ganz schön clever의 심장. 한 칸 기입이 보너스(추가 X·리롤·플러스원·여우)를 주고, 그 보너스가 또 다른 영역을 채워 연쇄가 줄줄이 터진다. '한 수로 다섯 칸이 연달아 채워지는' 순간이 쾌감의 정점. 우리 구현은 기입 시 트리거되는 보너스를 큐에 넣고 `resolveBonusChain()`으로 더 줄 게 없을 때까지 순차 해소(각 단계 tween + ChipAudio 피치 상승)해 연쇄를 청각화한다.
- `FE-DRAFT` 드래프트·시장 선택 — '내가 가져가는 주사위'와 '은쟁반에 남기는 것'(다음 사람/다음 차례에 줄 것)을 동시에 저울질한다. 높은 눈을 가져가면 낮은 눈들이 죄다 은쟁반으로 빠져 남에게 좋은 선택지를 주고, 낮은 눈을 가져가면 내 재굴림 폭이 좁아진다. 이 이중 가치 판단이 매 선택을 무겁게 한다.
- `FE-OPTIMIZE` 최적화 — 점수는 영역 간 곱·연계로 폭증하므로(예: 한 영역 보너스가 다른 영역 배수를 키움) '어떤 순서로 채워 콤보를 최대화할까'의 최적화가 끝없다. 같은 시트라도 기입 순서로 최종 점수가 배로 갈린다. 솔로/데일리에서 '자기 베스트 경신'이 핵심 동기.
- `FE-RISK-REWARD` 위험-보상 — 재굴림 3회 안에서 '지금 이 눈으로 안전하게 채울까, 한 번 더 굴려 더 좋은 눈을 노릴까'의 푸시유어럭. 더 굴렸다 낮은 눈만 남아 은쟁반으로 다 빠지면 그 차례를 손해 본다. 욕심과 안전의 줄다리기가 매 굴림에 긴장을 준다.
- `FE-JUST-ONE-MORE` 한 판 더 — 6라운드 한 판이 5~10분으로 짧고, 최종 점수가 단일 숫자라 '이번엔 더 높이' 하며 즉시 재도전. 콤보 체인이 매번 다르게 터져 같은 시드도 다른 경로를 시도하게 만든다. localStorage 베스트 + 데일리 연속 일수가 갈증을 만든다.
**핵심 메카닉:**
- 주사위·은쟁반: 6개 주사위(흰=조커/와일드, 노랑·파랑·초록·주황·보라 = 각 색 영역 전용). 활성 차례에 1개 선택 후 **고른 눈보다 낮은 눈의 주사위 전부를 은쟁반으로** 치움 → 남은 걸로 재굴림(최대 3선택). 수동 플레이어는 은쟁반 잔여 중 1개 사용. 흰 주사위는 어느 색으로도 기입 가능(조커).
- 다섯 색 영역(각기 다른 기입 규칙·콤보 출처):
  - **노랑:** 4×4 격자에 주사위 눈에 해당하는 칸을 X 표시. 한 행(가로)을 완성하면 행 끝의 즉시 보너스(다른 영역 X·여우 등), 한 열(세로)을 완성하면 열 아래 점수(10/14/16/20)를 동그라미 쳐 게임 종료 시 합산. 대각선 완성은 +1 보너스.
  - **파랑:** 흰+파랑 주사위 합에 해당하는 칸을 격자에 표시 — 채울수록 점수가 가속(채운 칸 수의 누진 점수).
  - **초록:** 왼→오른쪽으로 칸을 건너뛰지 않고 순서대로, 각 칸의 '최소 요구값(≥X)' 이상 눈이어야 다음으로 진행. 오른쪽으로 갈수록 점수↑.
  - **주황:** 왼→오른쪽 순서로 주사위 눈 값을 기입, 일부 칸은 배수(×2·×3)라 눈 값×배수가 점수.
  - **보라:** 엄격히 직전보다 큰 눈만 이어 기입(상승), 단 6을 기입한 다음에는 아무 값이나 다시 시작 가능.
- 보너스/콤보 출처: 영역의 특정 칸·줄 완성이 **여우(Füchse)·리롤·플러스원(+1)·고정 기입(다른 색 영역에 X·지정값을 즉시 기입)** 보너스를 준다. '+1'은 턴 종료 시 6개 주사위 중 1개(이미 쓰인 것 포함)를 추가로 골라 그 값으로 기입하는 추가 주사위 사용권(복수 보유 가능, 같은 주사위는 턴당 1회). 이 보너스가 또 다른 영역을 채워 연쇄(콤보 체인)를 만든다. 보너스 해소는 큐 기반 순차 처리.
- 여우(Fox) 보너스: 게임 종료 시 각 여우는 '내 다섯 영역 중 최저 점수 영역의 점수만큼'을 추가로 준다 — 약한 영역을 끌어올리는 보정 장치라 '여우를 몇 개 모으고 어느 영역을 버릴까'의 전략을 만든다.
- 라운드·점수: 라운드 수는 인원수에 따라 4인=4·3인=5·1~2인=6(활성·수동을 번갈아). 최종 점수 = 다섯 영역 점수 + 여우 보너스 합. 솔로(공식 솔로 규칙)는 활성/수동을 혼자 번갈아 6라운드.
**난이도·진행 곡선:** 외부 레벨 없이 '시드 굴림 + 내 기입 순서'로 매판 다른 경로가 생긴다. 난도는 (a) 솔로 목표 점수 임계(브론즈/실버/골드), (b) AI 경쟁자 기량(탐욕 1수 최대 즉시 점수 vs 콤보 체인 2수 탐색), (c) 데일리 시드(고정 굴림으로 순수 실력 비교)로 조절. 초반 라운드는 영역이 비어 콤보가 짧고, 후반은 영역이 익어 한 기입이 긴 연쇄를 부르는 점증이 자연 발생. level-designer로 '이 시드에서 골드 달성' 같은 퍼즐 챌린지를 만든다. FE-ESCALATION 시간 가속은 넣지 않고(사고형 최적화와 충돌) 압박은 '6라운드 한정'과 '자기 베스트'로만 준다.
**게임필·연출:** 손맛은 주사위를 '톡' 굴려 멈추는 물리감과, 한 칸 기입이 보너스를 줘 다른 칸이 연달아 채워지는 콤보 체인의 시각·청각 연쇄다. 주사위 굴림은 짧은 텀블 애니(또는 절차 굴림) 후 정지, 선택한 주사위는 떠올라 해당 영역으로 날아가 칸에 'X/숫자'가 톡 찍힌다. 보너스가 트리거되면 그 영역이 펄스하며 다음 영역으로 빛이 이어지고(체인 화살표), 콤보 단계마다 ChipAudio 피치가 한 단계씩 상승. 여우 획득은 특별 심볼 팝 + 상위음. 은쟁반으로 빠지는 주사위는 회색 페이드로 '못 쓴다'를 전달. 라운드 종료·신기록은 점수 롤업 + 절제된 컨페티. juice-fx '적게, 정확하게' — 콤보 체인 절정에만 강하게.
**끈끈함(리텐션):** 짧은 루프 + 단일 점수 + '내 기입 순서가 점수를 갈랐다'는 명확한 자기 책임 귀인이 즉시 재도전을 부른다. 콤보 체인이 매번 다르게 터지는 의외성과 '더 긴 연쇄를 짤 수 있었다'는 최적화 미련이 강하다. 날짜 시드 데일리(모두 같은 굴림)는 순수 실력 비교 + 결과 공유로 사회적 끈끈함을 만들고(Wordle 모델), 공식 솔로가 있어 단일플레이 변환 손실이 거의 없다. localStorage 베스트·연속 일수가 장기 동기.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 Phaser 4(물리 미사용 또는 주사위 굴림만 가벼운 연출, 순수 기입 로직), 보드모델은 '다섯 영역 상태 객체 + 주사위 풀 + 은쟁반 + 보너스 큐'(단일 상태원), renderBoard()는 기입/보너스 해소 시점에만 호출, PixelForge 또는 VectorForge(주사위·5색 시트·여우 심볼 절차 생성), ChipAudio(굴림·기입·콤보 피치 스택·여우·신기록 SFX), MobileHarness(주사위 탭 선택·세로 스케일·DOM 가드), juice-fx(주사위 날아감·체인 펄스·여우 팝·점수 롤업), game-ui-hud(영역별 점수·라운드·재굴림 잔여·은쟁반·데일리), level-designer(솔로 목표 임계·AI 기량·시드 챌린지), localStorage(베스트·데일리·연속 일수·고스트). 코어가 단일플레이로 손실 없이 성립 — **공식 솔로 규칙이 존재**하고(활성/수동 번갈아 6회) 시드 RNG로 데일리가 자연스럽다. 충실 재현: 6주사위 + 은쟁반 드래프트, 다섯 영역 기입 규칙, 보너스·여우·리롤·플러스원 콤보 체인, 6라운드, 솔로, 시드 데일리. 멀티의 '수동 플레이어가 은쟁반을 쓰는' 상호작용은 (a) **AI 경쟁자**(은쟁반을 탐욕 선택)로 '내 선택이 남에게 주는 영향'을 재현하거나, (b) **솔로 변형**(은쟁반 잔여를 다음 라운드 내 보너스/페널티로 환산)으로 단일플레이에 번역. 대체/단순화: 실시간 멀티·서버 랭킹은 ❌ → AI/데일리/localStorage 베스트로 축소. 콤보 체인 해소는 큐 기반 순차 tween으로 명확히 보여준다. 단일플레이 웹 기준 사실상 100% 재현.
**조합 훅:** 2048/머지와 결합 — 기입 콤보로 얻은 토큰을 슬라이드 머지해 추가 배수를 만드는 하이브리드(FE-COMBO+FE-CONSTRAINT); Sudoku 데일리와 묶기 — 하루 한 번 같은 시드 굴림으로 '최고 점수'를 겨루고 이모지 공유(FE-LUCK-TAME+FE-JUST-ONE-MORE); endless-runner에 이식 — 질주 중 굴린 주사위를 레인 기입에 써서 부스트·실드 콤보를 터뜨리는 '롤앤런'(FE-LUCK-TAME+FE-TIMING); arcade-classic 스코어어택 — 단판 6라운드 최고 점수 챌린지, 로컬 베스트·시드 공유(FE-OPTIMIZE); Railroad Ink와 교차 — 굴린 주사위를 '경로 그리기 vs 점수 칸 기입' 두 보드에 분배하는 듀얼 롤앤라이트(FE-LUCK-TAME+FE-PACKING).
**IP 안전 메모:** 금지: 'Ganz schön clever'/'That's Pretty Clever' 게임명·로고·서체, 원작 시트의 정확한 다섯 영역 레이아웃·색조·아이콘(여우 일러스트·각 영역의 고유 그래픽), 패키지 아트·구성물 디자인. 메카닉(주사위 드래프트, 은쟁반=낮은 눈 치움, 다섯 색 영역 기입 규칙, 보너스 콤보 체인, 여우=최저 영역 보정, 6라운드, 솔로)은 게임 시스템이라 자유롭게 구현 가능 — 저작권 보호 대상이 아니다. IP-safe 환기: 다섯 영역은 메카닉(격자/누진/상승/배수/엄격상승)만 차용하되 VectorForge/PixelForge로 자체 레이아웃·색·아이콘을 절차 생성, 여우는 자체 마스코트(예: 별/토큰)로 대체. 사운드는 ChipAudio 자체 생성. 고유 타이틀(예: 'Dice & Write', 'Combo Sheet', 'Cleverish')을 부여하고 원작명은 메카닉 설명 맥락에서만 표기. ip-license-guard 스킬로 최종 점검한다.

## Railroad Ink (2018)
**왜 많이 플레이됐나:** "주사위를 굴려 나온 길 조각을 모두가 공유하고, 각자 자기 7×7 보드에 같은 조각을 그려 넣어 출구를 잇는다"는 공유 무작위 + 개인 보드의 롤앤라이트다. 모두가 똑같은 주사위 결과를 받지만 '어디에 그릴지'는 각자 달라, 같은 운에서 배치 실력이 점수를 가르는 FE-LUCK-TAME의 교과서다. 폴리오미노처럼 길 조각을 빈틈없이 끼워 출구를 최대한 잇고 끊긴 끝(에러)을 줄이는 패킹 최적화가 깊고, 인터랙션이 0(서로의 보드를 건드리지 않음)이라 **완전한 솔로가 자연 성립**한다 — 1인이든 6인이든 규칙이 동일하다. 작고 빠르고 어디서나 켜지는 데다 색깔별 에디션·확장 주사위로 변주가 풍부해 롤앤라이트 붐의 대표작이 됐다(2018, Horrible Guild/CMON).
**장르 / 시점:** 공유 주사위 롤앤라이트 + 경로 빌딩(roll-and-write route drawing) / 정면에서 내려다보는 2D 평면 — 7×7 격자 보드와 12개 출구(가장자리), 주사위 풀을 한 화면에. 스크롤 없음, 정적 레이아웃. '판'은 내 개인 보드 하나.
**코어 루프:** 매 라운드 공용 주사위(4개)를 굴린다 → 나온 4개의 길 조각(도로/철도/역 등)을 **모두** 내 7×7 보드에 그려 넣되, 기존 길과 연결되게(또는 출구에서 시작) 배치한다(연결 안 되게는 못 둠) → 라운드당 특수 조각 1개를 추가로 쓸 수 있음(게임당 최대 3개) → 7라운드 후 종료, 출구 네트워크·최장 경로·중앙·에러를 합산해 점수.
**핵심 재미요소:**
- `FE-LUCK-TAME` 운 길들이기 — 주사위 4조각은 통제 밖이지만 '내 보드 어디에 어떻게 놓을지'는 온전히 내 재량이다. 모두가 같은 4조각을 받으므로(공유 무작위) 순수하게 배치 실력이 점수를 가른다 — **날짜 시드 데일리 경쟁의 완벽한 원형**(모두 같은 7라운드 굴림). 우리 엔진은 시드 RNG로 라운드별 주사위를 생성해 데일리의 공정 비교를 보장한다.
- `FE-PACKING` 패킹·빈틈 경제 — 길 조각을 7×7 한정 공간에 빈틈없이 끼워 출구를 잇는다. 끊긴 길 끝(error)은 곧 감점이라 '낭비 칸 = 실점'의 공간 경제가 핵심. 보드가 채워질수록 커지는 시각적 완성감과, 막판 조각을 어디 끼워 에러를 0으로 만들지의 긴장이 패킹 퍼즐의 쾌감을 만든다.
- `FE-OPTIMIZE` 최적화 — 단순히 다 그리는 걸 넘어 '출구를 최대한 한 네트워크로 묶고(연결 출구 많을수록 점수 급증), 최장 철도·도로를 늘리고, 중앙 9칸을 채우고, 에러를 0으로'의 다중 목표를 동시에 최적화한다. 같은 굴림이라도 배치로 점수가 크게 갈려 자기 베스트 경신 동기가 끝없다.
- `FE-PLANNING` 선계획·멀티스텝 — 7라운드 동안 들어올 조각은 모르지만, 지금 한 조각을 어디 놓으면 다음 출구 연결·최장 경로 확장에 유리한지 몇 수 앞을 내다본다. 도로와 철도는 '역'에서만 연결되므로 어디에 역을 두어 두 망을 잇느냐가 장기 설계의 핵심. 되돌릴 수 없는 잉크라(그린 건 못 지움) 한 수가 무겁다.
- `FE-AHA` 통찰·아하 — 흩어진 길 조각들이 막판 한 조각으로 두 출구 네트워크를 하나로 잇거나 끊긴 끝을 모두 메우는 '딱 맞는 배치'를 발견하는 순간의 쾌감. 애매하던 조각이 의외의 칸에서 큰 네트워크를 완성하는 발견감.
- `FE-JUST-ONE-MORE` 한 판 더 — 7라운드 한 판이 10~15분으로 짧고 최종 점수가 단일 숫자라 '이번엔 더 높이' 즉시 재도전. 매판 다른 굴림(또는 같은 데일리 시드의 더 나은 경로)이 반복을 부른다. localStorage 베스트·연속 일수가 갈증을 만든다.
**핵심 메카닉:**
- 보드·출구: 7×7 격자(49칸), 가장자리에 **12개 출구**(도로 출구·철도 출구가 정해진 위치에 배치). 중앙 3×3(9칸)은 채우면 가산점.
- 주사위·그리기: 공용 **4개 주사위** — 3개는 도로/철도 기본 조각 6종을, 1개는 역(도로↔철도 연결)·오버패스 등 특수 연결 3종을 보여준다. 라운드마다 나온 4조각을 모두 보드에 그림(회전·반전 허용). 배치 규칙: 새 조각의 길 끝이 기존 길/출구와 이어져야 함(허공에 고립 배치 금지), 도로는 도로끼리·철도는 철도끼리 연결되며 역에서만 두 망이 교차.
- 특수 조각: 6종의 특수 route 조각이 시트에 있고, **라운드당 1개**까지·**게임 전체 3개**까지 사용 가능(쓴 칸 표시). 까다로운 연결을 메우는 와일드 역할.
- 라운드 수: **7라운드**(기본판). 확장 주사위 사용 시 6라운드.
- 점수 체계(종료 시 합산):
  - **출구 네트워크:** 같은 연결망에 묶인 출구 수에 따라 점수 — 2개=4, 3=8, 4=12, 5=16, 6=20, 7=24, 8=28, 9=32, 10=36, 11=40, 12=45점(많이 묶을수록 급증).
  - **최장 철도 / 최장 도로:** 각 망의 가장 긴 연속 경로 칸 수 × 1점(각각 따로).
  - **중앙 9칸:** 무언가 그린 중앙 칸당 +1.
  - **에러:** 다른 길/가장자리(출구·단순 모서리)와 연결되지 않은 길 끝마다 −1점.
- 보드 모델: 7×7 셀 배열, 각 셀은 '도로/철도 연결 방향 비트마스크'(상·하·좌·우 × 도로/철도). 출구 연결·최장 경로·네트워크는 그래프 탐색(BFS/Union-Find)으로 순수 계산. 에러는 연결 안 된 끝 카운트.
**난이도·진행 곡선:** 외부 레벨 없이 '시드 굴림 + 내 배치'로 매판 다른 퍼즐이 생긴다. 초반 라운드는 빈 보드라 배치가 자유롭지만, 후반은 칸이 차며 '에러 없이 끼울 자리'가 줄어 패킹 압박이 자연 점증(FE-PACKING 절정). 난도 조절: (a) AI 경쟁자(같은 굴림을 탐욕 배치하는 고스트 — 점수 비교 상대), (b) 데일리 시드(고정 굴림 순수 실력 비교), (c) 특수 주사위 변형(확장처럼 추가 점수 규칙). level-designer로 '이 7라운드 시드에서 N점 이상' 챌린지를 만든다. 시간 가속은 넣지 않고 압박은 '7라운드 한정 + 에러 페널티 + 자기 베스트'로만 준다.
**게임필·연출:** 손맛은 길 조각을 격자에 '딱' 스냅해 그릴 때의 정렬감과, 끊겼던 두 출구가 한 조각으로 '이어지는' 연결의 만족이다. 주사위 굴림 후 4조각이 트레이에 뜨고, 조각을 드래그하면 회전·반전 가능, 합법 칸은 초록 하이라이트(에러 날 끝은 적색 경고), 놓는 순간 길이 잉크처럼 번지는 드로우 애니. 출구가 새 네트워크에 합류하면 그 망 전체가 글로우 펄스 + 점수 프리뷰 갱신, 라운드 종료 시 현재 점수 롤업. 에러 끝은 상시 작은 적색 마커로 '여기 −1' 경고. 종료 화면은 네트워크별 점수·최장 경로 하이라이트를 순차 재생. ChipAudio: 그리기 'ink', 출구 연결 'coin', 신기록 팡파르. juice-fx '적게, 정확하게' — 큰 네트워크 완성·종료 정산에만 강하게.
**끈끈함(리텐션):** 짧은 루프 + 단일 점수 + '내 배치가 점수를 갈랐다'(같은 굴림 공유)는 명확한 공정성 귀인이 즉시 재도전을 부른다. 패킹 완성의 시각적 만족과 '에러 0·더 큰 네트워크를 만들 수 있었다'는 최적화 미련이 강하다. 공유 무작위 = 날짜 시드 데일리의 완벽한 토양이라 '모두 같은 굴림' 비교 + 결과 공유로 사회적 끈끈함을 만든다(Wordle 모델). **완전 솔로가 규칙 그대로 성립**해 단일플레이 변환 손실이 0이다. localStorage 베스트·연속 일수가 장기 동기.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 Phaser 4(물리 미사용, 격자 스냅 드래그 + 순수 그래프 로직), 보드모델은 '7×7 비트마스크 셀 배열 + 12출구 + 주사위 트레이 + 특수 잔여'(단일 상태원), renderBoard()는 그리기 시점에만 호출, PixelForge 또는 VectorForge(도로/철도/역 조각·출구·보드 절차 생성), ChipAudio(굴림·그리기·연결·신기록 SFX), MobileHarness(드래그·회전 탭·세로 스케일·DOM 가드), juice-fx(잉크 드로우·네트워크 글로우·에러 마커·점수 롤업), game-ui-hud(라운드·현재 점수 프리뷰·특수 잔여·에러 수·데일리), level-designer(AI 기량·시드·챌린지), localStorage(베스트·데일리·연속 일수·고스트). 코어가 단일플레이로 손실 없이 성립 — **인터랙션이 0이라 솔로가 규칙 그대로** 자연스럽고(서로 보드 안 건드림), 시드 RNG로 데일리가 완벽하다. 충실 재현: 7×7 보드·12출구, 4주사위 공유 굴림·전부 그리기, 도로/철도/역 연결 규칙, 특수 조각 3개 제한, 7라운드, 네트워크·최장경로·중앙·에러 점수표, 시드 데일리. 멀티는 '동시에 같은 굴림으로 각자 그리고 점수 비교'일 뿐이라 (a) **AI 경쟁자/고스트**(같은 굴림을 탐욕 배치한 점수와 비교)로 경쟁감을 재현, (b) 순수 솔로(자기 베스트)로도 완결. 대체/단순화: 실시간 멀티·서버 랭킹은 ❌ → AI 고스트/데일리/localStorage 베스트로 축소. 네트워크·최장경로 계산은 Union-Find/BFS 1회로 결정론. 조각 회전·반전 입력은 탭/롱프레스로 모바일 단순화. 단일플레이 웹 기준 100% 재현.
**조합 훅:** Flow Free 경로 잇기와 결합 — 주사위 조각 대신 자유 드래그 경로로 출구를 잇되 에러 0·최소 교차로 perfect를 노리는 하이브리드(FE-PACKING+FE-ELEGANCE); Sudoku 데일리와 묶기 — 하루 한 번 같은 7라운드 시드로 '최고 네트워크 점수'를 겨루고 격자 이모지 공유(FE-LUCK-TAME+FE-JUST-ONE-MORE); Tetris/폴리오미노와 결합 — 떨어지는 길 조각을 빈틈없이 쌓아 출구를 잇는 낙하형 패킹(FE-PACKING+FE-SPATIAL, 가속은 완만히); arcade-classic 스코어어택 — 단판 7라운드 최고 점수 챌린지, 로컬 베스트·시드 공유(FE-OPTIMIZE); Ganz schön clever와 교차 — 굴린 주사위를 '경로 그리기 vs 점수 시트 기입' 두 보드에 분배하는 듀얼 롤앤라이트(FE-LUCK-TAME+FE-COMBO).
