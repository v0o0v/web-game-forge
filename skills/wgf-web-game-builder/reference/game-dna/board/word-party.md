# 게임 DNA · 보드게임 아틀라스 — 단어 · 파티 · 연상

> WebGameForge 게임 DNA **보드게임 아틀라스**(컴팩트 2티어)의 클러스터 파일이다 — 심화 35종과 달리 게임당 핵심만 압축한 카탈로그(총 100종 중 일부). 아래 게임들의 **메카닉·재미요소만** 분석한다(저작물 미사용). 물리 보드게임을 **디지털 단일플레이 웹 게임으로 번안하는 관점**으로 적는다. 솔로 단어 퍼즐(Scrabble·Boggle·Bananagrams)은 사전 데이터만 갖추면 웹 솔로의 모범생이지만, 파티 소통류(Codenames·Dixit·Just One 등)는 다인 사회성이 코어라 솔직하게 ❌ 판정하고 추출 요소(연상 단서의 적정 모호성·중복 소거·스펙트럼 판정)를 명시한다. 색인은 [INDEX.md](./INDEX.md), 심화 분석(퍼즐 35종)은 [../puzzle/INDEX.md](../puzzle/INDEX.md), 재미요소 사전은 [../fun-elements.md](../fun-elements.md), 전역 색인은 [../INDEX.md](../INDEX.md).

## 공통 번안 패턴

- **사전 데이터가 보드모델의 절반:** 단어 퍼즐 셋(Scrabble·Boggle·Bananagrams)의 핵심 의존성은 단어 사전이다. 영단어는 CC0/퍼블릭 도메인 워드리스트(ENABLE·SCOWL 계열 오픈 소스), 한글은 오픈 라이선스 사전 데이터를 자모 분해(초·중·종성) 전처리해 쓴다. Trie 또는 Set으로 빌드해 정적 번들에 포함 — 서버 없이 즉시 검증되고, 출처·라이선스는 ip-license-guard 단계에서 고지한다.
- **무효 단어의 공정 귀인:** 판정은 즉시, 어느 경로/타일이 문제인지 시각 피드백(juice-fx 타일 흔들림·붉은 점등)으로 — `FE-FAIRNESS`. 플레이어가 아는 단어가 거절되는 경험이 최악의 신뢰 손상이므로 사전 커버리지 자체가 품질이다.
- **파티 소통 코어 → 저작 태그 데이터:** 인간 마음이론(내 단서를 상대가 어떻게 해석할까)은 범위 밖. 단서·카드에 사전 저작된 의미 태그·연상 데이터를 부여하고 AI가 태그 겹침 휴리스틱으로 출제하게 하면 '왜 저 단서를 줬나'의 연역만 보존된다 — 진짜 병목은 코드가 아니라 태그 콘텐츠 저작량이다.
- **타이머 = 솔로 표준 다이얼:** Boggle의 제한 시간·Bananagrams의 속도전처럼 시간 자체가 상대인 게임은 솔로 무손실. 타임어택/점수어택 2모드를 두고 level-designer가 시간·격자 크기·타일 유입 속도로 난도를 조절한다.
- **날짜 시드 데일리의 최적 장르:** 같은 격자(Boggle)·같은 타일 순서(Scrabble 랙·Bananagrams)를 날짜 시드로 고정 — 단어 데일리는 이모지 결과 공유 리텐션의 검증된 왕도다. localStorage 베스트·연속 출석 기록.
- **입력:** 격자 스와이프 드래그(Boggle 경로 잇기), 타일 드래그&스냅(Scrabble·Bananagrams 배치), 오배치 스냅백 — MobileHarness 터치 우선, 다이얼류(Wavelength 추출)는 원형 드래그 입력.

### Scrabble (1948)

**코어:** 7타일 랙에서 글자를 꺼내 보드 위 기존 단어와 반드시 교차·연결되게 새 단어를 놓고, 글자 값 × 배수 칸으로 점수를 얻은 뒤 둔 만큼 가방에서 보충한다. 타일이 소진될 때까지 점수 합계를 겨루는 크로스워드 만들기의 원형.

**재미요소:** `FE-OPTIMIZE` — 글자 값·배수 칸·빙고를 곱연산으로 극대화하는 한 수 찾기. `FE-PLANNING` — 고배수 칸을 상대에게 열어주지 않는 수비와 랙 관리(모음·자음 균형)의 수읽기. `FE-MASTERY` — 어휘·짧은 단어 레퍼토리·고가치 글자 처리로 끝없이 오르는 숙련 천장. `FE-CONSTRAINT` — 랙 7타일과 '기존 배치에 이어야 함' 제약이 모든 수를 퍼즐로 만듦.

**핵심 메카닉:**
- 타일 100개(글자 98 + 블랭크 2), 글자별 점수·수량이 비대칭 — 흔한 글자는 싸고 많으며 희소 글자는 비싸다.
- 랙은 항상 7타일 유지(둔 만큼 보충). 새 단어는 기존 타일과 교차하거나 인접해 유효 단어만 만들어야 함.
- 배수 칸 4종: 글자 2배·3배 / 단어 2배·3배 — 단어 배수는 중첩 곱연산, 각 칸 보너스는 최초 사용 1회만.
- 빙고: 한 턴에 랙 7타일을 전부 사용하면 +50점.
- 종료: 가방 소진 후 한 명이 랙을 비우면(잔여 랙은 감점) 또는 전원 연속 패스.

**웹 번안:** ✅ `puzzle-game`. 보드모델 = 15x15 격자 + 랙 + 가방 카운트가 단일 상태 소스. AI 상대는 '배치 가능 수 열거 → 탐욕 1수 점수 평가'로 충분하고, 둔 수의 점수 내역을 보여주면 '수가 읽히는 AI'가 된다. 사전은 오픈 소스 워드리스트(영어 퍼블릭 도메인 계열, 한글은 오픈 라이선스 사전 + 자모 조합 검증)를 번들. 솔로 변형: AI 1:1 외에 '같은 랙 순서 시드로 N턴 최고점' 데일리가 잘 맞는다.

**조합 훅:** Tetris(FE-SPATIAL)와 교배 — 낙하하는 글자 타일로 가로·세로 단어를 완성해 지우는 워드폴(FE-COMBO+FE-ESCALATION); Rummikub(FE-REARRANGE)과 교배 — 이미 놓인 단어의 글자를 떼어 재배열할 수 있는 재구성 크로스워드(FE-REARRANGE+FE-AHA).

**IP 주의:** 'Scrabble' 상표(Hasbro/Mattel)·보드 배색과 배수 칸 표기 같은 트레이드 드레스는 금지 — 글자 값·배수 칸·빙고 보너스 같은 메카닉·규칙은 저작권 보호 대상이 아니다.

### Boggle (1972)

**코어:** 글자 주사위 16개를 흔들어 4x4 격자를 만들고, 제한 시간(고전 룰 3분) 동안 인접 칸(대각 포함)을 한 붓으로 이어 만들 수 있는 단어를 최대한 많이 찾아 적는다. 시간이 끝나면 길이별 점수로 합산.

**재미요소:** `FE-AHA` — 무작위 글자판에서 단어가 갑자기 '튀어나와 보이는' 발견의 순간이 코어 보상. `FE-FLOW` — 시선이 격자를 훑는 끊김 없는 스캔 몰입. `FE-MASTERY` — 접두·접미 패턴, 복수형·파생형 훑기 같은 탐색 레퍼토리가 기록을 끌어올림. `FE-CONSTRAINT` — 시간 제한과 '같은 주사위 재사용 금지' 경로 규칙.

**핵심 메카닉:**
- 4x4 격자, 단어는 인접 칸(가로·세로·대각) 연쇄로만, 한 단어 안에서 같은 칸 재사용 금지.
- 3글자 이상만 유효. 길이별 점수: 3~4글자 1점 / 5글자 2점 / 6글자 3점 / 7글자 5점 / 8글자 이상 11점.
- 다인전에서는 시간 종료 후 서로 비교해 중복 단어는 전원 0점 — 솔로 번안에서는 제거되는 규칙.
- 매판 주사위를 흔들어 격자가 재생성 — 판마다 단어 분포가 다른 무작위 변주.

**웹 번안:** ✅ `puzzle-game`. 격자 보드모델 + 스와이프 경로 입력(지나간 칸 하이라이트)이 전부라 구현이 가볍다. 사전은 오픈 소스 워드리스트(CC0/퍼블릭 도메인 계열, 한글은 오픈 사전 + 자모 처리). 솔로 점수화는 '격자에서 찾을 수 있는 총점 대비 달성률'을 사전 솔버로 미리 계산해 별점으로(FE-OPTIMIZE) — 시드 격자의 가능 단어 수를 검수해 저품질 판을 걸러낸다. 날짜 시드 같은 격자 데일리 + localStorage 베스트.

**조합 훅:** Bejeweled(FE-COMBO)와 교배 — 완성한 단어 경로의 타일이 터지고 새 글자가 낙하하는 무한 워드 매치(FE-FLOW+FE-JUST-ONE-MORE); topdown-shooter 런 구조와 교배 — 단어 길이가 공격력이 되는 워드 배틀 로그라이트(FE-POWER-FANTASY+FE-MASTERY).

**IP 주의:** 'Boggle' 상표(Hasbro)·주사위 글자면 구성의 그대로 복제는 피한다 — 격자 인접 경로 단어 탐색 메카닉 자체는 자유.

### Bananagrams (2006)

**코어:** 보드도 턴도 없이, 각자 받은 타일로 자기만의 크로스워드 격자를 실시간으로 짓는다. 손 타일을 다 쓰면 "Peel!"을 외쳐 전원이 더미에서 1장씩 강제로 가져가고, 더미가 인원수보다 적어진 뒤 먼저 타일을 소진한 사람이 최종 콜로 승리(전 단어 유효해야 함).

**재미요소:** `FE-REARRANGE` — 새 타일을 끼우기 위해 이미 만든 단어를 허물고 격자를 통째로 재조립하는 것이 코어 그 자체. `FE-FLOW` — 턴 대기가 없는 실시간 손놀림. `FE-ESCALATION` — Peel이 올 때마다 처리 못 한 타일이 쌓이는 점증 압박. `FE-TENSION` — 종반 더미가 줄어들수록 '다음 Peel이 마지막일까'의 긴장.

**핵심 메카닉:**
- 타일 144개, 인원에 따라 11~21장으로 시작(타일 전부 뒷면 더미 = 'Bunch').
- 자기 격자는 언제든 전면 재배열 가능 — 게임명부터 애너그램의 말장난.
- Peel: 누군가 손 타일 소진 시 전원이 1장씩 추가로 가져감(앞선 자가 전원을 압박하는 역설계).
- Dump: 막힌 타일 1장을 더미에 반납하고 3장을 가져오는 교환 — 패널티이자 탈출구.
- 더미가 인원수 미만일 때 먼저 소진한 사람이 최종 콜 — 무효 단어가 있으면 실격.

**웹 번안:** ✅ `puzzle-game` — FE-REARRANGE 교차(같은 재구성 계열인 Rummikub의 단어판 형제). 솔로 변환은 깔끔하다: 시스템이 일정 간격으로 Peel 틱(타일 자동 유입)을 넣으면 '시간이 상대'가 되고, 정해진 타일 풀을 다 소화한 시간이 기록이 된다. 타일 드래그 + 격자 스냅, 연결성·사전 유효성을 실시간 색으로 표시(juice-fx). Dump는 리스크 버튼으로 유지. 날짜 시드 같은 타일 순서 데일리 + localStorage 베스트 타임.

**조합 훅:** Tetris(FE-ESCALATION)와 교배 — Peel 틱을 낙하 가속으로 치환한 실시간 크로스워드 생존(FE-FLOW+FE-TENSION); Patchwork(FE-PACKING)와 교배 — 한정된 격자 안에 크로스워드를 빈틈없이 패킹하는 공간 제약 변형(FE-PACKING+FE-REARRANGE).

**IP 주의:** 'Bananagrams' 상표·바나나 파우치 트레이드 드레스·'Peel/Dump/Bananas' 고유 콜 명칭은 금지(자체 명칭 부여) — 실시간 개인 크로스워드·강제 타일 유입·교환 메카닉은 자유.

### Codenames (2015)

**코어:** 5x5로 깔린 단어 카드 25장 중 어느 것이 아군 요원인지 스파이마스터만 안다. 스파이마스터는 '한 단어 + 숫자' 단서 하나로 여러 단어를 동시에 암시하고, 팀은 한 장씩 지목 — 암살자 카드를 찍으면 즉시 패배. Spiel des Jahres 2016.

**재미요소:** `FE-AHA` — 단서 하나가 서로 무관해 보이던 단어들을 한 줄로 꿰는 연상 통찰. `FE-RISK-REWARD` — '하나 더 찍을까'의 푸시유어럭(틀리면 턴 상납, 최악은 암살자). `FE-TENSION` — 25장 중 단 한 장의 암살자가 모든 추측에 드리우는 일발 긴장. `FE-SOCIAL` — 단서를 사이에 둔 팀 단위 마음 읽기.

**핵심 메카닉:**
- 키 카드가 25칸을 아군/적군/구경꾼/암살자로 비밀 배정 — 스파이마스터만 열람.
- 단서는 '단어 1개 + 숫자 1개'만 허용, 판 위에 보이는 단어는 단서로 금지.
- 팀은 숫자보다 1회 더까지 추측 가능, 틀린 카드를 찍으면 턴 종료(적 요원이면 적이 이득).
- 아군 요원 전원 식별로 승리, 암살자 지목은 즉시 패배.

**웹 번안:** ❌ — 코어는 단서 작성과 해석 양쪽 모두 인간 마음이론이라 범위 밖(서버·NLP 없는 환경에서 자유 연상 단서를 채점할 수 없음). 추출할 재미요소: **한 단서 다수 지목**(`FE-AHA` — 저작된 '단서 → 정답 단어 세트' 데이터로 "이 단서가 가리키는 N개를 찾아라" 데일리 연상 퍼즐이 성립), **추가 추측의 푸시유어럭**(`FE-RISK-REWARD` — 확신 없는 한 장을 더 여는 선택 구조), **치명 1장 설계**(`FE-TENSION` — 오답 중 단 하나만 즉사급인 비대칭 페널티는 어떤 지목 퍼즐에도 이식 가능).

**조합 훅:** Minesweeper(FE-DEDUCTION)와 교배 — 단서 숫자들로 암살자 위치를 소거해 가는 연상 지뢰밭(FE-DEDUCTION+FE-TENSION); Wordle(FE-SOCIAL)과 교배 — 저작 단서 데일리에 시도 수·오답 패턴 이모지 공유(FE-AHA+FE-SOCIAL).

**IP 주의:** 'Codenames' 상표(CGE)·요원 카드 일러스트는 금지 — '단어+숫자 단서'·키 카드·암살자 메카닉은 자유.

### Just One (2018)

**코어:** 한 명이 눈을 가린 사이(카드를 못 보는 추측자), 나머지 전원이 제시어에 대한 한 단어 단서를 비공개로 쓴다. 공개 전 단서끼리 비교해 **중복(동일·동계열) 단서는 전부 소거** — 추측자는 남은 단서만 보고 1회 추측한다. 카드 13장으로 한 게임, 맞힌 장 수가 팀 점수. Spiel des Jahres 2019.

**재미요소:** `FE-EXPRESSION` — 단 한 단어에 나만의 연상 각도를 담는 압축 창의. `FE-RISK-REWARD` — 뻔한 단서는 중복으로 지워지고 너무 튀는 단서는 무용지물 — '적정 독창성'의 저울질이 코어. `FE-SOCIAL` — 소거 공개 순간 "다 '사과' 썼냐!"의 탄식과 폭소. `FE-AHA` — 부분 단서 2~3개를 종합해 제시어가 떠오르는 순간.

**핵심 메카닉:**
- 전원 동시·비공개 단서 작성(한 단어), 의논 금지.
- 동일 단서·동계열 변형은 추측자가 보기 전에 전부 제거 — 살아남은 단서만 정보.
- 추측은 1회, 패스 가능. 오답은 페널티(통상 카드 추가 소모)로 정답보다 비싸다.
- 13라운드 협력 점수 — 만점 추구형 스코어 어택 구조.

**웹 번안:** ❌ — '여러 인간이 동시에 같은 연상을 떠올린다'는 사실 자체가 메카닉이라 솔로 범위 밖. 추출할 재미요소: **중복 소거 스코어링**(`FE-RISK-REWARD` — 제시어별 연상 빈도표를 저작해 두면 '남들이 떠올릴 답을 피하면서 유효해야 한다'는 역발상 채점이 솔로로 성립 — 흔한 답일수록 0점), **부분 단서 종합 추리**(`FE-DEDUCTION` — 단서 일부가 가려진 상태에서 제시어를 맞히는 추측자 측 퍼즐), **소거 리빌 연출**(지워지는 단서를 한 장씩 보여주는 공개 연출 패턴).

**조합 훅:** Wordle(FE-DEDUCTION)과 교배 — '가장 덜 흔하면서 통하는 연상어'를 노리는 빈도표 채점 데일리(FE-RISK-REWARD+FE-EXPRESSION); Ganz schön clever(FE-COMBO)와 교배 — 연속 정답이 보너스를 연쇄시키는 13라운드 콤보 스코어 어택.

**IP 주의:** 'Just One' 상표(Repos Production)·이젤 컴포넌트 디자인은 금지 — 동시 단서 작성·중복 소거 규칙은 자유.

### Dixit (2008)

**코어:** 이야기꾼이 자기 손의 초현실 그림 카드 1장에 모호한 단서(단어·문장·소리 무엇이든)를 붙이면, 전원이 자기 손에서 그 단서에 어울리는 카드를 몰래 내고, 섞어 공개한 뒤 이야기꾼의 카드를 투표로 찾는다. **전원이 맞혀도, 아무도 못 맞혀도 이야기꾼은 0점** — 일부만 맞힐 만큼 모호해야 득점. Spiel des Jahres 2010.

**재미요소:** `FE-EXPRESSION` — 그림 한 장에 시적 단서를 붙이는 창작 그 자체. `FE-NARRATIVE` — 초현실 이미지와 연상이 만드는 몽환적 분위기가 게임의 절반. `FE-RISK-REWARD` — '너무 쉬워도 0점, 너무 어려워도 0점'의 적정 모호성 저울이 메카닉의 심장. `FE-SOCIAL` — '이 사람이라면 이 단서를 이렇게 풀었겠지'라는 사람 읽기.

**핵심 메카닉:**
- 이야기꾼 단서 → 전원 미끼 카드 제출 → 셔플 공개 → 이야기꾼 카드 투표(자기 카드 투표 불가).
- 점수 곡선: 전원 적중 또는 0명 적중 → 이야기꾼 0점·나머지 2점 / 일부 적중 → 이야기꾼·적중자 3점.
- 미끼 보너스: 내 카드에 표를 받으면 표당 +1 — 남의 단서에 어울리는 카드를 내는 2차 심리전.
- 손패 보충으로 순환, 목표 점수 도달까지.

**웹 번안:** ❌ — 인간의 연상 창의성과 '그 사람다움'을 읽는 사회적 코어라 범위 밖. 추출할 재미요소: **적정 모호성 점수 곡선**(`FE-RISK-REWARD` — '절반만 맞힐 난도를 노려라'는 채점 곡선은 단서 난도 베팅·힌트 설계 등 다른 시스템에 이식 가능한 명곡선), **미끼 제출**(`FE-BLUFF` — 남의 단서에 묻어가 표를 훔치는 기대값 판단은 AI 투표자 상대 확률 퍼즐로 부분 추출 가능), **그림 연상 데일리**(`FE-AHA` — 이미지에 의미 태그를 저작하면 '단서와 가장 맞는 그림 고르기' 퀴즈가 성립).

**조합 훅:** story-architect + vector-graphics 연계 — 절차 생성 초현실 이미지에 저작 태그를 붙인 연상 추리 데일리(FE-NARRATIVE+FE-AHA); level-architect 차용 — '일부만 성공할 난도가 최고 보상'이라는 Dixit 곡선을 난도·보상 설계 원리로 이식(FE-RISK-REWARD).

**IP 주의:** 'Dixit' 상표(Libellud)·카드 일러스트(이 게임은 그림이 표현의 핵심이라 특히 주의)·토끼 말 조형은 금지 — 단서 투표·점수 곡선 메카닉은 자유.

### Wavelength (2019)

**코어:** '뜨겁다↔차갑다' 같은 양극 개념 카드 위에 숨은 과녁이 무작위 위치에 걸리고, 과녁을 본 사이킥이 그 위치에 해당하는 단서 하나를 말한 뒤 침묵한다. 팀은 다이얼을 돌려 위치를 추측 — 과녁 중심에 가까울수록 고득점(중심 4점, 빗나갈수록 3·2점).

**재미요소:** `FE-EXPRESSION` — 연속 스펙트럼 위 한 점을 찌르는 단서 짓기('미지근한 커피' 같은). `FE-TENSION` — 다이얼을 확정하고 가림판을 여는 공개의 순간. `FE-SOCIAL` — 정확히 4점 칸에 꽂혔을 때의 '우리 통했다' 일체감. `FE-AHA` — 단서 하나로 타인의 감각 보정을 역산하는 통찰.

**핵심 메카닉:**
- 과녁은 5구간 동심 띠(중심 4점·양옆 3점·바깥 2점), 매 라운드 무작위 위치.
- 사이킥은 단서 제시 후 일절 추가 발언·표정 금지.
- 상대팀은 정답이 추측보다 왼쪽/오른쪽인지 베팅해 적중 시 1점 — 단, 4점 명중이면 무효.
- 양극 개념 카드 풀이 콘텐츠의 전부 — 카드가 곧 리플레이성.

**웹 번안:** ❌ — 코어는 타인의 감각 척도(calibration)를 읽는 사회적 동기화라 범위 밖. 추출할 재미요소: **스펙트럼 판정 입력**(다이얼 UI는 그 자체로 훌륭한 연속값 입력 장치 — '이 단서는 스펙트럼 어디쯤?'을 저작 기준값으로 채점하는 추정 데일리 퀴즈가 솔로 성립, `FE-AHA`), **근접 보상 곡선**(`FE-RISK-REWARD` — 정답/오답 이분법이 아니라 가까울수록 점수인 연속 채점은 모든 추정 게임에 이식 가능), **공개 모먼트 연출**(`FE-TENSION` — 가림판이 열리며 바늘과 과녁이 드러나는 리빌이 긴장의 전부).

**조합 훅:** juice-fx 집중 투자 — 다이얼 드래그 햅틱감·슬로모 리빌·과녁 점등이 손맛의 본체(FE-JUICE+FE-TENSION); Stack(FE-TIMING)과 교배 — 스펙트럼 위를 왕복하는 바늘을 타이밍 정지로 과녁에 맞히는 아케이드 변형(FE-TIMING+FE-TENSION).

**IP 주의:** 'Wavelength' 상표(CMYK)·회전 가림판 장치의 고유 디자인은 금지 — 양극 스펙트럼·숨은 과녁·근접 점수 메카닉은 자유.

### Telestrations (2009)

**코어:** 전원이 스케치북에 제시어를 받아 그림으로 그리고, 옆 사람에게 넘기면 그 그림만 보고 글로 추측하고, 다음 사람은 그 글을 다시 그림으로 — 그리기와 추측을 번갈아 책이 한 바퀴 돌면, 원형 제시어가 어떻게 변질됐는지 전원 공개한다. 전언(텔레폰) 게임 × 픽셔너리.

**재미요소:** `FE-SURPRISE` — '고래'가 '우산 쓴 감자'로 끝나는 변질의 공개가 보상의 전부. `FE-EMERGENCE` — 한 칸의 작은 오해가 체인을 타며 증폭되는 창발. `FE-SOCIAL` — 공개 라운드를 함께 넘기며 터지는 폭소(점수는 사실상 장식). `FE-EXPRESSION` — 그림 실력이 없을수록 오히려 재밌어지는 무해한 자기표현.

**핵심 메카닉:**
- 각자 자기 책으로 시작, 매 단계 '그림 → 글 추측 → 그림'을 교대하며 전원이 동시에 옆으로 전달.
- 그림에 글자·숫자 표기 금지 — 변질을 보장하는 핵심 제약.
- 책이 주인에게 돌아오면 첫 장부터 차례로 공개 — 변질 과정 자체가 콘텐츠.
- 점수 규칙이 있으나 가볍게 취급 — 웃음이 실질 보상인 파티 구조.

**웹 번안:** ❌ — 다인의 그리기·해석 체인 그 자체가 코어이고, 자유 그림 채점은 서버·ML 없이 불가라 범위 밖. 추출할 재미요소: **변질 체인 역추리**(`FE-DEDUCTION`+`FE-SURPRISE` — '단어→연상→연상…'으로 저작된 변질 체인의 끝만 보고 원형을 거슬러 맞히는 퍼즐은 솔로 성립), **점진 리빌 연출**(`FE-TENSION` — 체인을 한 장씩 까는 공개 리듬은 결과 화면 연출로 이식), **의도된 정보 손실**(`FE-EMERGENCE` — 전달마다 정보가 깎이는 시스템은 절차 변형 장치로 차용 가능).

**조합 훅:** Wordle(FE-DEDUCTION)과 교배 — 변질 단서 체인의 원형을 역추리하는 데일리(시도마다 체인 한 칸 추가 공개, FE-DEDUCTION+FE-SURPRISE); story-architect 연계 — '전언이 만드는 소문' 시스템으로 NPC 간 정보 변질을 서사 장치화(FE-NARRATIVE+FE-EMERGENCE).

**IP 주의:** 'Telestrations' 상표(USAopoly)·스케치북 컴포넌트 디자인은 금지 — 그림·글 교대 전언 구조는 자유.

### Concept (2013)

**코어:** 말과 제스처를 금지당한 출제자가 보드에 깔린 보편 아이콘(약 백 개 — 사람·색·크기·용도 등) 위에 메인 개념 마커와 보조 마커들을 조합 배치해 단어·문구를 설명하고, 나머지가 자유롭게 외쳐 맞힌다. As d'Or(프랑스 올해의 게임) 2014.

**재미요소:** `FE-AHA` — 아이콘 조각들('액체'+'빨강'+'과일')이 한 단어로 수렴하는 순간. `FE-DEDUCTION` — 마커가 추가될 때마다 후보의 교집합을 좁히는 추론. `FE-CONSTRAINT` — 고정된 아이콘 어휘만으로 무엇이든 표현해야 하는 제약이 창의를 강제. `FE-EXPRESSION` — 같은 단어도 사람마다 전혀 다른 조합으로 푸는 표현 다양성.

**핵심 메카닉:**
- 보편 아이콘 보드 + 메인 개념 마커(주제) / 보조 마커(부가 속성)의 계층 표기.
- 제시어 카드는 110장에 약 990개, 3단계 난도(공식 구성 기준).
- 발화·제스처 금지 — 아이콘 배치 순서와 강조(마커 수)만이 정보.
- 정답 시 출제 측·정답자 모두 득점하나 점수는 가볍게 취급되는 파티 구조.

**웹 번안:** ⚠️ `puzzle-game` — 출제 측(인간 창의)은 범위 밖이지만 **추측 측 솔로가 성립**한다: 제시어마다 아이콘 조합·공개 순서를 저작해 두고(또는 의미 태그에서 휴리스틱 생성), AI 출제자가 마커를 하나씩 추가 배치 — 적은 힌트로 맞힐수록 고득점. 자유 입력 채점은 선택지·글자 수 힌트로 완화한다. 아이콘 어휘 1벌은 VectorForge로 자체 디자인(이 게임 번안의 최대 콘텐츠 비용이자 자산). 보드모델은 아이콘 격자 + 마커 스택, 입력은 탭. 날짜 시드 데일리 출제.

**조합 훅:** Wordle(FE-DEDUCTION)과 교배 — 아이콘이 한 개씩 공개되는 데일리, 시도 수·공개 수를 이모지로 공유(FE-DEDUCTION+FE-SOCIAL); game-ui-hud 연계 — 아이콘 보드 설계 자체가 HUD/아이콘 시스템 구축 과제와 동형(FE-CONSTRAINT+FE-EXPRESSION).

**IP 주의:** 'Concept' 상표(Repos Production)·보드의 아이콘 일러스트는 금지 — 아이콘 조합 설명 메카닉은 자유, 아이콘 어휘는 100% 자체 디자인.

### Taboo (1989)

**코어:** 모래시계가 흐르는 동안 카드 맨 위의 제시어를, 그 아래 적힌 **금지어 5개를 입에 올리지 않고** 말로 설명해 팀이 연속으로 맞히게 한다. 금지어(부분 단어·파생형 포함)를 말하면 상대팀 감시자가 버저를 울리고 그 카드는 무효.

**재미요소:** `FE-CONSTRAINT` — 가장 설명하기 좋은 단어 5개가 정확히 막혀 있는 우회 표현의 강제. `FE-EXPRESSION` — 막힌 길을 도는 순발력 화술이 곧 실력. `FE-TENSION` — 타이머 + 상대팀의 버저 감시라는 이중 압박. `FE-SOCIAL` — 버저가 울릴 때의 좌절과 폭소.

**핵심 메카닉:**
- 카드 구조: 제시어 1 + 금지어 5 — 금지는 부분 사용·파생형까지 확장(예: 'base'는 'baseball'에도 금지).
- 제한 시간(고전판 1분 모래시계) 동안 맞힌 카드 수가 점수, 금지어 위반·패스는 감점/무효.
- 상대팀 1인이 카드를 함께 보며 버저로 실시간 판정 — 감시자조차 게임의 일부.
- 라운드마다 출제자 교대, 팀 합산 점수.

**웹 번안:** ❌ — 음성 발화와 인간 추측이 코어라 범위 밖(음성 인식 없는 환경에서 성립 불가). 추출할 재미요소: **금지어 역방향 퍼즐**(`FE-DEDUCTION`+`FE-CONSTRAINT` — 금지어가 ■로 가려진 저작 설명문에서 제시어를 추리 — '빠진 핵심 단어들'의 윤곽 자체가 단서가 되는 반전), **파생형 차단 규칙**(부분 문자열 금지는 단어 입력 게임의 우아한 제약 다이얼 — '글자 E 사용 금지' 같은 변형), **타이머 연속 처리**(`FE-FLOW` — 제한 시간 내 카드 연속 소화 구조는 모든 퀴즈류의 표준 리듬).

**조합 훅:** Wordle(FE-DEDUCTION)과 교배 — 가려진 설명문 데일리 추리(공개 힌트가 늘수록 점수 하락, FE-DEDUCTION+FE-RISK-REWARD); arcade-classic 타이핑 어택 — 금지 글자를 피해 유효 단어를 빠르게 입력하는 제약 타이핑(FE-CONSTRAINT+FE-FLOW).

**IP 주의:** 'Taboo' 상표(Hasbro)·버저 조형은 금지 — 금지어 회피 설명·시간 연속 처리 메카닉은 자유.
