## 공통 번안 패턴

- **판정은 기계, 입력은 탭 하나:** 이 클러스터의 공통 골격은 '조건이 성립한 순간을 인간이 먼저 알아채기'. 보드모델은 단순(카드 배열·합계·시퀀스)하고 `isMatch(state)` 순수 판정 함수를 렌더와 분리하면 봇·리플레이·데일리 검증이 전부 공짜로 따라온다.
- **AI = 반응시간 분포 봇:** 미니맥스가 아니라 '평균 반응시간 ± 편차 + 오답률'로 모델링한 라이벌 봇이 표준. 난이도 = 타이머 단축·오답률 하락. 봇이 잡는 순간을 고스트 손/플래시로 시각화해 패배를 납득시킨다(`FE-FAIRNESS`).
- **타임어택 표준 HUD:** 콤보 타이머(연속 정답 가속)·오답 시간 차감·등급 별점. 반응류 4종(Dobble·Ghost Blitz·Jungle Speed·Halli Galli)이 같은 루프를 공유하므로 game-ui-hud 한 벌로 재사용.
- **실물 민첩 2갈래 번안:** ① matter-physics 직역 — 플릭·스태킹을 드래그-조준-세기 입력으로 옮기고 촉각은 흔들림 게이지·ChipAudio 경고음으로 치환(Crokinole·Jenga·Rhino Hero). ② 타이밍 탭 추상화 — 안정도 게이지를 정확한 순간에 멈추는 미니게임으로 긴장만 증류.
- **데일리 시드:** 날짜 시드 카드열·시퀀스·배치로 모두 같은 판에서 기록 경쟁, 결과 이모지 클립보드 공유(`FE-SOCIAL` `FE-LUCK-TAME`). localStorage 베스트·고스트 리플레이.
- **절차 콘텐츠 생성:** Dobble의 사영평면(위수 n 소수면 카드당 n+1심볼·n²+n+1장) 같은 수학 구조로 덱을 절차 생성하고, VectorForge로 '비슷하지만 다른' 심볼 패밀리를 만들어 시각 변별 난이도 곡선을 설계한다.

### Dobble / Spot It! (2009)

**코어:** 카드 55장, 카드마다 심볼 8개 — 어떤 두 장을 골라도 공통 심볼이 정확히 1개 존재한다. 두 카드 사이의 그 유일한 공통 심볼을 먼저 찾아 외치는(터치하는) 사람이 이긴다. 2009년 프랑스 발매.

**재미요소:** `FE-AHA` — 안 보이던 공통 심볼이 '탁' 보이는 순간의 시각 통찰 연타 · `FE-FLOW` — 찾기→넘기기→찾기의 무호흡 스캔 리듬 · `FE-SET-LOGIC` — 같음 판정 자체가 코어인 순수 매칭 · `FE-MASTERY` — 심볼 어휘 암기와 스캔 패턴 전략의 숙련 천장.

**핵심 메카닉:**
- 수학 골격 = 위수 7 유한 사영평면: 심볼 57종, 카드당 8심볼, 가능한 57장 중 55장 사용 — '어떤 두 장도 공통 심볼 정확히 1개'가 구조적으로 보장된다.
- 심볼 크기·회전·배치를 변주해 같은 심볼도 다르게 보이게 — 시각 변별이 난이도의 원천.
- 공식 룰은 같은 판정(유일 공통 심볼 찾기)을 공유하는 미니게임 여러 종으로 구성 — 판정 엔진 하나에 규칙 스킨 여럿.
- 일반화: 위수 n(소수 거듭제곱)이면 카드당 n+1심볼·n²+n+1장 — 카드당 심볼 수로 난이도 곡선을 절차 설계할 수 있다.

**웹 번안:** ✅ `arcade-classic`. 사영평면 생성기로 덱을 절차 생성하고(위수 2~7 = 심볼 3~8개 난이도 사다리), 심볼은 VectorForge 절차 아이콘. 솔로 타임어택 직역: 카드 쌍 연속 제시 → 공통 심볼 탭, 콤보 타이머 가속 + 오탭 시간 차감. 반응 타이머 봇 레이스와 날짜 시드 데일리 덱(같은 순서로 기록 경쟁 + 이모지 공유)이 표준 장착.

**조합 훅:** Memory와 교배 — 직전 카드 심볼을 가린 채 기억으로 공통 찾기(`FE-MEMORY`) · Bejeweled식 콤보 연출 — 연속 정답이 화면을 점점 달구는 피버 게이지(`FE-COMBO` `FE-JUICE`).

**IP 주의:** 'Dobble'·'Spot It!' 상표와 고유 심볼 일러스트 세트는 금지 — 사영평면 수학 구조와 '유일 공통 심볼' 판정 규칙은 자유.

### Ghost Blitz / Geistesblitz (2010)

**코어:** 색과 형태가 1:1로 묶인 오브제 5개(흰 유령·녹색 병·회색 쥐·파란 책·빨간 의자)를 펼쳐 두고 카드를 공개한다. 카드에 '올바른 색'의 물건이 있으면 그것을, 하나도 없으면 색도 형태도 카드에 등장하지 않는 유일한 물건을 먼저 잡는다(Zoch, 2010).

**재미요소:** `FE-AHA` — '그대로'와 '배제'를 오가는 조건 반전의 두뇌 스위치 · `FE-SET-LOGIC` — 색×형태 격자에서 교집합/여집합을 푸는 즉석 집합 연산 · `FE-MASTERY` — 의식적 추론이 자동 반사로 바뀌는 학습 곡선 · `FE-TENSION` — 다 같이 손이 허공에 떠 있는 0.5초.

**핵심 메카닉:**
- 오브제 5종 = 5색 × 5형태의 1:1 매핑(색이 곧 정체성).
- 카드 = 물건 2개를 색이 맞거나 틀리게 채색해 묘사.
- 판정 분기: ① 정색 오브제가 카드에 있으면 그것 ② 둘 다 오색이면 카드에 보이는 색·형태 어디에도 안 걸리는 유일 오브제(배제 추론).
- 정답자가 카드를 획득하며 누적 — 속도와 정확도의 저울.

**웹 번안:** ✅ `arcade-classic`. 화면 하단 오브제 5버튼 + 카드 자동 공개의 솔로 타임어택이 거의 직역이다. 판정이 결정적이라 오답 시 '왜 이게 정답인지' 한 줄 해설을 즉시 띄울 수 있다(`FE-FAIRNESS`). 난이도 축: 카드 노출 시간 단축, 물건 3개 카드, 판정 규칙 3번째 분기 추가. 날짜 시드 카드열 데일리 + 반응 타이머 봇 레이스.

**조합 훅:** Simon과 교배 — 정답 오브제를 시퀀스로 누적 암기했다가 한꺼번에 입력(`FE-MEMORY` `FE-ESCALATION`) · 로그라이트 모디파이어 — 라운드마다 판정 규칙이 하나씩 변이해 매번 새로 배우게(`FE-RULE-DISCOVERY` `FE-SURPRISE`).

**IP 주의:** 'Geistesblitz'/'Ghost Blitz' 상표와 유령 캐릭터·목제 오브제 조형은 금지 — 색·형태 배제 판정 메카닉은 자유.

### Jungle Speed (1997)

**코어:** 각자 더미에서 돌아가며 카드를 공개하다, 두 사람의 공개 카드 무늬가 같아지는 순간 둘이 중앙 토템을 먼저 잡는 듀얼 — 진 쪽이 상대 공개 더미를 인수한다. 자기 카드를 먼저 소진하면 승리. 1990년대 초 고안돼 1997년판으로 널리 보급됐다.

**재미요소:** `FE-TENSION` — 매 카드 공개가 잠재적 듀얼인 상시 경계 상태 · `FE-TIMING` — 먼저 닿는 손이 전부인 찰나 승부 · `FE-SURPRISE` — 규칙 자체를 뒤트는 특수 카드 난입 · `FE-AHA` — '비슷하지만 다른' 무늬를 가르는 순간 판별.

**핵심 메카닉:**
- 무늬가 일부러 헷갈리게 디자인됨(기본은 색 무시, 형태만 비교) — 시각 변별 착시가 콘텐츠의 핵심.
- 특수 카드 3종: 전원 동시 잡기(안쪽 화살표) / 전원 동시 공개(바깥 화살표) / 형태 대신 색 매칭으로 전환(다색 화살표).
- 듀얼 패자와 오잡기는 카드 인수 — 카드가 벌점이자 탄약.
- 카드 소진 승리 — 잘 잡을수록 빨리 끝나는 자기 가속 구조.

**웹 번안:** ✅ `arcade-classic`. 봇 N명을 반응시간 분포로 모델링하고, 내 카드와 봇 카드가 매칭되는 순간 중앙 토템 탭 레이스. '비슷한 무늬 패밀리'는 VectorForge 절차 생성(기준 도형 + 미세 변형)으로 무한 공급된다. 특수 카드의 규칙 전환이 솔로 루프의 단조로움을 깨는 장치. 날짜 시드 덱 데일리 + 생존 시간·카드 소진 기록.

**조합 훅:** Dobble 판정과 교배 — 매칭 조건을 '유일 공통 심볼'로 바꾼 고난도 토템(`FE-SET-LOGIC`) · 색/형태 전환을 상시 모디파이어 휠로 — 룰이 주기적으로 회전하는 무한 모드(`FE-ESCALATION` `FE-SURPRISE`).

**IP 주의:** 'Jungle Speed' 상표·토템 조형·고유 무늬 아트는 금지 — 동일 무늬 듀얼과 오브제 잡기 레이스 골격은 자유.

### Halli Galli (1990)

**코어:** 돌아가며 자기 더미의 카드를 공개해 쌓는다. 모든 공개 더미를 합쳐 같은 과일이 '정확히 5개'가 되는 순간 종을 먼저 친 사람이 공개 카드를 전부 가져간다(Haim Shafir, Amigo 1990).

**재미요소:** `FE-TENSION` — 매 장이 '혹시 5?'인 상시 산수 경계 · `FE-TIMING` — 조건 성립과 동시에 내리치는 종 · `FE-FLOW` — 공개→합산→공개의 기계적 리듬 속 집중 · `FE-JUST-ONE-MORE` — 판이 짧고 규칙이 5초면 설명돼 즉시 리매치.

**핵심 메카닉:**
- 카드 = 과일 1종이 1~5개. 판정 = 각 더미 맨 윗장 합산, 같은 과일이 '정확히 5'(4도 6도 무효).
- 오타종 페널티: 자기 더미에서 다른 플레이어들에게 카드를 1장씩 지불 — 성급함의 비용.
- 카드를 다 잃으면 탈락, 종 친 승자가 판의 카드를 흡수 — 부익부 가속 구조.

**웹 번안:** ✅ `arcade-classic`. 솔로 타임어택 직역: 더미들이 자동으로 공개되고 조건 성립 순간 화면(종)을 탭 — 빠를수록 가산, 오탭 감점. 난이도 축이 풍부하다: 과일 종 수, 더미 수, 공개 속도, 목표 합 변형. 반응 타이머 봇 레이스와 날짜 시드 데일리가 그대로 얹힌다. 현재 합산을 보여주는 시각 보조 토글(켜면 입문, 끄면 암산 숙련)로 `FE-FAIRNESS`와 `FE-MASTERY`를 동시에 잡는다.

**조합 훅:** Ganz schön clever류 기입과 교배 — 종 칠 때의 합 구성(2+3, 1+4…)을 보너스 트랙에 마킹하는 메타 채점(`FE-COMBO` `FE-OPTIMIZE`) · 목표 합이 5→10→15로 점증하는 무한 에스컬레이션 모드(`FE-ESCALATION`).

**IP 주의:** 'Halli Galli' 상표·과일 일러스트·종 트레이드 드레스는 금지 — '정확히 N 합산 시 종 치기' 규칙은 자유.

### Memory / Concentration (고전)

**코어:** 짝이 있는 카드 전부를 뒷면으로 깔고, 턴마다 2장을 공개한다. 짝이면 가져가고 한 번 더, 아니면 제자리에 다시 뒤집는다 — 최다 짝 획득 승리. 전통 Pelmanism 계보를 1959년 Ravensburger가 현대 상품형으로 정립했다.

**재미요소:** `FE-MEMORY` — 가려진 위치 정보 암기가 게임의 전부인 본진 · `FE-AHA` — '아까 거기서 봤다'가 적중하는 회상 쾌감 · `FE-JUST-ONE-MORE` — 짝 적중 시 연속턴이 만드는 미니 콤보 · `FE-FAIRNESS` — 실패가 언제나 '내 기억'으로 귀인되는 투명함.

**핵심 메카닉:**
- 정보가 오직 플레이(공개 이력)로만 축적 — 판이 진행될수록 운 게임에서 기억 게임으로 상전이.
- 짝 적중 시 연속턴 — 종반 기억 폭발 체인.
- 그리드 크기·짝 수가 난이도와 플레이타임을 직결 제어.
- 다인전에선 상대가 공개한 카드도 내 정보 — 남의 실패에 무임승차하는 기억전.

**웹 번안:** ✅ `puzzle-game`. `FE-MEMORY` 본진이자 웹 구현 최단거리(상태 = 카드 배열 + 공개 이력). 솔로 표준은 '최소 시도 수' 별점(`FE-OPTIMIZE`)과 타임 모드. 변형 축: 짝 노출 시간 단축, 3장 세트 매칭, 일정 턴마다 카드 일부가 자리를 바꾸는 고난도(`FE-REARRANGE`). 날짜 시드 배치 데일리 + 시도 수 이모지 공유, localStorage 베스트·연속 출석.

**조합 훅:** Simon과 교배 — 위치 + 순서를 함께 암기하는 2축 기억(`FE-ESCALATION`) · 수집 메타 — 맞춘 짝이 도감에 등록되고 테마 덱이 해금되는 진행(`FE-COLLECT` `FE-SURPRISE`).

**IP 주의:** 'memory'는 Ravensburger 상표(특히 유럽권) — 일반명(Concentration/Pairs)을 쓰고, 카드 쌍 뒤집기 규칙 자체는 퍼블릭 도메인이라 자유.

### Simon (1978)

**코어:** 4색 버튼 원반이 빛·소리 시퀀스를 재생하면 그대로 따라 누른다. 성공할 때마다 시퀀스가 1개씩 길어지고, 틀리거나 제한시간(원판 기준 약 5초) 안에 못 누르면 종료(Ralph Baer·Howard Morrison 설계, Milton Bradley 1978).

**재미요소:** `FE-MEMORY` — 점점 길어지는 시퀀스 암기의 본진 · `FE-ESCALATION` — '한 개 더'가 누적되는 구조 자체가 압박 곡선 · `FE-FLOW` — 음·빛·손가락이 합치되는 멀티모달 리듬 · `FE-JUICE` — 버튼마다 고유 음정이 주는 악기 같은 손맛.

**핵심 메카닉:**
- 시퀀스는 매번 앞부분 전체 반복 + 새 항목 1개 — 작업 기억을 청킹(음 패턴화)으로 확장하게 만든다.
- 버튼별 고유 음 — 청각 인코딩이 기억을 보조하는 원판의 핵심 설계.
- 입력 제한시간과 후반 재생 가속 — 점증 압박.
- 원판 매뉴얼 기준 목표 길이 8/14/20/31의 스킬 레벨 4단계.

**웹 번안:** ✅ `arcade-classic`. 본질이 전자 게임이라 이 클러스터에서 유일하게 직역이 곧 완성형 — 공식적으로 1인용이 성립하는 구조다. ChipAudio로 버튼 음 합성, juice-fx 글로우·펄스. 변형 모드: 역순 재생, 소리만/빛만 제시, 속도 점증, 버튼 5~6개 확장. 날짜 시드 시퀀스 데일리 — 모두 같은 수열로 도달 길이 경쟁 + 이모지 공유, localStorage 베스트.

**조합 훅:** Memory와 교배 — 그리드 위치 + 순서의 2축 시퀀스 암기(`FE-SPATIAL`) · endless-runner에 이식 — 장애물 패턴이 사전 예고 시퀀스로 제시되는 암기 러너(`FE-MEMORY` `FE-FLOW`).

**IP 주의:** 'Simon'은 Hasbro 상표이고 원반형 4색 배색 트레이드 드레스도 주의 — '시퀀스 따라 누르기' 메카닉('Simon Says' 전래 놀이 계보)은 자유.

### Jenga (1983)

**코어:** 3개씩 18층, 총 54블록 타워에서 한 손으로 블록 1개를 빼 꼭대기에 다시 올린다. 타워를 무너뜨린 사람이 패배(Leslie Scott, 1983년 런던 토이페어 출시).

**재미요소:** `FE-TENSION` — 손끝 하나에 걸린 붕괴 직전 니어미스의 본진 · `FE-ESCALATION` — 뺄수록 높아지고 성겨지는 자기 강화 불안정 · `FE-RISK-REWARD` — 안전한 블록이냐, 상대를 몰아넣을 위험한 블록이냐 · `FE-JUICE` — 나무 블록의 마찰·기울어짐이 주는 촉각 피드백.

**핵심 메카닉:**
- 느슨한 블록 탐색(살짝 밀어 반응 확인) → 추출 → 꼭대기 재적재의 3박자.
- 완성된 최상층 아래에서만 추출 — 타워는 위로만 자란다.
- 한 손 규칙 — 정밀 조작 제약이 곧 난이도.
- 붕괴 = 즉시 패배의 단일 실패 조건 — 명확하고 잔인한 귀인.

**웹 번안:** ⚠️ `arcade-classic`(+`matter-physics`). 코어인 손끝 촉각은 물리 직역이 불가능 — 두 갈래 번안을 명시한다. ① matter-physics 직역: 블록 드래그 추출 + 무게중심·하중 시뮬, 촉각 대신 흔들림 게이지와 삐걱 경고음(ChipAudio)으로 위험 신호를 치환. ② 타이밍 탭 추상화: 블록마다 안정도 수치를 두고 움직이는 게이지를 정확한 순간에 멈추면 추출 성공 — 물리 없이 긴장만 증류. 솔로는 '붕괴 전 최고층' 기록 도전 + 봇 교대전, 날짜 시드 초기 타워 데일리.

**조합 훅:** NMBR 9의 높이 채점과 교배 — 층수×안정도 곱점수의 솔로 빌더(`FE-OPTIMIZE`) · Rhino Hero식 지시 카드를 얹어 '이번 턴은 가운데 열만' 같은 제약 변주(`FE-CONSTRAINT` `FE-SURPRISE`).

**IP 주의:** 'Jenga'는 상표(Leslie Scott → Hasbro) — 블록 추출·재적재 타워 메카닉 자체는 자유.

### Rhino Hero (2011)

**코어:** 턴마다 직전 지붕 카드에 인쇄된 윤곽대로 벽 카드를 접어 세우고, 손의 지붕 카드 1장을 그 위에 올린다. 손 카드를 먼저 소진하면 승리, 탑을 무너뜨리면 즉시 패배(원제 Super Rhino, HABA 2011, 지붕 카드 31장·벽 카드 28장 구성).

**재미요소:** `FE-TENSION` — 카드 한 장 올릴 때마다 흔들리는 탑 · `FE-ESCALATION` — 높아질수록 기하급수로 커지는 붕괴 확률 · `FE-SPATIAL` — 벽 윤곽 지시를 읽고 하중을 가늠하는 배치 감각 · `FE-RISK-REWARD` — 어려운 지붕 카드를 먼저 버릴까, 안전하게 갈까의 손 관리.

**핵심 메카닉:**
- 지붕 카드의 벽 윤곽 = 다음 층의 구조를 지금 결정 — 카드 선택이 곧 다음 사람에 대한 공격.
- 특수 심볼: 순서 역전·턴 스킵·카드 추가 인수·이중 지붕(벽 없이 연속 2장).
- 코뿔소 심볼이 나오면 영웅 피겨를 탑 위로 옮겨 하중을 더하는 물리 이벤트.
- 손 소진 레이스 + 붕괴 즉패의 이중 종료(붕괴 시 손이 가장 적은 쪽이 승자).

**웹 번안:** ⚠️ `arcade-classic`(+`matter-physics`). 종이 카드를 접어 세우는 촉각이 코어라 보정이 필수다. matter-physics로 하중·기울기 누적을 시뮬하고, 드래그 배치의 위치 오차가 미세 기울기로 누적되게 하면 정밀도가 곧 실력이 된다. 또는 타이밍 탭(흔들림 주기에 맞춰 올리기)으로 추상화. 솔로: 지시 카드 덱을 뽑으며 '최고층 도전', 피겨 이벤트가 난수 양념, 날짜 시드 카드 순서 데일리.

**조합 훅:** 지붕 카드 심볼을 로그라이트 이벤트로 확장 — 층마다 효과가 발동하는 타워 런(`FE-SURPRISE` `FE-BUILD`) · platformer와 교배 — 쌓기 페이즈 후 그 탑을 직접 등반하는 2페이즈 게임(`FE-BUILD` `FE-EXPLORE`).

**IP 주의:** 'Rhino Hero' 상표·HABA 코뿔소 캐릭터·카드 아트는 금지 — 카드 타워 스태킹과 지시 심볼 골격은 자유.

### Crokinole (1876)

**코어:** 원형 보드 가장자리 자기 구역에서 디스크를 손가락으로 튕긴다. 안쪽 링일수록 고득점, 중앙 홀에 완전히 빠지면 20점 확정(즉시 회수). 상대 디스크는 장외(도랑)로 쳐내고, 라운드(통상 1인 12디스크)가 끝나면 점수 차만 승자가 가져간다. 1876년 캐나다 온타리오의 수제 보드가 최고(最古) 기록.

**재미요소:** `FE-MASTERY` — 힘·각도 제어의 끝없는 숙련 천장(플릭 스포츠) · `FE-RISK-REWARD` — 20홀 정조준이냐 안전한 수비 배치냐 · `FE-JUICE` — 디스크끼리 부딪히는 타격감과 궤적의 손맛 · `FE-TENSION` — 마지막 디스크 한 발에 걸린 라운드.

**핵심 메카닉:**
- 동심원 점수대(안쪽일수록 고득점) + 중앙 20홀(빠지면 보드에서 제거하고 확정 가산).
- 강제 접촉 규칙: 상대 디스크가 보드에 있으면 반드시 맞혀야 유효, 못 맞히면 내 디스크 제거 — 일방 농성을 차단하는 핵심 장치.
- 중앙 둘레의 페그(기둥)들이 직선 샷을 차단 — 뱅크샷·콤보샷 기술의 원천.
- 차등 채점: 라운드마다 양측 점수 차만 득점 — 접전 유지 장치.

**웹 번안:** ⚠️ `arcade-classic`(+`matter-physics`). 2D 톱다운 원형 보드 + 원 충돌이라 물리 자체는 가볍게 옮겨지지만, 실물 손가락 스냅의 정밀 감각은 드래그-조준-세기 입력으로 보정해야 한다(조준선 토글: 켜면 입문, 끄면 숙련 — `FE-FAIRNESS`/`FE-MASTERY` 양립). AI 상대는 조준 오차 분포(가우시안)로 난이도를 만들면 잘 치고 못 치는 게 눈에 보여 공정하다. 솔로: 시드 배치 트릭샷 퍼즐 데일리 + 별점, 타깃 연습 모드.

**조합 훅:** ICECOOL의 추격 감각과 교배 — 움직이는 타깃을 쳐내는 변형(`FE-TIMING`) · 손제작 트릭샷 캠페인 — 페그 배치 퍼즐을 한 발에 푸는 당구식 레벨(`FE-ELEGANCE` `FE-AHA`).

**IP 주의:** crokinole은 19세기 전통 게임으로 퍼블릭 도메인 — 명칭·규칙 자유, 특정 제조사의 보드 디자인·로고만 회피.

### ICECOOL (2016)

**코어:** 라운드마다 1명은 술래(Catcher), 나머지는 러너. 바닥이 둥근 오뚝이형 펭귄 피겨를 튕겨 얼음 학교의 방과 문을 통과시킨다 — 러너는 자기 색 물고기가 걸린 문을 통과해 점수 카드를 얻고, 술래는 러너 피겨를 맞혀 잡는다. 전원이 술래를 한 번씩 맡으면 종료, 최다 점수 승리(Brain Games 2016, Kinderspiel des Jahres 2017).

**재미요소:** `FE-JUICE` — 커브·점프로 휘어 나가는 피겨 궤적의 물리 손맛 · `FE-MASTERY` — 누르는 위치·각도로 만드는 트릭샷 기술 천장 · `FE-TENSION` — 쫓고 쫓기는 추격의 한 발 · `FE-SURPRISE` — 물고기 카드 점수 뽑기의 운 양념.

**핵심 메카닉:**
- 둥근 바닥 피겨 = 누르는 지점에 따라 직진·커브·벽 넘는 점프가 갈리는 아날로그 입력 — 손가락 기술 자체가 콘텐츠.
- 연결된 방들과 문 통과가 득점 트리거(자기 색 물고기 토큰 회수 → 카드 획득).
- 술래/러너 비대칭 역할이 라운드마다 순환 — 공수 양면을 모두 평가.
- 물고기 카드 = 비공개 무작위 점수 — 마지막까지 승자 불명.

**웹 번안:** ❌ 코어는 범위 밖 — 실물 오뚝이 피겨를 손가락으로 눌러 휘게 만드는 신체 기술과, 술래잡기의 다인 비대칭 사회성이 게임의 본체라 디지털 플릭으로 옮기는 순간 다른 게임이 된다. 추출할 재미요소: 플릭 추격의 `FE-TENSION`, 커브샷 궤적의 `FE-JUICE`, 문 통과 보상 동선 설계의 `FE-RISK-REWARD`. 드래그 플릭 + 스핀(커브) 파라미터의 톱다운 추격 아케이드로 만들면 '영감 번안'은 가능하다(`arcade-classic`+`matter-physics`).

**조합 훅:** Crokinole 플릭 물리 + endless-runner 압박 — AI 술래가 따라붙는 방 연쇄 코스를 플릭으로 주파(`FE-ESCALATION` `FE-TENSION`) · 물고기 수집 메타 — 코스에서 모은 토큰으로 피겨를 커스텀(`FE-COLLECT` `FE-EXPRESSION`).

**IP 주의:** 'ICECOOL' 상표·펭귄 캐릭터 아트·얼음 학교 보드 디자인은 금지 — 플릭 추격·문 통과 득점 골격은 자유.

## IP 공통 원칙

메카닉·규칙·승리 조건은 저작권 보호 대상이 아니므로 자유롭게 차용한다. 다만 게임명 상표(Dobble·Spot It!·Geistesblitz·Jungle Speed·Halli Galli·memory·Simon·Jenga·Rhino Hero·ICECOOL 등)·고유 심볼/과일/캐릭터 일러스트·토템/종/피겨 조형 트레이드 드레스는 일절 사용하지 않는다. 모든 표현물은 100% 자체 제작 — 심볼·기물은 PixelForge/VectorForge 절차 생성, 사운드는 ChipAudio 합성, 타이틀은 자체 부여(예: 'Dobble 클론'이 아니라 독자 이름). 배포 전 [`ip-license-guard`](../../../../wgf-ip-license-guard/SKILL.md)로 최종 점검한다.
