# 게임 DNA · 보드게임 아틀라스 — 협력 · 제한 소통

> WebGameForge 게임 DNA **보드게임 아틀라스**(컴팩트 2티어)의 클러스터 파일이다 — 심화 35종과 달리 게임당 핵심만 압축한 카탈로그(총 100종 중 일부). 아래 게임들의 **메카닉·재미요소만** 분석한다(저작물 미사용). 물리 보드게임을 **디지털 단일플레이 웹 게임으로 번안하는 관점**으로 적는다. 협력 게임은 '시스템 vs 플레이어'라 본질적으로 솔로 친화지만, 제한 소통 코어는 다인 사회성이 본질이라 솔직하게 ❌/⚠️ 판정하고 추출 요소를 명시한다. 색인은 [INDEX.md](./INDEX.md), 심화 분석(퍼즐 35종)은 [../puzzle/INDEX.md](../puzzle/INDEX.md), 재미요소 사전은 [../fun-elements.md](../fun-elements.md), 전역 색인은 [../INDEX.md](../INDEX.md).

## 공통 번안 패턴

- **시스템 턴 = 자동 확산 틱:** 감염 덱(Pandemic)·침수 덱(Forbidden Island)·화재 주사위(Flash Point)·침략자 컨베이어(Spirit Island)는 전부 '플레이어 턴 → 시스템 틱' 구조다. 보드모델에 `tickSystem()` 단일 함수로 정식화하고, 확산·연쇄를 큐에 쌓아 한 단계씩 연출 재생(juice-fx)하면 `FE-ESCALATION`·`FE-EMERGENCE`가 그대로 산다.
- **패배 시계 다이얼:** 아웃브레이크 트랙·수위계·황폐 풀·모래시계를 HUD 게이지 1~3개로 노출(game-ui-hud). 게이지 시작값·증가 속도가 level-designer의 난도 다이얼이 된다.
- **제한 소통 → 나 vs 시스템 추론:** 인간 간 마음이론(내 단서를 상대가 어떻게 해석할까)은 범위 밖. 대신 '수가 읽히는 휴리스틱 AI'의 행동에서 은닉 정보를 역추론하는 `FE-HIDDEN-INFO`+`FE-DEDUCTION` 퍼즐로 치환한다 — AI 부조종사의 주사위 배치, AI 유령의 카드 선택에서 '왜 저걸 했지?'를 읽게.
- **다인 분업 → 전환 비용:** 여러 역할·동작을 한 명이 핸들링하되 역할 전환에 행동/시간 비용을 부과해 '내 것만 가능' 제약(`FE-CONSTRAINT`)을 솔로에 보존한다(Magic Maze 동작 모드 전환, Pandemic 2역할 핸들링).
- **역할 비대칭 = 캐릭터 선택·해금:** 협력 게임의 역할 능력은 시작 캐릭터 선택 + localStorage 해금 진행으로 옮기면 리플레이 동기가 된다.
- **날짜 시드 데일리:** 위기 덱(감염·침수·침략·화재) 순서를 날짜 시드로 고정하면 '모두 같은 위기'를 받는 공유 무작위가 성립 — 결과(남은 턴·구출 수·점수)를 이모지로 공유.

### Pandemic (2008)

**코어:** 내 턴에 행동 4회(이동·치료·카드 교환·연구소 건설)로 도시들의 질병 큐브를 억제하고, 같은 색 도시 카드 세트를 연구소에서 소모해 4종 질병의 치료제를 모두 발견하면 승리. 턴 끝마다 감염 덱이 도시를 자동 오염시키고, 큐브 3개 도시에 4번째가 오면 인접 도시 전체로 번지는 아웃브레이크가 연쇄한다.

**재미요소:** `FE-ESCALATION` — 에피데믹 카드가 감염률을 올리고 버린 감염 카드를 되섞어 덱 위에 얹어, 이미 아픈 도시가 또 터지는 점증 압박. `FE-EMERGENCE` — 큐브 3개 도시들이 이웃해 있으면 아웃브레이크 하나가 도미노 연쇄로 번지는 창발. `FE-PLANNING` — 행동 4회의 동선·카드 교환 타이밍을 몇 턴 앞서 최적화. `FE-TENSION` — 아웃브레이크 트랙·큐브 재고·덱 고갈 3종 패배 시계가 항상 째깍거림.

**핵심 메카닉:**
- 턴 구조: 행동 4회 → 플레이어 카드 2장 드로우 → 감염률만큼 감염 카드 공개·큐브 배치.
- 치료제: 같은 색 도시 카드 세트를 연구소에서 소모(역할에 따라 필요 장수 경감). 4종 모두 발견 시 즉시 승리.
- 아웃브레이크: 큐브 3개 도시에 추가 시 인접 도시 전부에 1개씩 — 연쇄 가능(같은 체인에서 도시당 1회).
- 에피데믹 카드: 감염률 상승 + 새 도시 대량 오염 + 감염 버림 더미를 섞어 덱 위로(같은 도시 재감염 보장).
- 패배: 아웃브레이크 8회 / 한 색 큐브 고갈 / 플레이어 덱 고갈. 역할별 비대칭 특수능력.

**웹 번안:** ✅ `puzzle-game`. 보드모델 = 도시 그래프(인접 리스트) + 색별 큐브 카운트 + 덱 상태가 단일 상태 소스. 상대가 시스템이라 솔로가 자연 성립 — 역할 2개를 한 명이 번갈아 핸들링하거나 1역할에 행동 보정. 감염 틱·아웃브레이크 연쇄는 큐 연출로 단계 재생해 '번지는 공포'를 가시화하고, 날짜 시드 데일리(같은 덱 순서)와 localStorage 베스트(남은 턴 수·아웃브레이크 수)로 리텐션을 만든다.

**조합 훅:** Minesweeper(FE-DEDUCTION)와 교배 — 감염 덱의 잔여 구성을 추론해 다음 터질 도시를 확률 표기하는 정보전 레이어; topdown-shooter 이식 — 거점 오염이 실시간 확산하고 치료제 재료를 수송하는 액션 디펜스(FE-ESCALATION+FE-TENSION).

**IP 주의:** 'Pandemic' 상표·Z-Man Games 지도 아트·역할 일러스트는 금지 — 행동 경제·감염 덱·아웃브레이크 연쇄 같은 메카닉·규칙은 저작권 보호 대상이 아니다.

### Forbidden Island (2010)

**코어:** 내 턴에 행동 3회(이동·타일 보강·카드 건네기·보물 회수)로 가라앉는 섬을 누비며, 같은 보물 카드 세트로 보물 4개를 회수하고 전원이 착륙장 타일에 모여 헬리콥터 카드로 탈출하면 승리. 턴 끝 침수 덱이 타일을 적시고, 이미 침수된 타일이 또 뽑히면 영구 소실된다.

**재미요소:** `FE-ESCALATION` — 수위 트랙이 오를수록 턴당 침수 카드가 늘어 섬이 가속도로 좁아짐. `FE-TENSION` — 착륙장·보물 타일이 소실 직전(침수 상태)일 때의 니어미스 압박. `FE-COLLECT` — 보물 4종 세트 수집이 명확한 진행 게이지. `FE-CONSTRAINT` — 행동 3회 안에서 보강이냐 전진이냐의 매 턴 선택.

**핵심 메카닉:**
- 타일 상태 3단: 정상 → 침수(보강으로 복구 가능) → 소실(제거 — 섬이 실제로 줄어듦).
- 보물 회수: 해당 보물 카드 세트를 모아 대응 타일 위에서 회수(타일 쌍이 둘 다 소실되면 그 보물은 영구 불가 = 패배).
- 수위 트랙: 수위 상승 카드가 나올 때마다 턴당 침수 카드 수 증가, 최고 수위 도달 시 패배.
- 승리: 보물 4개 + 전원 착륙장 집결 + 헬리콥터 카드. 패배: 보물 타일 쌍 소실 / 착륙장 소실 / 수위 최고 / 플레이어 고립 익사.
- 역할별 특수능력(대각 이동·원격 보강 등).

**웹 번안:** ✅ `puzzle-game`. Pandemic의 경량 가족판 구조라 솔로 변환이 더 쉽다 — 타일 그리드 + 침수 2단 상태 + 덱이 보드모델 전부. 역할 1~2개 핸들링, 침수·소실을 타일 가라앉는 트윈으로 연출. 날짜 시드 데일리(같은 침수 덱 순서)로 '모두 같은 섬의 침몰'을 공유하고, 남은 타일 수가 점수가 된다.

**조합 훅:** endless-runner 이식 — 밟은 발판이 차례로 가라앉는 '침몰 러너'(FE-ESCALATION+FE-TIMING); Flow Free(FE-SPATIAL)와 교배 — 소실되는 그리드 위에서 탈출 경로의 연결성을 유지하는 경로 보전 퍼즐(FE-PLANNING+FE-TENSION).

**IP 주의:** 'Forbidden Island' 게임명·Gamewright 타일 일러스트·보물 조형(고유 명칭 포함)은 금지 — 침수 2단·세트 수집·수위 트랙 메카닉은 자유.

### Hanabi (2010)

**코어:** 카드를 거꾸로 들어 **내 패는 나만 못 보고** 동료 패만 보인다. 턴마다 (a) 단서 주기(토큰 1개 소모 — 색 또는 숫자 하나를 골라 해당 카드 전부 지목) (b) 내 카드 추정 플레이(불꽃을 색별 1→5 순서로 적재) (c) 버리기(토큰 회복) 중 하나. 5색을 모두 5까지 쌓으면 만점 25점. Spiel des Jahres 2013.

**재미요소:** `FE-HIDDEN-INFO` — 가려진 것이 남의 패가 아니라 '내 패'라는 반전이 모든 추론의 출발점. `FE-CONSTRAINT` — 단서 토큰 8개의 빠듯한 경제: 단서를 아끼려 버리면 정보가 늘 부족하고, 펑펑 쓰면 손이 묶임. `FE-DEDUCTION` — '왜 하필 지금 이 단서를?'이라는 단서의 함의(컨벤션) 연역. `FE-MEMORY` — 받은 단서를 손패 위치별로 누적 암기.

**핵심 메카닉:**
- 단서 토큰 8개 / 퓨즈 3개(오플레이 3회면 즉시 종료).
- 단서는 색·숫자만 허용, 해당하는 카드를 **전부** 지목해야 함(부분 지목 불가).
- 카드 분포가 비대칭(1은 많고 5는 한 장뿐)이라 무엇을 버려도 되는지 자체가 추론 대상.
- 점수 = 색별 최고 적재 수의 합, 최대 25점.

**웹 번안:** ❌ — 코어는 인간 간 마음이론(내가 주는 단서를 상대가 어떻게 해석할지, 상대의 침묵까지 정보)이라 범위 밖. 추출할 재미요소: **단서 경제**(`FE-CONSTRAINT` — 정보 획득에 자원을 지불하는 구조는 어떤 연역 퍼즐에도 이식 가능), **가려진 내 패 연역**(`FE-HIDDEN-INFO`+`FE-MEMORY` — '내 것만 안 보인다' 시점 반전). 단방향 축소판으로 '고정 컨벤션 AI가 단서를 주고 나는 내 패를 연역해 플레이'하는 `puzzle-game` 연역 퍼즐은 성립하지만, 그것은 Hanabi가 아니라 단서 해석 솔리테어다.

**조합 훅:** Wordle(FE-DEDUCTION)과 교배 — 턴마다 비싼 단서를 사서 가려진 내 카드 후보를 소거하는 단서 구매 연역(FE-CONSTRAINT+FE-DEDUCTION); Bejeweled류 매치 보드에 이식 — 내 다음 피스가 가려져 있고 단서 토큰으로만 엿보는 '블라인드 매치'(FE-HIDDEN-INFO+FE-RISK-REWARD).

**IP 주의:** 'Hanabi' 게임명·특정 판본의 불꽃 카드 아트는 금지 — 거꾸로 든 손패·단서 토큰 경제·퓨즈 메카닉은 자유.

### The Mind (2018)

**코어:** 1~100 숫자 카드를 레벨 수만큼 각자 받고, 턴도 신호도 없이 **전원이 침묵 속에서** 낮은 카드부터 오름차순으로 테이블에 내려놓는다. 누군가 더 낮은 카드를 들고 있는데 높은 카드가 먼저 나오면 생명 차감 — 시간의 흐름 자체가 유일한 소통 수단이 되는 텔레파시 게임.

**재미요소:** `FE-TIMING` — '내 카드가 38이면 38만큼 기다린다'는 암묵 박자 합의가 코어 그 자체. `FE-TENSION` — 손이 카드 위에서 떨리는 '낼까 말까'의 순간들. `FE-SOCIAL` — 레벨이 오를수록 팀이 하나의 박자로 동기화되는 일체감(이 게임의 진짜 보상).

**핵심 메카닉:**
- 레벨 N = 인원당 N장 배분(인원수에 따라 최종 레벨 8~12), 레벨 클리어마다 진행.
- 생명: 오플레이 시 차감(틀린 시점에 그보다 낮은 카드 전원 공개 폐기), 소진 시 패배.
- 표창(쓰리켄): 무언 만장일치 합의로 발동 — 전원이 자기 최저 카드를 공개 폐기해 정보 환기.
- 보상 카드: 특정 레벨 클리어 시 생명·표창 추가.

**웹 번안:** ❌ — 코어는 사람들 사이의 침묵 동기화·일체감 그 자체라 범위 밖. 추출할 재미요소: **'시간 간격 = 숫자 간격' 변환의 `FE-TIMING`** — 솔로 번안 시 '값에 비례한 시간을 견뎌야 내려놓을 수 있는' 인내 타이밍 게임(미지의 시스템 카드가 끼어드는 리스크 포함), 그리고 `FE-TENSION`의 손맛(꾹 누르고 있다 떼는 입력)은 `arcade-classic` 원버튼 게임으로 옮길 수 있다.

**조합 훅:** Stack(FE-TIMING)과 교배 — 보이지 않는 기준 박자에 맞춰 블록을 놓는 블라인드 타이밍(FE-TIMING+FE-TENSION); endless-runner 이식 — 숫자 게이트를 '값 비례 대기 후 통과'하는 박자 러너(FE-TIMING+FE-FLOW).

**IP 주의:** 'The Mind' 게임명·NSV 판본 디자인은 금지 — 오름차순 동시 플레이·생명/표창 메카닉은 자유.

### The Crew (2019)

**코어:** 트럼프(로켓 수트) 있는 협력 트릭테이킹 — 매 임무 시작에 '이 카드를 이 플레이어가 트릭으로 따야 한다'는 과제 카드가 배정되고, 대화 금지·1인당 임무당 1회의 제한 소통(카드 한 장 공개 + 그것이 그 색의 최고/최저/유일임을 토큰으로 표시)만으로 과제를 전부 달성하면 임무 클리어. 50개 임무가 점진 난도의 캠페인을 이룬다. Kennerspiel des Jahres 2020.

**재미요소:** `FE-PLANNING` — '누가 언제 리드하고 누가 일부러 져 주는가'의 트릭 순서 수읽기. `FE-HIDDEN-INFO` — 동료 패를 플레이 패턴에서 역추론. `FE-CONSTRAINT` — 소통 1회 제한이 모든 플레이를 신호로 만드는 정보 압축. `FE-NARRATIVE` — 50임무 우주 탐사 캠페인의 진행감.

**핵심 메카닉:**
- 표준 트릭테이킹: 리드 수트 의무 따라가기, 없으면 자유(로켓이 트럼프).
- 과제 카드: 특정 카드(색+숫자)를 지정 플레이어가 따야 함 + 순서 토큰(1번째·2번째·상대 순서 등) 제약.
- 소통 토큰: 1인당 임무마다 1회, 손에서 카드 1장을 공개하고 최고/최저/유일 위치로 토큰을 놓아 표시(임무 재도전 시 복구).
- 50임무 캠페인: 과제 수·제약이 점증, 실패 시 같은 임무 재도전.

**웹 번안:** ⚠️ `puzzle-game` — 다인 은닉 패와 암묵 협조가 본질이라 설계 보정 필요. 두 갈래가 유효: (a) **전 패 공개 더블더미 퍼즐** — 4인분 패를 모두 펼쳐 놓고 '어떤 순서로 내야 전 과제가 달성되는가'를 푸는 논리 퍼즐로 변환(FE-PLANNING 완전 보존, 시드 데일리에 최적), (b) 읽히는 컨벤션 AI 동료 3인과 은닉 유지 플레이. 50임무 캠페인 구조는 level-designer 진행표 + localStorage 해금으로 그대로 이식된다.

**조합 훅:** Sudoku(FE-DEDUCTION)와 교배 — '이 배치에서 과제 달성이 가능한 유일한 플레이 순서'를 연역하는 트릭 퍼즐 데일리(FE-PLANNING+FE-DEDUCTION); Ganz schön clever와 교배 — 트릭 결과가 콤보 기입판을 채우는 트릭&라이트(FE-PLANNING+FE-COMBO).

**IP 주의:** 'The Crew'·'Quest for Planet Nine' 명칭·KOSMOS 카드 아트는 금지 — 협력 트릭테이킹·과제 카드·소통 토큰 메카닉은 자유.

### Spirit Island (2017)

**코어:** 섬의 정령이 되어 매 턴 성장(카드 획득·존재감 확장·에너지)을 고르고 권능 카드를 빠른/느린 타이밍에 시전해, 침략자의 탐험→건설→약탈 3단 컨베이어를 끊는다. 공포를 쌓으면 승리 조건이 단계적으로 완화되고, 약탈이 황폐(blight)를 임계 이상 퍼뜨리면 패배. 무거운 협력 게임 중 손꼽히는 솔로 명작.

**재미요소:** `FE-COMBO` — 원소 임계(불 3·대기 2…)를 맞추면 권능이 증폭되는 연쇄 설계. `FE-BUILD` — 성장 선택·권능 카드 획득·존재감 트랙 해방으로 내 정령이 판마다 강해지는 빌드. `FE-POWER-FANTASY` — 초반엔 막기 급급하다 후반 대권능으로 침략자를 쓸어버리는 카타르시스. `FE-PLANNING` — 침략자 행동이 1턴 앞 공개되는 '예지된 위협'에 대한 수읽기.

**핵심 메카닉:**
- 침략자 컨베이어: 카드가 탐험→건설→약탈 슬롯으로 매 턴 슬라이드 — 이번에 탐험한 지형이 다음 턴 건설, 그다음 약탈된다(완전 공개 정보의 예고 시스템).
- 턴 구조: 정령 성장 → 빠른 권능 → 침략자 행동 → 느린 권능 → 정리(빠름/느림 타이밍 선택이 핵심 재량).
- 공포: 마을·도시 파괴로 누적, 단계가 오르면 승리 조건이 '도시만 전멸'식으로 완화.
- 황폐: 약탈 피해가 임계를 넘으면 지형에 황폐 — 연쇄 확산하며 정령 존재감을 지움, 풀 고갈 시 패배.
- 정령별 완전 비대칭(고유 권능·성장 트랙) + 적응 난이도(국가별 침략자 변형).

**웹 번안:** ✅ `puzzle-game` — 공식 1인 플레이가 1급 시민(시스템 vs 플레이어의 정점). 보드모델: 지역 그래프 + 침략자 3열 슬롯 + 정령 상태. 콘텐츠 규모가 보정 대상 — 정령 2~3종 + 권능 20~30장으로도 코어가 성립하므로 축소 출시 후 확장. 침략자 컨베이어를 HUD 상단에 항상 노출하면 FE-PLANNING이 산다. 시드 데일리 침략 덱 + localStorage 정령 해금.

**조합 훅:** topdown-shooter 런 빌드와 교배 — 웨이브 사이에 권능 카드를 드래프트하고 원소 임계로 증폭하는 디펜스 로그라이트(FE-BUILD+FE-COMBO+FE-DECKCRAFT); Plants vs. Zombies식 레인과 교배 — 침략자 컨베이어를 레인 예고로 시각화한 정령 디펜스(FE-PLANNING+FE-ESCALATION).

**IP 주의:** 'Spirit Island' 게임명·정령 고유 명칭·Greater Than Games 아트는 금지 — 컨베이어 예고·공포 단계·원소 임계 메카닉은 자유.

### Flash Point: Fire Rescue (2011)

**코어:** 소방관이 되어 매 턴 AP(행동 포인트)로 불타는 건물을 누비며 화염·연기를 진압하고 희생자를 업어 구급차까지 구출한다. 턴 끝 주사위가 무작위 칸에 연기를 추가 — 연기 위 연기는 화염이 되고, 화염 위에 또 떨어지면 폭발이 벽을 부수며 사방으로 번진다. 규정 인원의 희생자를 구하면 승리, 너무 많이 잃거나 건물이 붕괴하면 패배.

**재미요소:** `FE-ESCALATION` — 핫스팟·구조 손상이 누적되며 건물이 회복 불능으로 기울어가는 점증. `FE-EMERGENCE` — 폭발이 벽을 부숴 지형 자체가 바뀌고 화염 경로가 창발적으로 열림. `FE-RISK-REWARD` — 안쪽 깊숙한 희생자를 노릴수록 퇴로가 위험해지는 저울질. `FE-TENSION` — 다음 주사위가 어디에 떨어질지 모르는 매 턴 끝의 조마조마함.

**핵심 메카닉:**
- AP 경제: 턴마다 AP로 이동·문 개폐·진압(연기→제거, 화염→연기)·희생자 운반, 일부 AP 이월 가능. 역할별 특화 AP.
- 확산 3단: 빈 칸 연기 → 연기 위 연기 = 화염 → 화염 위 = 폭발(직선 4방향으로 화염 전파, 벽은 손상 큐브).
- POI 토큰: 희생자 후보가 뒤집힌 채 배치(허탕 포함) — 가 봐야 아는 탐색.
- 승패: 희생자 규정 수 구출로 승리 / 희생자 다수 손실 또는 구조 손상 누적에 의한 건물 붕괴로 패배.
- 가족 모드/전문가 모드(위험물·핫스팟·차량) 2단 난도.

**웹 번안:** ✅ `puzzle-game` — 공식 1인 지원(1~6인)에 시스템이 상대라 솔로 무손실. 그리드 + 벽/문을 에지로 갖는 보드모델, 확산 틱은 큐 연출(연기 피어오름→화염 점화→폭발 셰이크)이 게임필의 핵심. 시드 데일리 건물 배치 + 구출 수·잔여 체력 점수화, localStorage 베스트.

**조합 훅:** Sokoban(FE-PLANNING)과 교배 — 희생자 운반 동선을 미는/끄는 퍼즐로 정밀화한 턴제 구조 퍼즐(FE-PLANNING+FE-RISK-REWARD); Bomberman류 arcade-classic 이식 — 확산을 실시간으로 돌린 소화 액션(FE-EMERGENCE+FE-JUICE).

**IP 주의:** 'Flash Point: Fire Rescue' 상표·Indie Boards & Cards 보드 아트·역할 일러스트는 금지 — 연기/화염/폭발 3단 확산·POI 탐색·AP 경제는 자유.

### Magic Maze (2017)

**코어:** 실시간·무언 협력 — 각 플레이어가 '북쪽 이동' '동쪽 이동' '에스컬레이터' '탐험' 같은 **동작 하나씩만** 담당하고, 턴 없이 아무나 아무 폰이든 자기 동작으로만 움직여, 쇼핑몰에서 4영웅이 각자 목표 물건을 동시에 훔치고 각자 출구로 탈출한다. 모래시계가 다 떨어지기 전에 — 말은 금지(타이머를 뒤집은 직후의 대화 창은 예외), '뭐라도 해!' 폰으로 상대를 응시 재촉하는 것만 허용.

**재미요소:** `FE-CONSTRAINT` — 내가 할 수 있는 일이 단 한 방향뿐이라는 극단 제약이 코미디와 퍼즐을 동시에 만듦. `FE-TIMING` — 폰 하나를 여럿이 릴레이로 움직이는 실시간 핸드오프 박자. `FE-TENSION` — 모래시계 잔량과 침묵의 압박. `FE-FLOW` — 손발이 맞기 시작했을 때의 무언 질주감.

**핵심 메카닉:**
- 동작 타일 분배: 이동 4방위·에스컬레이터·차원문·탐험(새 타일 공개)을 인원에 따라 나눠 가짐 — 합쳐야 한 명분.
- 실시간·무턴: 유용하다고 판단되는 순간 누구든 자기 동작을 아무 폰에 수행.
- 모래시계: 소진 시 즉시 패배, 맵의 모래시계 칸에서 뒤집기(횟수 제한) — 뒤집은 직후에는 누군가 폰을 움직이기 전까지 자유 대화 허용(기본 규칙).
- 진행 2막: 4영웅이 각자 절도 대상 칸에 도달 → **동시 절도** → 경보 속 각자 출구로 탈출.
- 탐험으로 맵이 점차 확장되는 타일 공개.

**웹 번안:** ⚠️ `arcade-classic` — 분업의 사회적 코미디는 다인 본질이라 보정 필요. 유효한 솔로 번안: **동작 모드 전환 비용** — 화면 하단에 동작 버튼(북/동/남/서/에스컬레이터/탐험)을 두되 한 번에 한 모드만 활성, 전환에 짧은 쿨다운을 부과해 '모든 걸 할 수 있지만 동시에는 하나'라는 제약을 보존한 실시간 멀티태스킹 퍼즐로 만든다. 모래시계 칸 = 시간 연장 픽업, MobileHarness 가상 버튼 + 폰 탭 선택. 시드 데일리 몰 배치.

**조합 훅:** Pac-Man(FE-TENSION)과 교배 — 경보 후 경비원 추적이 붙는 탈출 2막(FE-TENSION+FE-TIMING); Lemmings(FE-PLANNING)와 교배 — 자동 전진하는 4영웅에게 동작을 꽂아 넣는 라우팅 퍼즐(FE-CONSTRAINT+FE-PLANNING).

**IP 주의:** 'Magic Maze' 게임명·Sit Down! 판본의 몰 타일 아트·'뭐라도 해!' 폰 디자인은 금지 — 동작 분담·실시간 무턴·동시 절도 구조는 자유.

### Mysterium (2015)

**코어:** 한 명이 말 못 하는 유령이 되어, 초현실 그림뿐인 환상 카드만으로 각 심령술사에게 배정된 용의자→장소→흉기를 차례로 암시한다. 심령술사들은 7라운드(시계) 안에 각자 자기 조합을 모두 맞히고, 마지막에 공유 환상 3장으로 진범 하나를 투표 지목해야 전원 승리.

**재미요소:** `FE-DEDUCTION` — '이 그림의 무엇이 단서인가(색? 모티프? 분위기?)'를 소거법으로 좁히는 연상 연역. `FE-NARRATIVE` — 유령의 집·미해결 살인이라는 분위기가 모든 추리에 서사적 무게를 줌. `FE-HIDDEN-INFO` — 정답이 스크린 뒤에 물리적으로 존재하고 매 라운드 부분 해제되는 구조. `FE-SOCIAL` — 남의 추리에 투시 토큰으로 베팅하는 관전 재미.

**핵심 메카닉:**
- 유령은 환상 카드 핸드(7장)에서 1장 이상을 골라 각 심령술사에게 전달 — 발화·제스처 금지.
- 단계 진행: 용의자 → 장소 → 흉기를 심령술사별로 순서대로 적중해야 다음 단계로.
- 라운드 시계 7칸: 시간 안에 전원이 자기 조합을 완성 못 하면 패배.
- 투시 토큰: 동료의 추리가 맞을지 베팅해 적중 시 최종 단계에서 더 많은 공유 환상을 볼 권리 획득.
- 최종 투표: 공유 환상 3장(용의자·장소·흉기 각 1장)으로 진범 후보 중 하나를 지목.

**웹 번안:** ⚠️ `puzzle-game` — 인간 유령의 연상 창의성과 해석의 어긋남이 본질이라 보정 필요. 유효한 솔로 번안: **심령술사 측 고정** — 환상 카드와 대상 카드에 사전 저작된 의미 태그(모티프·색·정서)를 부여하고, AI 유령이 태그 겹침 휴리스틱으로 카드를 고르게 하면 '왜 이 카드를 줬나'의 연상 연역이 보존된다(태그 데이터가 콘텐츠 비용). 카드 아트는 VectorForge 절차 생성 + 저작 모티프 조합으로 해결, 7라운드 시계·정답 공개 연출은 그대로. 날짜 시드 사건 데일리.

**조합 훅:** Wordle(FE-DEDUCTION)과 교배 — 라운드마다 환상 단서로 용의자 후보를 소거하는 데일리 추리(FE-DEDUCTION+FE-HIDDEN-INFO); story-architect 연계 — 사건·인물·동기를 절차 생성해 매판 다른 미스터리 서사(FE-NARRATIVE+FE-SURPRISE).

**IP 주의:** 'Mysterium' 게임명·Libellud의 초현실 환상 카드 일러스트는 금지(이 게임은 카드 아트가 표현의 핵심이라 특히 주의) — 무언 연상 단서·단계 추리·라운드 시계 메카닉은 자유.

### Sky Team (2023)

**코어:** 파일럿과 부조종사 단 둘이서, 매 라운드 스크린 뒤에서 각자 주사위 4개를 비공개로 굴리고 말 없이 교대로 계기판 슬롯(기울기 축·엔진·플랩·랜딩기어·브레이크·관제)에 배치해, 7라운드의 접근 끝에 기체를 활주로에 무사히 내려놓는 2인 분업 협력. Spiel des Jahres 2024.

**재미요소:** `FE-LUCK-TAME` — 나쁜 굴림을 어느 슬롯에 흘려보낼지, 커피로 값을 보정할지의 운 길들이기. `FE-TENSION` — 기울기 한계 초과·속도 초과·관제 미처리 하나로 즉사하는 일발 긴장. `FE-HIDDEN-INFO` — '파트너가 왜 저 슬롯에 먼저 놨지?'에서 상대 주사위를 역추론. `FE-CONSTRAINT` — 매 라운드 의무 배치 슬롯(축·엔진)이 만드는 빠듯한 배정 퍼즐.

**핵심 메카닉:**
- 라운드 구조: 전략 의논(단, 주사위 값·배치 지시는 금지) → 비공개 굴림(공동 리롤 토큰 — 횟수 제한 자원) → 한 개씩 교대 배치.
- 기울기 축: 양측이 놓은 값의 차만큼 기체가 기울어짐 — 한계 초과 시 추락.
- 엔진: 양측 합이 전진 속도를 결정 — 접근 트랙을 너무 빨리/늦게 소화하면 위험.
- 커피 토큰: 슬롯에 모아 두면 주사위 값을 ±1 보정 — 운 길들이기의 핵심 자원.
- 착륙 판정: 랜딩기어·플랩 전개 완료(표시등 녹색)·활주로 항공기 관제 제거·정렬·감속·브레이크 충족 시 승리, 공항별 난도 변형.

**웹 번안:** ⚠️ `puzzle-game` — 2인 비공개 분업이 코어라 보정 필요하나 질 좋은 솔로 번안이 가능한 편: **AI 부조종사의 주사위는 은닉하되 배치 우선순위(휴리스틱)를 읽히게** 만들면, '저기에 놨다 = 내가 필요한 값이 없다'는 역추론(FE-HIDDEN-INFO)이 시스템 상대로도 보존된다. 계기판은 슬롯 그리드 보드모델 + 기울기 게이지·접근 트랙 HUD, 주사위 드래그 배치 입력. 공항(난도 변형)을 날짜 시드 데일리로 — 착륙 여부 + 잔여 커피가 공유 점수.

**조합 훅:** Ganz schön clever(FE-LUCK-TAME)와 교배 — 주사위 배정이 콤보 보너스를 연쇄시키는 계기판 기입(FE-LUCK-TAME+FE-COMBO); Railroad Ink와 교배 — 같은 시드 주사위로 모두가 같은 착륙 조건에 도전하는 데일리 챌린지(FE-LUCK-TAME+FE-SOCIAL).

**IP 주의:** 'Sky Team' 게임명·Scorpion Masque의 계기판 아트·공항 명칭 구성은 금지 — 비공개 주사위 교대 배치·기울기 축·커피 보정 메카닉은 자유.
