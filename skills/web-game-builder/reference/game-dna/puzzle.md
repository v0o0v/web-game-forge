## Tetris (1984)
**왜 많이 플레이됐나:** 규칙은 5초 만에 이해되지만 숙련 천장은 평생 안 닿는 "쉽게 배우고 끝없이 깊은" 완벽한 단순성 때문. 한 판이 짧고 점수 갱신 욕구가 즉각적이라 누구나 한 번 더 누른다.
**장르 / 시점:** 낙하 블록 퍼즐 (falling-block puzzle) / 고정 화면 세로 보드. 정면 2D 그리드 뷰(10×20 셀 표준), 블록은 위에서 아래로 수직 낙하.
**코어 루프:** 위에서 떨어지는 테트로미노를 좌우 이동·회전으로 빈틈 없이 쌓고, 가로 한 줄이 꽉 차면 그 줄을 소거해 보드 높이를 낮춘다 — 쌓임이 천장에 닿기 전까지 이 판단을 초당 여러 번 반복한다.
**핵심 재미요소:**
- `FE-FLOW` 몰입 흐름 — 블록 낙하·이동·회전·고정이 끊김 없이 이어지고, 손이 보드 상태를 거의 반사적으로 처리하게 되는 무아지경 리듬. 속도가 빨라질수록 '생각 없이 손이 먼저 움직이는' 플로우 상태에 빠진다.
- `FE-ESCALATION` 점증 압박 — 라인을 지울수록 레벨이 오르고 낙하 속도(스텝 딜레이)가 단축돼 판단 시간이 점점 줄어든다. 후반엔 거의 즉시 내려와 긴장이 극대화된다.
- `FE-MASTERY` 숙련 표현 — T-스핀·테트리스(4줄 동시 소거)·완벽 클리어 등 고급 기술과 하드드롭 타이밍으로 실력 천장이 매우 높다. 자기 최고 점수·최고 레벨 경신이 핵심 동기.
- `FE-TENSION` 긴장·니어미스 — 보드가 천장 근처까지 차올랐다가 절묘한 회전·끼워넣기로 여러 줄을 한 번에 비워 회생하는 아슬아슬한 순간의 쾌감.
**핵심 메카닉:**
- 7종 테트로미노(I,O,T,S,Z,J,L)를 4×4 행렬 또는 좌표 오프셋으로 정의하고 보드 상단 중앙에서 랜덤(7-bag 권장) 스폰. O는 회전 불변, I/S/Z는 사실상 2상태, T/J/L은 4상태.
- 레벨별 스텝 딜레이마다 현재 피스를 1칸 하강. 바닥·기존 블록 충돌 시 board[row][col]에 고정 후 라인 검사 → 새 피스 스폰.
- 회전: 정사각 피스 행렬을 전치 후 각 행 역순으로 뒤집어 시계방향 회전 구현, 충돌 시 wall kick으로 좌우 1~2칸 보정 시도.
- 라인 클리어: 꽉 찬 행을 board.splice로 제거하고 상단에 빈 행 추가. 동시 소거 줄 수(1/2/3/4)에 따라 점수 가중(테트리스=4줄 보너스).
- 소프트드롭(↓ 가속 낙하)·하드드롭(Space 즉시 바닥), next-piece 미리보기, 선택적 hold 슬롯.
**난이도·진행 곡선:** 레벨은 누적 소거 라인 수로 상승, 레벨↑마다 낙하 스텝 딜레이 단축(예: 800ms→ 점차 50ms대). 초반은 여유롭게 모양 학습, 중반부터 속도 압박, 후반은 거의 즉시 낙하로 반사신경·선읽기 시험. 별도 스테이지 없는 단일 무한 모드 + 점수/레벨이 유일한 진행 지표.
**게임필·연출:** 블록 고정 시 짧은 'bump' 칩사운드 + 미세 락딜레이, 라인 소거 시 해당 행 플래시·축소 트윈 + 'coin'류 상승 SFX, 테트리스(4줄)는 더 화려한 연출·스크린셰이크. 하드드롭은 잔상·낙하 라인 이펙트로 묵직함. 게임오버는 보드 전체 그레이아웃 + 'die' 사운드. juice-fx로 손맛 강화.
**끈끈함(리텐션):** 한 판이 수십 초~수 분으로 짧고 실패 원인이 항상 '내 쌓기 판단'이라 즉시 재도전이 자연스럽다(자기 책임 귀인). 점수·레벨 자기 기록이 명확한 목표로 남아 "딱 한 판만 더"가 끝없이 이어진다. 절차적 피스 순서로 매 판이 미세하게 달라 질리지 않는다.
**우리 엔진 재현도:** ✅ · 스킬 [`puzzle-game`](../../../puzzle-game/SKILL.md) · 엔진 PixelForge, ChipAudio, MobileHarness, juice-fx, game-ui-hud — puzzle-game 스킬이 Tetris를 1급 레시피로 명시(보드 모델/렌더 분리, 테트로미노 7종, 회전 전치+행역순, wall kick 기본, splice 라인클리어). 물리 불필요(Arcade 미사용)한 순수 로직 그리드라 코드생성 신뢰도 높음. board[row][col] 단일 상태소스 + renderBoard()로 Phaser Rectangle/Image 갱신. 블록 스프라이트는 PixelForge 단색 팔레트로 즉시 생성, SFX는 ChipAudio bump/coin/die. 모바일은 MobileHarness 스케일 + 스와이프(이동)·탭(회전)·아래 스와이프(드롭). 순수 단일플레이 로직 그리드라 서버·3D·대량 라이선스 콘텐츠 전혀 불필요 → 단일플레이 웹 기준 ✅ 적정. 단순화/주의: SRS 정식 회전·정확한 락딜레이·7-bag·고급 T-스핀 판정은 정밀 튜닝 필요(기본 wall kick으로 충분), 멀티플레이 대전(가비지 라인)은 ❌ — 단일플레이 점수 모드로 축소.
**조합 훅:** endless-runner에 '낙하 블록 회피' 역발상: 옆스크롤 주자가 위에서 떨어지는 테트로미노 더미를 피하거나 줄 맞춰 디딤발판으로 쌓는 하이브리드; topdown-shooter에 '탄막 정리' 변주: 격자에 쌓이는 적 블록을 같은 색 4종으로 줄맞춰 소거해 한 번에 파괴하는 라인클리어 슈터; arcade-classic에 '점증 속도 + 자기기록' 코어 이식: 어떤 미니게임이든 레벨업마다 가속되는 스텝 타이머와 best-score 갱신 루프로 한 판 더 욕구 주입.
**IP 안전 메모:** 'Tetris'는 등록 상표 — 게임 내 타이틀·스토어 명칭으로 사용 금지(메카닉 설명용으로만 언급). 원작의 테트로미노 색 배열(공식 가이드라인 컬러)·로고 폰트·코로부시카 등 원곡 음악·공식 스프라이트/효과음 일체 미사용. 재현 시 절차적으로: 블록은 PixelForge 자체 CC0 팔레트(원작과 다른 색조합), 사운드는 ChipAudio 생성 8비트, 폰트는 자체/오픈 폰트. '낙하 블록 줄맞추기 퍼즐' 같은 일반 메카닉 명칭으로 환기하고 고유 타이틀(예: 'Stackfall', 'Linedrop')을 새로 부여한다. ip-license-guard 스킬로 최종 점검.

## Candy Crush Saga (2012)
**왜 많이 플레이됐나:** 짧고 즉각적인 스왑 한 번이 캐스케이드 연쇄로 폭발하는 도파민 루프에, 누구나 1분 안에 배우는 직관성과 '레벨 한 판 더' 구조가 결합돼 캐주얼층까지 대규모로 흡수했다. 라이프 시스템과 맵 진행이 세션을 짧게 끊으며 장기 리텐션을 만들었다.
**장르 / 시점:** 매치3 퍼즐 (스왑형 타일 매칭) / 탑다운 고정 그리드를 정면으로 내려다보는 2D 평면. 정적 카메라이며, 보드는 레벨마다 형태가 다른 비정형 그리드(흔히 한 변 9칸 안팎, 구멍·막힘 영역 포함)다.
**코어 루프:** 인접한 두 타일을 스왑해 같은 색 3개 이상을 만들면 타일이 터지고, 위 타일이 중력으로 떨어지며 빈칸이 리필되어 또 다른 매치가 자동으로 연쇄(캐스케이드)된다. 제한된 이동 수 안에서 레벨 목표(점수/특정 타일 제거 등)를 달성하는 것이 한 판이다.
**핵심 재미요소:**
- `FE-COMBO` 연쇄·콤보 — 한 번의 스왑이 매치→제거→낙하→리필→재매치로 캐스케이드되며 점수가 연쇄적으로 불어난다. 내가 의도하지 않은 추가 연쇄가 '굴러떨어질 때'의 쾌감이 이 게임의 심장.
- `FE-AHA` 통찰·아하 — 꽉 막힌 보드에서 특수 캔디를 만들 한 수, 혹은 목표 타일을 무너뜨릴 결정적 스왑을 찾아내는 순간의 발견감. 보드 전체를 스캔해 최적 수를 읽는 퍼즐 해법의 쾌감.
- `FE-CONSTRAINT` 제약 퍼즐 — 이동 수 제한(또는 시간 제한)이라는 빡빡한 자원 안에서 목표를 달성해야 한다. 한 수의 효율을 극대화하고 특수 캔디 콤보를 아껴 쓰는 최적화 압박이 난도의 본질.
- `FE-JUST-ONE-MORE` 한 판 더 — 레벨 단위가 1~3분으로 짧고, 실패해도 즉시 재시작 가능하며 별점·맵 진행 갈증이 '딱 한 판만 더'를 부른다. 라이프 소진이 세션을 끊어 오히려 다음 접속을 유도.
**핵심 메카닉:**
- 보드 모델 board[row][col]을 단일 상태 소스로 두고, 인접 두 타일 스왑 → 가로/세로 3+ 매치 탐색 → 매칭 제거 → 중력 낙하 → 빈칸 랜덤 리필 → 연쇄 매치 재탐색 루프(puzzle-game Match-3 레시피 그대로).
- 스왑 후 매치가 없으면 스왑을 되돌리는 무효 처리(invalid swap revert) + 흔들림 피드백.
- 특수 캔디 생성 규칙: 4매치=줄 제거(라인 블래스트/원작 striped candy 메카닉), 5매치 직선=색깔 폭탄(같은 색 전체 제거/원작 color bomb), L자·T자 매치(보통 5개)=포장 캔디형 주변 3×3 폭발(원작 wrapped candy). 특수+특수 스왑 시 강화 콤보.
- 레벨별 목표 타입: (a) 제한 이동 수 안에 목표 점수, (b) 특정 색 N개 제거, (c) 하단의 '젤리/장애물 타일' 모두 제거, (d) 재료 타일을 보드 바닥까지 떨어뜨리기.
- 라이프(하트) 시스템: 실패 시 1 소모, 일정 실시간(원작 기준 약 30분, 최대 5개)마다 1 회복. 별 1~3개로 클리어 등급 부여 + 맵 노드 잠금 해제.
**난이도·진행 곡선:** 초반 레벨은 단순 점수/색 제거로 매치3 기본기를 가르치고, 점차 이동 수 축소·장애물 타일(잼/초콜릿 번식 타일/뚜껑)·다중 목표를 더해 난도를 점증한다. 특수 캔디 조합이 사실상 필수가 되는 중후반 '벽 레벨'이 결제·재도전을 유도. 맵은 선형 노드 진행이며, 레벨 클리어로 다음 노드가 열린다. 우리 재현은 15~30개 손제작 레벨 + 난도 파라미터(보드 크기/이동 수/목표값/장애물 비율) 곡선으로 축소 재현.
**게임필·연출:** 타일이 터질 때 스케일 팝 + 파티클 스파클, 캐스케이드마다 점점 올라가는 음 높이의 콤보 사운드 스택, 특수 캔디 발동 시 화면 라인 스윕/플래시, 점수 카운터 롤업이 핵심. 라이프 소진/레벨 클리어 시 스타 연출과 팡파르. 손맛은 '연쇄가 굴러갈 때 멈추지 않고 터지는' 리듬에서 나온다. juice-fx로 셰이크·파티클·사운드 스택을 강하게 깔수록 캐주얼 만족도가 급상승.
**끈끈함(리텐션):** 캐스케이드는 부분적으로 운(RNG 리필)에 좌우돼 '내 실력 + 약간의 행운'이라는 통제감과 변주를 동시에 주고, 별점·맵 진행이라는 가시적 수집 욕구가 장기 동기를 만든다. 라이프 게이트가 세션을 짧게 끊어 '다 못 깬 레벨'에 대한 미완성 긴장을 남기고, 회복 타이머가 재접속을 강제한다. 짧은 루프 + 즉시 재시작이 '한 판 더'를 끝없이 부른다.
**우리 엔진 재현도:** ⚠️ · 스킬 `puzzle-game` · 엔진 PixelForge 또는 VectorForge(타일 스프라이트/특수 캔디 글로우), ChipAudio(매치·캐스케이드 음 높이 스택, 특수 발동음), MobileHarness(스와이프로 스왑 방향 판별, 스케일·DOM 가드), juice-fx(타일 팝·파티클·스크린 플래시·점수 롤업), game-ui-hud(이동 수/목표 진행도/별점 HUD), level-designer(레벨 목표·난도 파라미터 테이블) — 코어 매치3 루프(스왑·매치 탐색·중력·리필·캐스케이드)와 특수 캔디·이동 수 제한·별점·라이프는 puzzle-game의 Match-3 레시피로 ✅ 충실 재현 가능(물리 불필요, 순수 보드 로직). ⚠️인 이유는 메타·콘텐츠 규모: 원작 수천 개 레벨/서버 세이브/소셜 랭킹/실시간 라이프 동기화는 불가하므로, (1) 레벨은 15~30개 손제작 + 난도 파라미터 곡선으로 축소, (2) 라이프 회복·진행은 localStorage 기반 단일 기기 저장으로 대체, (3) 친구 랭킹/리더보드는 로컬 베스트 스코어로 축소, (4) 결제·뽑기 제거. 캐스케이드 애니메이션은 Phaser tween 체인으로, 낙하는 보드 인덱스 보간으로 처리. 비정형(구멍 뚫린) 보드는 셀 유효성 마스크로 표현 가능하나 손제작 레벨 수만큼 디자인 비용 발생.
**조합 훅:** endless-runner에 이식: 달리는 도중 하단에 미니 매치3 보드를 띄워, 3매치를 만들면 대시·실드가 발동하는 '매치로 가속하는' 하이브리드; topdown-shooter에 이식: 적을 처치하면 색 타일이 떨어지고, 같은 색 3개를 스왑 정렬하면 그 색의 강력한 광역기가 발동하는 '퍼즐 무기 장전' 구조; arcade-classic에 이식: 제한 시간 내 캐스케이드 최대 연쇄를 노리는 아케이드 점수 모드(레벨/맵 제거, 순수 FE-COMBO+FE-JUST-ONE-MORE 리더보드 챌린지).
**IP 안전 메모:** 금지: 'Candy Crush'·'Saga' 명칭/로고/폰트, 원작 캔디 스프라이트(빨간 젤리빈·줄무늬 캔디·컬러 폭탄 등 고유 디자인)와 음성('Sweet!','Delicious!','Divine!' 보이스), 'Tiffi/Mr.Toffee' 캐릭터, 원작 BGM·효과음을 그대로 쓰지 말 것. IP-safe 환기: 캔디 대신 추상 보석/과일/도형 등 자체 팔레트를 PixelForge/VectorForge로 절차 생성, 특수 캔디는 '라인/색폭탄/광역'이라는 메카닉만 차용하되 자체 디자인·이름(예: 라인 블래스터, 컬러 봄)으로, 보이스라인은 ChipAudio 자체 사운드로 대체. 매치3 스왑·캐스케이드·이동 수 제한은 장르 보편 메카닉이라 자유롭게 구현 가능 — 표현물(아트/사운드/명칭)만 100% 자체 제작하면 안전.

## 2048 (2014)
**왜 많이 플레이됐나:** 규칙이 한 줄로 설명되는데(같은 수 합치기) 보드 가득 차면 끝이라 한 판이 짧고 즉시 다시 도전하게 만든다. 오픈소스 무료 웹게임이라 링크 한 번으로 누구나 즉시 플레이, 점수 자랑이 쉬워 바이럴로 퍼졌다.
**장르 / 시점:** 슬라이드 머지 퍼즐 (그리드 기반 단일 플레이어) / 평면 2D 추상 그리드 정면 고정 시점 — 4x4 정사각 보드 전체를 한 화면에 표시, 스크롤 없음.
**코어 루프:** 방향(← → ↑ ↓ 또는 스와이프)을 입력하면 모든 타일이 그 방향으로 밀려가며 같은 숫자끼리 합쳐지고(2+2=4), 이동이 일어났을 때만 빈 칸에 새 타일(2 또는 4)이 하나 생긴다. 더 큰 수를 만들려고 방향을 고르고, 보드가 꽉 차 이동 불가가 되면 종료된다.
**핵심 재미요소:**
- `FE-JUST-ONE-MORE` 한 판 더 — 한 수가 1초, 한 판이 수 분이라 게임오버 직후 '이번엔 더 큰 수를' 하며 즉시 재시작. 최고 점수 갱신 욕구가 재도전을 반복시킨다.
- `FE-AHA` 통찰·아하 — 큰 타일을 한쪽 구석에 몰아 고정하고 그 줄을 안 건드리는 '코너 전략'을 스스로 발견하는 순간의 쾌감. 규칙은 단순하나 최적해 탐색의 깊이가 있다.
- `FE-CONSTRAINT` 제약 퍼즐 — 16칸이라는 한정된 공간 안에서 매 수마다 새 타일이 자리를 잠식한다. 빈 칸을 자원처럼 아껴 쓰며 머지 효율을 최적화하는 것이 핵심.
- `FE-TENSION` 긴장·니어미스 — 보드가 거의 다 찼는데 합칠 짝이 안 보일 때의 조마조마함. 마지막 빈 칸 하나로 연쇄 머지를 터뜨려 살아나는 아슬아슬한 회복의 쾌감.
**핵심 메카닉:**
- 4x4 board[row][col] 2D 배열을 유일한 상태 소스로 두고, 방향 입력 시 한 축 슬라이드+머지 로직(0 제거→인접 동일값 합산→재패딩)을 적용. 다른 3방향은 보드를 회전/전치 후 동일 함수 재사용.
- 머지된 타일은 같은 입력 한 번 안에서 다시 머지되지 않도록 플래그 처리(연속 4-4-4-4가 한 번에 16이 되지 않게 2개씩만 합침).
- 점수 계산: 머지가 일어날 때마다 '합쳐져 생긴 타일의 값'을 점수에 가산(2+2→+4, 8+8→+16). 한 입력에서 여러 머지가 발생하면 각 결과값을 모두 합산. 이 단일 점수 지표가 최고 기록 경신·비교의 기준.
- 이동이 실제로 일어난 경우(moved=true)에만 빈 칸 중 랜덤 위치에 90% 2 / 10% 4 타일 스폰.
- 게임오버 판정: 빈 칸이 없고 가로·세로 어느 방향으로도 인접 동일값이 없으면 더 이상 이동 불가 → 종료.
- 타일 값별 색상 매핑(2,4,8...2048)으로 수가 커질수록 색이 진해져 진행도를 색으로 직관 표현.
- 점수·최고 점수 localStorage 저장으로 세션 간 기록 유지.
**난이도·진행 곡선:** 난이도는 외부에서 주어지지 않고 내부적으로 점증한다 — 수가 커질수록 같은 짝을 만들기 어려워지고 빈 칸이 귀해져 보드 운영 압박이 자연 상승. 2(쉬움)→128(전략 필요)→512(고난도)→2048(승리)로 이어지는 자가 점증 곡선. 2048 달성 후에도 계속 진행(4096, 8192...) 가능한 무한 모드로 숙련 천장을 열어둔다.
**게임필·연출:** 타일이 목표 칸까지 스르륵 미끄러지는 슬라이드 트윈(Quad.out 80~120ms)이 핵심 손맛. 머지 순간 합쳐진 타일이 살짝 커졌다 돌아오는 스쿼시(scale yoyo)와 새 타일의 팝-인(Back.out)이 만족감을 준다. 머지 시 '코인'류 짧은 8비트 SFX, 큰 수 달성 시 더 높은 톤. 새 타일 스폰은 부드러운 페이드+스케일로 등장.
**끈끈함(리텐션):** 짧은 루프 + 명확한 점수 지표 + '내 실수로 막혔다'는 납득(랜덤 스폰은 있지만 운영 책임이 본인에게 있음)이 결합해 재도전을 부른다. 점수가 단일 숫자로 환산돼 자기 기록 경신과 타인과의 비교가 쉬워 'just one more' 충동이 끊이지 않는다.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 PixelForge, VectorForge, ChipAudio, MobileHarness, juice-fx — 물리 불필요한 순수 보드 로직이라 Arcade/Matter 없이 완전 재현 가능. puzzle-game 스킬에 2048 슬라이드+머지+스폰 레시피가 이미 포함돼 있어 그대로 사용. 타일 비주얼은 VectorForge(둥근 사각+숫자 텍스트)가 IP-safe하면서도 깔끔, 픽셀 테마면 PixelForge. 슬라이드/머지/팝 트윈과 셰이크는 juice-fx로, 머지/게임오버 SFX는 ChipAudio로 생성. 모바일 스와이프 방향 판별은 MobileHarness + pointerdown/pointerup delta. 점수 가산(머지 결과값 합산)·localStorage 최고점 저장도 순수 JS라 추가 부담 없음. 서버·멀티·3D 요소가 전혀 없어 축소 없이 100% 재현.
**조합 훅:** endless-runner에 '머지 레인' 도입 — 달려오며 같은 숫자 게이트를 통과해 캐릭터 수치를 합치고 길 끝의 큰 적을 넘어서는 슬라이드 머지+질주 하이브리드; topdown-shooter에 '탄환 머지' — 같은 등급 탄/드론을 합쳐 상위 무기로 업그레이드, 보드 운영 대신 화면 운영으로 FE-CONSTRAINT 이식; arcade-classic 시간제한 변형 — 제한 시간 안에 목표 타일을 만드는 FE-ESCALATION 버전으로 긴장감 강화; puzzle-game 매치3와 결합 — 슬라이드로 모은 같은 색을 3개 이상 인접 시 추가 보너스 머지가 터지는 FE-COMBO 캐스케이드.
**IP 안전 메모:** '2048'이라는 게임명·원작 특유의 베이지/오렌지 색 팔레트·서체(원작은 Clear Sans)·그 정확한 타일 색 코드 값을 그대로 베끼지 말 것. 메카닉(슬라이드 머지, 4x4, 2배수 합산, 랜덤 스폰, 머지 결과값 점수 가산)은 수학 규칙이라 자유롭게 사용 가능. IP-safe 환기법: 게임명을 'Merge Slide', 'Double Up' 등 일반 명칭으로, 타일 색·서체는 VectorForge/PixelForge로 새로 디자인(예: 보석/동물/우주 테마로 값을 표현), 합산 규칙도 2배수 대신 다른 수열(피보나치 등)로 변주해 차별화. 모든 에셋·사운드는 코드 절차 생성(CC0).

## Threes (2014)
**왜 많이 플레이됐나:** 짧고 우아한 규칙(1+2=3, 같은 수끼리 두 배)인데 한 수 한 수가 깊은 수읽기를 요구해 "쉽게 배우고 평생 못 끝내는" 퍼즐로 자리 잡았다. 숫자 타일에 표정·소리를 입힌 캐릭터 감성이 차가운 수학 퍼즐을 따뜻하게 만들어 대중적 호감을 얻었다.
**장르 / 시점:** 슬라이드-병합 수(數) 퍼즐 (slide-and-merge number puzzle) / 탑다운 2D 그리드(4x4), 세로 화면 고정.
**코어 루프:** 한 방향으로 스와이프하면 그 방향으로 움직일 수 있는 타일(빈칸이 있거나 1+2/동수 병합이 가능한 줄)만 딱 한 칸 시프트하고 막힌 행/열은 멈추며, 맞닿은 1+2 또는 같은 수 두 장이 병합된다. 실제로 이동이 일어난 쪽 반대편 가장자리에서 미리 예고된 새 타일 한 장이 들어온다. 이 한 수가 더 큰 수를 만들 길을 여는지 보드를 막는지를 매번 가늠하는 것이 30초 루프다.
**핵심 재미요소:**
- `FE-CONSTRAINT` 제약 퍼즐 — 4x4 16칸이라는 극단적으로 좁은 공간에서 매 수마다 새 타일이 강제로 들어와 칸을 잡아먹는다. 2048처럼 끝까지 미끄러지지 않고 한 칸씩만 움직이므로, 한정된 자리와 '들어올 다음 타일' 안에서 병합 라인을 최적화하는 자원 압박이 핵심 재미다.
- `FE-AHA` 통찰·아하 — 1과 2는 서로만 합쳐지고 3 이상은 같은 수끼리만 두 배가 된다는 규칙을 깨닫는 순간, 그리고 '큰 수를 한 모서리에 쌓고 사다리를 만든다'는 전략을 스스로 발견하는 순간의 쾌감. 보드가 꽉 차 보여도 한 수로 연쇄 정리가 풀리는 해법을 찾는 맛.
- `FE-TENSION` 긴장·니어미스 — 보드가 거의 꽉 차 가능한 방향이 한두 개로 줄었을 때, 다음에 들어올 예고 타일이 보드를 끝장낼지 살릴지 아슬아슬하게 가늠하는 긴장. 큰 타일을 살리려 한 수를 버티는 순간의 조마조마함이 2048보다 신중하고 무겁다.
- `FE-JUST-ONE-MORE` 한 판 더 — 한 게임이 짧고 점수(최종 보드의 카드 가치 합)가 즉시 갱신되며 즉시 재시작이 가능해, 더 높은 카드를 노리고 '한 판 더'를 반복하게 된다. 자기 최고 기록과 가장 큰 카드 달성이 재도전 동기.
**핵심 메카닉:**
- 보드는 4x4 정수 배열이 유일 상태원. 0=빈칸, 1, 2, 3, 6, 12, 24... (3 이후 두 배). 렌더는 상태 변경 시점에만 renderBoard()로 갱신(puzzle-game 원칙).
- 병합 규칙: 1+2=3(또는 2+1=3), 그리고 3 이상은 같은 수 두 장만 두 배(3+3=6, 6+6=12...). 1+1, 2+2는 병합 불가 — 이 규칙이 2048과 결정적으로 다른 IP-safe 분기.
- 이동: 스와이프/방향키 한 번에 그 방향으로 움직일 수 있는 타일만 '딱 한 칸'만 시프트. 빈칸도 없고 유효 병합도 없는 막힌 행/열은 안 움직임(2048식 전체 끝까지 슬라이드 금지) — 줄마다 이동 여부가 갈리는 한 칸 이동이 신중함의 근원.
- 한 수에 한 셀은 한 번만 병합. 이동이 실제로 일어난 줄에만 반대쪽 가장자리에서 새 타일 1장 스폰.
- 다음 타일 예고(next preview): 들어올 카드를 화면 상단에 미리 1장 보여줌(원작은 색/값만 노출). 단 정확한 진입 위치(어느 행/열)는 안 알려줘 약간의 불확실성 유지.
- 스폰 분포: 초반엔 1/2/3 위주, 보드의 최대 카드가 커질수록 가끔 큰 보너스 카드(예: 6/12...)를 섞어 가중 RNG로 변주.
- 게임오버: 네 방향 모두 이동/병합 불가일 때. 점수=보드 위 모든 카드의 가치 합(1·2는 0점, 3 이상은 3=3점, 6=9점식 3의 거듭제곱 가치).
**난이도·진행 곡선:** 난도 곡선은 '들어오는 타일'과 '비는 공간'의 줄다리기로 자연 상승한다. 초반엔 1/2/3이 흔해 3을 쉽게 만들지만, 큰 카드를 만들수록 그 카드는 같은 수를 한 번 더 모아야만 자라므로 보드 점유율이 올라가고 운신 폭이 좁아진다. 외부 레벨이 없는 단일 무한 세션이며, 플레이어 실력에 따라 도달 가능한 최대 카드(48, 96, 192...)가 사실상의 진행 단계 역할을 한다.
**게임필·연출:** 타일이 한 칸 미끄러질 때 짧고 탄력 있는 트윈(ease로 살짝 오버슈트), 병합 순간 스쿼시&스트레치 팝과 작은 파티클, 새 타일은 가장자리에서 스케일 0→1로 톡 등장한다. 카드마다 부드러운 파스텔 컬러와 표정/숨쉬기 애니메이션을 주어 '살아 있는 캐릭터' 감성을 낸다. 조작감은 빠른 액션이 아니라 묵직하고 또박또박한 '한 수 두는' 손맛이 핵심 — 입력은 즉각 받되 연출은 100~150ms로 안정적이고 만족스럽게.
**끈끈함(리텐션):** 규칙은 30초면 배우지만 최적 전략(큰 수를 모서리에 고정하고 작은 수로 사다리 만들기, 1과 2의 재고 관리)은 끝이 없어 실력 천장이 매우 높다. 매 수가 되돌릴 수 없는 결정이라 '내가 더 잘 둘 수 있었다'는 납득과 다음 판 욕구가 동시에 생긴다. 캐릭터화된 타일이 정서적 애착을 만들어 단순 숫자 게임보다 다시 켜게 만든다.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 VectorForge(부드러운 파스텔 카드+표정 캐릭터), ChipAudio(슬라이드/병합/스폰 SFX, 오리지널 BGM), MobileHarness(세로 고정 스케일+스와이프 입력), juice-fx(병합 스쿼시·파티클·팝업 점수), game-ui-hud(점수·다음 타일 프리뷰·최고기록) — 순수 그리드 로직이라 서버·물리·3D 불필요로 충실 재현 가능. puzzle-game의 2048 슬라이드+머지 레시피를 베이스로 두 가지를 바꾸면 된다: (1) '끝까지 슬라이드'를 '움직일 수 있는 줄만 한 칸 시프트'로 변경, (2) 병합 판정을 2048의 '같은 수'에서 Threes식 '1+2 그리고 3이상 동수 배수'로 교체. 다음-타일 예고는 가중 RNG 큐로 구현. 캐릭터 감성은 VectorForge drawFn으로 카드별 표정/숨쉬기 프레임을 절차 생성해 IP-safe하게 대체. 원작의 정확한 카드 가치·스폰 가중치·보너스 카드 등장 규칙 표는 비공개이므로 체감상 유사하게 자체 튜닝(단순화)한다.
**조합 훅:** arcade-classic Snake/Breakout에 '같은 수 한 칸 시프트 병합'을 얹어, 먹이/벽돌이 숫자를 갖고 같은 수끼리 닿으면 합쳐지며 커지는 하이브리드(FE-CONSTRAINT+FE-AHA); endless-runner에서 레인 3개에 흐르는 숫자 타일을 좌우 한 칸 이동으로 1+2/동수 병합해 목표 수를 만드는 리듬형 머지 러너(FE-TIMING+FE-JUST-ONE-MORE); topdown-shooter의 적에게 숫자를 부여하고 같은 수 적을 충돌시켜 병합·소멸시키는 병합형 정리 슈팅(FE-COMBO+FE-TENSION).
**IP 안전 메모:** 원작 이름 'Threes', 시그니처 카드 캐릭터(눈·표정 디자인과 각 카드별 고유 페르소나/이름), 특유의 폰트·UI 컬러 팔레트, 오리지널 사운드/음악, 정확한 스폰 가중치·점수표는 사용 금지. 메카닉(한 칸 시프트, 1+2=3 후 동수 배수 병합, 다음 타일 예고, 보드 꽉 참 게임오버)은 아이디어/규칙이라 자유롭게 구현 가능. 감성은 VectorForge로 자체 디자인한 파스텔 둥근 카드 + 우리만의 표정/숨쉬기 애니로 '캐릭터화'만 차용해 IP-safe하게 환기하고, 캐릭터 이름·디자인은 완전 오리지널로 만든다. 'Threes'는 메카닉 설명 맥락에서만 표기하고 게임 타이틀/에셋엔 쓰지 않는다.

## Baba Is You (2019)
**왜 많이 플레이됐나:** 규칙 자체가 화면 위 단어블록으로 존재하고, 그 단어를 밀어 게임의 법칙을 실시간으로 다시 쓴다는 단 하나의 발상이 매 스테이지마다 새로운 "그게 되네?"의 충격을 준다. 좁은 그리드와 적은 요소만으로 무한에 가까운 횡적 사고 퍼즐을 뽑아내 평론·입소문이 폭발했다.
**장르 / 시점:** 규칙 조작(rule-manipulation) 소코반형 그리드 퍼즐 / 탑다운 격자(top-down grid), 고정 단일 화면 스테이지.
**코어 루프:** 방향키로 캐릭터를 한 칸씩 움직여 박스와 단어블록을 민다. 화면에 적힌 'X IS PUSH', 'FLAG IS WIN' 같은 규칙문장을 재배열해 무엇이 나이고·무엇이 벽이고·무엇이 승리인지를 바꾼 뒤, 새로 만든 규칙으로 WIN 타일에 도달한다.
**핵심 재미요소:**
- `FE-AHA` 통찰·아하 — 막힌 스테이지를 노려보다 'BABA IS WIN'으로 규칙을 비틀거나 'WALL IS YOU'로 조종 대상을 바꾸는 한 수가 떠오르는 순간, 풀이 전체가 한꺼번에 무너지듯 열리는 강렬한 깨달음이 핵심 쾌감.
- `FE-CONSTRAINT` 제약 퍼즐 — 화면 안 단어블록 수가 곧 사용 가능한 규칙의 전부. 'IS' 한 개, 'WIN' 한 개처럼 제한된 어휘를 어떻게 짜맞춰 목표를 달성할지 최적화하는 폐쇄형 퍼즐.
- `FE-EMERGENCE` 창발·시스템 상호작용 — 몇 안 되는 규칙 원자('IS'+속성)들이 조합되며 설계자도 예상 못 한 풀이가 튀어나온다. 'STOP을 PUSH로 만들어 길을 뚫는다' vs '내가 곧 깃발이 된다'처럼 동일 스테이지에서 서로 다른 시스템적 해법이 창발하고, 일부 스테이지는 의도된 우회/꼼수 해법까지 허용한다.
- `FE-MASTERY` 숙련 표현 — 초반 'IS PUSH/STOP'만 알면 풀리던 것이 후반엔 'HAS/MAKE/MOVE/HOT·MELT' 같은 규칙 상호작용 연쇄를 머릿속으로 시뮬레이션해야 풀려, 규칙 문법 자체에 대한 숙련 천장이 가파르게 높아짐.
**핵심 메카닉:**
- 보드는 `grid[row][col]`에 객체 ID 목록을 담는 2D 배열이 유일한 상태원천. 한 칸에 여러 객체(캐릭터+단어블록 등)가 겹칠 수 있어 칸당 스택을 유지한다.
- 단어블록은 NOUN(BABA/WALL/FLAG/ROCK), VERB('IS'), PROPERTY(YOU/WIN/PUSH/STOP/SINK/HOT/MELT/DEFEAT) 세 종류 타일. 이동마다 가로·세로로 'NOUN IS PROPERTY' 또는 'NOUN IS NOUN' 연속 3칸을 스캔해 활성 규칙 집합을 재계산한다. (원작은 AND/NOT/조건어로 3칸을 넘는 가변 길이 문장도 파싱하지만, 우리 재현은 3칸 고정 문장으로 단순화한다.)
- 이동 처리는 두 단계: (1)입력 방향으로 YOU 객체를 밀려는 시도 → PUSH 객체는 연쇄적으로 한 칸 밀고 STOP/경계면 전체 이동 취소, (2)이동 확정 후 규칙 재파싱 → WIN 동칸 판정·SINK/HOT&MELT/DEFEAT 같은 파괴 규칙 적용.
- 규칙 우선순위·충돌 해소: 'X IS YOU'가 사라지면 조종 불가(패배 아님, 무브 막힘) → 한 수 되돌리기(Undo) 필수. 매 이동을 스냅샷 스택에 저장해 Z키/버튼으로 무제한 Undo, R로 스테이지 리셋.
- 'NOUN IS NOUN'(예 'ROCK IS BABA')은 해당 칸의 객체 스프라이트·정체성을 통째로 변환. 변환 후 규칙 재적용으로 연쇄 변화가 일어난다.
- 스테이지는 코드/JSON 레벨맵으로 정의(level-designer). 클리어 시 다음 맵 로드, 월드맵 없이 선형/소규모 분기 진행으로 축소.
**난이도·진행 곡선:** 튜토리얼 스테이지는 'BABA IS YOU / FLAG IS WIN'을 그대로 주고 PUSH·STOP만 도입. 이후 규칙을 깨뜨려야(IS를 옮겨 끊기) 풀리는 단계, 정체성 변환(NOUN IS NOUN), 다중 규칙 상호작용(HOT/MELT, SINK, MAKE/HAS), 마지막엔 규칙을 만들어 자기 자신을 승리로 바꾸는 메타 해법으로 난도 상승. 한 스테이지 안에서는 짧지만, 한 칸 한 칸이 곧 깨달음의 단계라 체감 밀도가 높다.
**게임필·연출:** 조용하고 미니멀한 게임필 — 격자에 딱 맞아떨어지는 한 칸 이동, 단어블록이 밀릴 때의 깔끔한 스냅. 규칙이 갱신되는 순간 화면 전 객체의 외형/거동이 동시에 바뀌는 '세계 재정의'의 시각적 카타르시스가 핵심 연출. WIN 달성 시 짧은 반짝임과 청아한 사운드, 규칙 파싱 활성화 시 단어블록 미세 글로우로 '지금 이 문장이 살아있다'를 표현.
**끈끈함(리텐션):** 막힌 퍼즐이 머릿속을 떠나지 않는 '잠복 효과'가 강력하다 — 끄고 나서도 출퇴근길에 해법이 번뜩이며, 그 한 수가 맞아떨어졌을 때의 보상이 다음 스테이지로 즉시 끌어당긴다. Undo 무제한으로 실패 비용이 0에 가까워 부담 없이 실험을 반복하게 되고, '이 규칙들로 또 뭘 할 수 있지?'라는 호기심이 리텐션을 만든다.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 PixelForge, ChipAudio, MobileHarness, level-designer, game-ui-hud, juice-fx — 물리 불필요(Arcade·Matter 미사용) — 순수 그리드 로직이라 우리 스택과 정합도 최상. puzzle-game의 보드모델/렌더 분리 패턴을 그대로 쓰되, 칸당 단일값 대신 객체 스택 배열로 확장하고 매 이동 후 규칙 재파싱 함수를 넣는다. 단어블록 타일과 객체 스프라이트는 PixelForge 단색/픽셀 글리프로 IP-safe 자체 제작, SFX는 ChipAudio(이동 bump·승리 coin·변환 짧은 톤). Undo 스택은 매 이동 grid 깊은복사 스냅샷. 한계: 원작의 방대한 스테이지·월드맵·숨겨진 규칙(HAS/MAKE/MOVE 등 수십 개)과 AND/NOT/조건어 가변 문장 파싱은 전부 재현하면 콘텐츠·파서가 비대해지므로, 핵심 규칙 8종(YOU/WIN/PUSH/STOP/SINK/HOT/MELT/DEFEAT) + 정체성 변환 + 3칸 고정 문장 파싱만으로 10~20개 자작 스테이지로 축소 재현 권장. 레벨은 level-designer로 JSON 정의, 선형 진행.
**조합 훅:** endless-runner: 달리는 도중 좌우 레인 위에 'GAP IS SAFE' 'SPIKE IS PASS' 같은 규칙블록이 흘러오고, 점프 대신 규칙을 켜고 끄며 장애물을 통과하는 실시간 규칙조작 러너; topdown-shooter: 적·총알·벽의 속성을 'BULLET IS YOU' 'ENEMY IS FRIEND'로 한 칸짜리 규칙 패널을 밀어 전투 도중 교전 법칙을 비트는 아레나 슈터; arcade-classic(브레이크아웃): 블록에 PUSH/STOP/WIN 단어가 박혀 있어, 공으로 단어를 떨궈 'WALL IS WIN'을 완성하면 즉시 클리어되는 규칙조작 벽돌깨기; platformer-game: 발판·가시·문의 속성을 스테이지 한쪽 규칙 슬롯에 단어를 끼워 바꾸는 '내가 규칙을 짠다' 식 1인 퍼즐 플랫포머.
**IP 안전 메모:** 사용 금지: 'Baba'·'Keke'·'Me' 등 원작 캐릭터 이름, 원작 특유의 흰 토끼/벽돌 도트 스프라이트, 굵은 픽셀 폰트와 단어블록 디자인, Hempuli의 BGM·SFX, 'Baba Is You' 로고/상표. IP-safe 환기법: 메카닉('NOUN IS PROPERTY' 규칙 파싱, 단어블록 밀기, 정체성 변환, Undo)은 게임 시스템이라 자유롭게 구현하되, 캐릭터/속성 명칭은 자체 어휘로 교체(예 BABA→임의의 자작 마스코트명, FLAG→GOAL, ROCK→CRATE). 모든 스프라이트·폰트·단어 타일·사운드는 PixelForge/ChipAudio로 절차 생성(CC0). 스테이지 레이아웃은 원작 카피 금지, 동일 규칙 문법 위에서 자작.

## Monument Valley (2014)
**왜 많이 플레이됐나:** 에셔(Escher)풍 불가능 기하 착시를 손가락으로 직접 비틀어 길을 만드는 촉각적 쾌감과, 말없이 분위기로만 끌고 가는 미니멀한 아름다움이 "게임이라기보다 움직이는 예술품"이라는 입소문을 탔다. 짧고 우아한 한 입 크기 챕터라 비게이머도 끝까지 완주하기 쉬웠다.
**장르 / 시점:** 착시·불가능기하 환경 퍼즐 (조작형 디오라마 퍼즐) / 고정 등각투상(isometric) 디오라마 시점. 직교 투영 덕분에 2D 화면에서 "불가능한 연결"이 성립하는 것이 시점 자체가 메카닉.
**코어 루프:** 디오라마를 둘러보며 막힌 길을 찾고 → 회전 노브·슬라이딩 기둥·이동 발판 같은 구조물을 손가락으로 돌리거나 밀어 → 등각투상 화면상에서 끊긴 두 경로가 시각적으로 맞물려(겹쳐) 보이게 만들면 실제로 길이 이어지고, 캐릭터를 탭해 다음 지점으로 걷게 한다.
**핵심 재미요소:**
- `FE-AHA` 통찰·아하 — 물리적으로 불가능한 두 경로가 등각 화면에서 '겹쳐 보이면 실제로 이어진다'는 규칙을 스스로 발견하는 순간이 핵심 쾌감. 구조물을 한 번 더 돌리는 순간 막혔던 길이 톡 연결되는 깨달음.
- `FE-CONSTRAINT` 제약 퍼즐 — 한 레벨에 회전 노브 1~2개, 슬라이더 1개처럼 조작 가능한 요소가 극히 제한적. 적은 입력으로 정답 배치를 찾아내는 최적화의 묘미. 실패/죽음이 없고 오직 '맞는 배치냐'만 존재.
- `FE-NARRATIVE` 분위기·암시적 서사 — 대사가 거의 없이 색·기하·앰비언트 사운드로만 고요하고 신비로운 분위기를 형성. 명시적 스토리텔링보다는 침묵의 정서와 미적 톤이 핵심이며, 챕터마다 바뀌는 풍경·구조가 다음 방으로의 호기심을 자아낸다(강한 플롯 서사는 아님).
- `FE-JUICE` 감각 피드백 — 구조물을 돌릴 때의 부드러운 관성·스냅, 길이 연결되는 순간의 미세한 사운드·라이트 펄스, 캐릭터의 우아한 걸음 애니메이션이 조작을 '만지는' 손맛으로 만든다.
**핵심 메카닉:**
- 등각투상 그래프 연결: 각 발판/길 끝을 노드로 두고, 구조물 상태(회전 각도·슬라이드 위치)에 따라 두 노드의 화면 투영 좌표가 임계거리 이내로 일치하면 그래프에 edge를 동적으로 추가/삭제하는 connectivity 모델.
- 회전 노브: 특정 서브구조를 담은 Phaser Container를 탭/드래그로 90도 단위 스냅 회전(tween). 회전 후 노드 투영 좌표 재계산 → 연결 갱신.
- 슬라이딩 기둥/이동 발판: 컨테이너를 등각 축을 따라 보간 이동시켜 끊긴 길의 높이·위치를 맞춤. 이동 중에는 캐릭터가 함께 실려 가는 'platform-as-elevator' 처리.
- 캐릭터 경로 이동: 탭한 목표 노드까지 현재 그래프에서 BFS 최단경로 탐색 → waypoint tween 체인으로 등각 좌표를 따라 걷는 애니메이션 재생(Arcade 물리 미사용, 순수 좌표 보간).
- 착시 트릭 노드: 두 노드를 '실제 거리는 멀지만 화면 투영이 겹치면 연결'로 명시 플래그 처리해 에셔식 impossible-figure 연결을 데이터로 표현.
- 스텝업/계단 규칙: 인접 노드 간 등각 높이차 1칸까지만 보행 허용해 퍼즐 정합성 보장.
**난이도·진행 곡선:** 죽음·점수·타이머 없는 비경쟁 progression. 챕터마다 새 조작 요소(회전 → 슬라이드 → 착시 연결 → 이동 발판 → 시점이 동시에 두 구조에 영향)를 1개씩 도입해 메카닉 어휘를 점진적으로 쌓는 튜토리얼-바이-디자인. 난도는 '동시에 고려해야 할 조작 요소 수'와 '착시 연결의 비직관성'으로만 상승. 각 레벨은 5~10분 한 입 크기.
**게임필·연출:** 고요하고 명상적. 파스텔/모노톤 컬러 블록, 소프트 섀도우, 미니멀 평면. 조작은 묵직하지만 부드러운 관성과 각도 스냅으로 '정확히 제자리에 맞물리는' 촉감. 길이 연결될 때 은은한 차임·라이트 펄스, 캐릭터의 느리고 우아한 걸음. 화면 흔들림·폭발 같은 거친 juice가 아니라 절제된 미세 피드백이 손맛의 핵심.
**끈끈함(리텐션):** 실패가 없어 좌절 대신 '풀릴 때까지 만지작거리는' 안전한 탐색 심리가 작동하고, 아하 순간의 도파민이 다음 방으로 끌어당긴다. 짧고 완결된 챕터 구조가 '하나만 더'를 부르며, 스크린샷으로 자랑하고 싶은 시각적 아름다움이 자발적 공유를 유발한다.
**우리 엔진 재현도:** ⚠️ · 스킬 `puzzle-game` · 엔진 VectorForge, MobileHarness, puzzle-game, vector-graphics, level-designer, juice-fx, game-ui-hud — 물리(Arcade/Matter)는 본질적으로 불필요 — 핵심은 '등각 그래프 연결 + 화면투영 일치 판정'이라 순수 로직으로 구현하므로 오히려 puzzle-game 스킬의 '보드모델/렌더 분리' 철학과 잘 맞는다(이에 따라 engine_features에서 Matter 제거). 단 다음을 단순화/대체해야 한다: (1) 진짜 3D 회전 불가 → VectorForge로 등각 큐브·발판·계단 스프라이트를 코드 생성하고, 깊이는 z=row+col 식 가짜 isometric depth sort로 표현. 회전은 실제 3D가 아니라 사전 정의된 4방향(0/90/180/270) 스프라이트 상태 + Container tween 스냅으로 페이크. (2) 착시 연결은 물리가 아니라 데이터 플래그(노드 쌍의 화면투영 거리 임계 판정)로 명시 처리. (3) 원작의 방대한 손제작 레벨·아트는 콘텐츠 축소 — 6~10개 큐레이션 레벨 + 단순 레벨 에디터(level-designer로 노드/구조물/연결규칙을 JSON 정의)로 대체. (4) 매끄러운 곡선·궤도 회전 같은 정교한 모션은 tween easing으로 근사. (5) 가장 큰 한계: 원작 후반부의 '카메라/시점 의존 착시'(같은 구조물이 보는 각도에 따라 다르게 연결되는 트릭)는 고정 등각 단일 카메라 가짜 isometric에서 일반화하기 매우 어려워, 해당 류 레벨은 임의 시점 회전이 아니라 미리 스크립트된 상태 전환·페이크 카메라 연출로만 흉내 내야 한다. 서버·멀티·실시간 3D 메시 회전은 ❌이며 본 게임엔 불필요. 즉 '비주얼·기본 연결 메카닉의 충실 재현은 가능하나, 진정한 임의각 3D 회전·시점 의존 착시·대량 손제작 콘텐츠는 축소'되므로 ⚠️.
**조합 훅:** endless-runner에 이식: 자동 전진하는 러너 경로를, 달리는 도중 구조물을 탭 회전해 다음 발판을 즉석에서 연결하는 '리듬형 착시 러너'로 변주(FE-TIMING + FE-AHA); arcade-classic에 이식: 시간제한 안에 최소 회전 횟수로 길을 잇는 스코어어택 모드로, 비경쟁 명상 퍼즐을 '한 판 더' 점수 갱신 게임으로 전환(FE-JUST-ONE-MORE); topdown-shooter/탑다운 미로에 이식: 적의 시야·총알 경로를 등각 착시 연결로 차단·우회시키는 '기하 조작 스텔스' 퍼즐(FE-CONSTRAINT); platformer-game에 이식: 점프 액션 플랫포머에 회전 가능한 디오라마 룸을 더해, 중력 방향이 화면 회전에 따라 바뀌는 'rotating-room 플랫포머'(FE-FLOW + FE-AHA).
**IP 안전 메모:** 원작 이름 'Monument Valley', 캐릭터 'Ida(흰 옷의 공주)'·토템·까마귀족, 고유 컬러 팔레트와 특정 레벨 실루엣, 오리지널 앰비언트 음악·로고·서체는 사용 금지. 메카닉(등각 착시 길 연결, 구조물 회전·슬라이드, 무실패 디오라마 퍼즐)은 IP 보호 대상이 아니므로 자유롭게 차용 가능. IP-safe하게 환기하려면: 추상적인 무명 기하 정령/오브 같은 자체 마스코트(VectorForge blob 캐릭터)로 교체, 팔레트는 직접 고른 CC0 톤, 사운드는 ChipAudio 자체 생성 앰비언트, 레벨 형상은 에셔식 '불가능 도형'이라는 퍼블릭 도메인 미술 개념(impossible figure)에서 직접 설계하되 원작 특정 레벨을 모방하지 않는다. 장르를 '등각 착시 길잇기 퍼즐'로 일반 명사화해 표기.
