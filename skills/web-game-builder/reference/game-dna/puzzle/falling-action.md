## Tetris (1984)
**왜 많이 플레이됐나:** 규칙은 5초 만에 이해되지만(블록 떨어진다, 줄 채우면 사라진다) 숙련 천장은 평생 안 닿는 "쉽게 배우고 끝없이 깊은" 완벽한 단순성이다. 한 판이 짧고 점수·레벨 갱신 욕구가 즉각적이라 누구나 "한 판 더"를 누른다. 절차적 피스 순서로 매 판이 미세하게 달라 외워지지 않고, 실패가 항상 "내 쌓기 판단"으로 납득돼 즉시 재도전이 자연스럽다.
**장르 / 시점:** 낙하 블록 퍼즐(falling-block puzzle) — 그리드 기반 단일 플레이어 / 고정 화면 정면 2D 그리드 뷰(표준 10x20 셀), 블록은 위에서 아래로 수직 낙하. 스크롤 없음.
**코어 루프:** 위에서 떨어지는 테트로미노를 좌우 이동·회전으로 빈틈 없이 쌓고, 가로 한 줄이 꽉 차면 그 줄을 소거해 보드 높이를 낮춘다. 쌓임이 천장에 닿기 전까지 이 공간 판단을 초당 여러 번 반복하며, 레벨이 오를수록 낙하가 빨라져 판단 시간이 줄어든다.
**핵심 재미요소:**
- `FE-FLOW` 몰입 흐름 — 낙하·이동·회전·고정·소거가 끊김 없이 이어져 손이 보드 상태를 거의 반사적으로 처리하는 무아지경 리듬. 핵심은 낙하 중 피스를 머릿속에서 회전·평행이동시켜 '저 빈틈에 L자가 끼워질까'를 실시간으로 가늠하는 공간 판단이며, 이를 머리가 아니라 손이 먼저 처리할수록 플로우가 깊어진다. 소프트/하드드롭으로 입력 템포를 스스로 조절해 리듬이 끊기지 않는다.
- `FE-SPATIAL` 공간 추론 — 낙하 중인 피스를 머릿속에서 회전·평행이동시켜 '이 L자가 저 빈틈에 들어갈까', '한 줄을 채우려면 어느 칸을 비워둘까'를 움직이기 전에 미리 시뮬레이션하는 기하 판단이 매 피스의 핵심. Tetris는 이 공간추론 재미의 원형이며 fun-elements.md도 FE-SPATIAL 대표작으로 명시한다.
- `FE-ESCALATION` 점증 압박 — 누적 소거 라인으로 레벨이 오르면 낙하 스텝 딜레이가 단축돼(예 800ms→50ms대) 판단 시간이 줄어든다. 후반엔 거의 즉시 낙하해 공간 추론을 초 단위로 강제, 긴장이 극대화된다. 단 '반응 가능 속도' 상한을 둬 FE-FAIRNESS를 깨지 않게 한다.
- `FE-MASTERY` 숙련 표현 — 4x4 행렬 회전과 칸 매칭을 반사적으로 굴리는 공간 추론, 다음/홀드 피스까지 함께 그리는 선읽기, T-스핀·테트리스(4줄 동시 소거)·하드드롭 타이밍·완벽 클리어 등 고급 기술로 실력 천장이 매우 높다. 자기 최고 점수·최고 레벨·최다 라인 경신이 핵심 동기이며, 같은 규칙 안에서 무한히 더 잘할 여지가 있다.
- `FE-RISK-REWARD` 위험-보상 — 4줄을 한 번에 비우는 테트리스는 점수 가중치가 크지만, 그러려면 한 칸(보통 I 슬롯)을 비워 둔 채 높이 9줄을 쌓아야 해 천장 충돌 위험이 급증한다. '지금 1줄씩 안전하게 vs 테트리스 노리고 버티기'의 매 순간 저울질이 점수 욕심과 생존을 충돌시킨다.
- `FE-TENSION` 긴장·니어미스 — 보드가 천장 근처까지 차올랐다가 절묘한 회전·끼워넣기로 여러 줄을 한 번에 비워 회생하는 아슬아슬한 순간의 쾌감. 죽음이 코앞일수록 회복 성공의 짜릿함이 커지며, 정식 레퍼런스도 Tetris의 핵심 재미요소로 명시한다.
**핵심 메카닉:**
- 보드모델: board[20][10] 2D 배열이 유일한 상태 소스(0=빈칸, 1~7=고정 블록 색 ID). 낙하 중 피스는 별도 {type, rotation, row, col} 객체로 보드와 분리 관리하고, 고정 시점에만 board에 셀 값을 굽는다(bake). 렌더는 상태 변경 직후 renderBoard()로만 갱신 — update 루프에서 그리지 않음.
- 피스 정의: 7종 테트로미노(I,O,T,S,Z,J,L)를 4x4 행렬 또는 좌표 오프셋 배열로 정의, 보드 상단 중앙에서 스폰. 스폰 순서는 7-bag(7종 셔플 후 순차 배출)로 가뭄/연속 편향을 막아 공정성 확보.
- 회전: 피스 행렬을 전치(transpose) 후 각 행 역순(reverse)으로 시계방향 90도 회전. O는 회전 불변, I/S/Z는 2상태, T/J/L은 4상태. 회전 결과가 벽·기존 블록과 충돌하면 wall kick으로 좌우 1~2칸 보정 시도, 모두 실패면 회전 취소.
- 낙하/고정: 레벨별 스텝 딜레이(Phaser time event)마다 현재 피스를 1칸 하강. 바닥·기존 블록 충돌 시 board에 고정 → 라인 검사 → 새 피스 스폰. 소프트드롭(↓ 가속), 하드드롭(Space 즉시 바닥+짧은 락딜레이).
- 라인 클리어: 꽉 찬 행(board[r].every(v=>v!==0))을 board.splice로 제거하고 상단에 빈 행 unshift. 동시 소거 줄 수(1/2/3/4)에 점수 가중(테트리스=4줄 보너스). 누적 라인으로 레벨·낙하속도 갱신.
- 입력: 키보드(←→ 이동, ↑ 회전, ↓ 소프트드롭, Space 하드드롭, C/Shift 홀드). 모바일은 MobileHarness로 좌우 스와이프=이동, 탭=회전, 아래 스와이프=하드드롭. game-ui-hud로 점수·레벨·라인·다음 피스 미리보기·홀드 슬롯 표시.
**난이도·진행 곡선:** 레벨은 누적 소거 라인 수로 상승하고, 레벨↑마다 낙하 스텝 딜레이를 단축한다(예 800ms 시작 → 레벨당 일정 비율 감소 → 50ms대 수렴, 인간 반응 하한을 상한으로 둠). 초반은 여유롭게 모양·회전을 학습하는 구간, 중반부터 속도 압박으로 선읽기 강제, 후반은 거의 즉시 낙하로 반사신경·다음피스 활용을 시험한다. 별도 스테이지 없는 단일 무한 모드 + 점수/레벨/라인이 유일한 진행 지표. 선택 변주: 40라인 스프린트(타임어택)·시드 고정 모드 추가로 FE-MASTERY 측정 가능.
**게임필·연출:** 블록 고정 시 짧은 'bump' 칩사운드 + 미세 락딜레이로 '딱 놓이는' 손맛. 라인 소거 시 해당 행 플래시(흰색 tint) → 축소/페이드 트윈(juice-fx breakBurst) + 'coin'류 상승 SFX. 테트리스(4줄)는 더 화려한 다단 파티클 + 스크린셰이크(magnitude≤0.01, 80ms 내)로 보상 차별화. 하드드롭은 낙하 라인 잔상·바닥 임팩트 파티클로 묵직함. 소거 줄 수가 많을수록 SFX 피치를 높여 청각적 보상 스택. 게임오버는 보드 전체 그레이아웃 + 'die' 사운드 + 즉시 재시작 핫스타트 경로(0.5초 내).
**끈끈함(리텐션):** 한 판이 수십 초~수 분으로 짧고, 실패 원인이 항상 '내 쌓기 판단'이라 자기 책임 귀인이 명확해 즉시 재도전이 자연스럽다(FE-FAIRNESS 결). 점수·레벨·라인 자기 기록이 명확한 단일 목표로 남아 "딱 한 판만 더"가 끝없이 이어진다. 7-bag 절차 순서로 매 판이 미세하게 달라 외움이 안 통하고, 테트리스/T-스핀 같은 고급 기술이 '다음엔 더 잘 둘 수 있다'는 숙련 갈증을 끊임없이 자극한다.
**우리 엔진 재현도:** ✅ · 스킬 [`puzzle-game`](../../../../puzzle-game/SKILL.md) · 엔진 board[row][col] 2D 배열 단일 상태 소스 + renderBoard() 분리 렌더, Phaser 4 time event(레벨별 가변 스텝 딜레이 낙하 타이머), Phaser Rectangle/Image 셀 렌더(또는 PixelForge 단색 블록 스프라이트), keyboard 입력 + MobileHarness 스와이프/탭 매핑, juice-fx(라인 플래시·breakBurst 파티클·스크린셰이크·하드드롭 잔상), ChipAudio SFX(bump/coin/die + 소거 줄수별 피치 스택), game-ui-hud(점수·레벨·라인·next preview·hold 슬롯), localStorage 최고점/최다라인 영속화, Phaser.Math.RND.sow 시드 PRNG(7-bag·시드공유 모드) — puzzle-game 스킬이 Tetris를 1급 레시피로 명시(보드모델/렌더 분리, 테트로미노 7종, 회전=전치+행역순, wall kick 기본, splice 라인클리어). 물리 불필요한 순수 로직 그리드라 Arcade/Matter 없이 완전 재현, 코드생성 신뢰도 높음. 보드모델: board[20][10] 정수 배열(0=빈칸, 1~7=색 ID)이 유일 상태원이고 낙하 피스는 {type,rotation,row,col} 별도 객체로 관리해 충돌검사→고정 시점에만 board에 bake. 렌더는 변경 직후 renderBoard()로 Phaser Rectangle/Image 갱신. 블록은 PixelForge 자체 CC0 팔레트(원작과 다른 색조합), SFX는 ChipAudio 8비트 생성, 폰트는 오픈/자체. 단순화/대체: (1) SRS 정식 회전·정밀 락딜레이·고급 T-스핀 판정은 풀 구현이 까다로우니 기본 wall kick(좌우 1~2칸 보정)+단순 락딜레이로 충분 — 캐주얼 체감 무리 없음, 필요시 점진 강화. (2) 7-bag은 권장이나 단순 랜덤으로도 동작(공정성만 약간 저하). (3) 멀티플레이 대전(가비지 라인 주고받기)은 ❌ — 단일플레이 점수/스프린트 모드로 축소, 경쟁은 로컬 베스트·시드공유 고스트로 대체. 서버·3D·대량 라이브 콘텐츠 전혀 불필요해 단일플레이 웹 기준 축소 없이 ✅.
**조합 훅:** endless-runner에 '낙하 블록 발판' 역발상: 옆스크롤 주자 위로 떨어지는 테트로미노 더미를 줄 맞춰 디딤발판으로 쌓거나 회피하는 공간추론+질주 하이브리드(FE-MASTERY+FE-FLOW).; topdown-shooter에 '라인클리어 슈터': 격자에 쌓이는 적 블록을 같은 색/모양으로 한 줄 채워 한 번에 광역 파괴하는 탄막 정리 변주(FE-COMBO+FE-RISK-REWARD).; arcade-classic에 '점증 속도 + 자기기록' 코어 이식: 어떤 미니게임이든 레벨업마다 가속되는 스텝 타이머 + best-score 갱신 루프로 '한 판 더' 욕구 주입(FE-ESCALATION+FE-JUST-ONE-MORE).; puzzle-game(2048/Threes)와 결합: 낙하 블록에 숫자를 부여해 가로줄을 채우는 대신 같은 수를 세로로 합쳐 상위 블록을 만드는 '머지 낙하' 변주(FE-CONSTRAINT+FE-MASTERY).
**IP 안전 메모:** 'Tetris'는 등록 상표 — 게임 내 타이틀·스토어 명칭으로 사용 금지(메카닉 설명용으로만 언급). 금지: 원작 공식 가이드라인 테트로미노 색 배열, 로고 폰트, '코로부시카' 등 원곡 음악, 공식 스프라이트/효과음, 특정 공식 레벨·연출. IP-safe 환기: 블록은 PixelForge/VectorForge 자체 CC0 팔레트(원작과 다른 색조합), 사운드는 ChipAudio 생성 8비트, 폰트는 오픈/자체. '낙하 블록 줄맞추기 퍼즐' 같은 일반 메카닉 명칭으로 환기하고 고유 타이틀(예 'Stackfall', 'Linedrop')을 새로 부여. 회전·라인클리어·7-bag·레벨 가속은 장르 보편 규칙이라 자유 구현 가능 — 표현물(아트/사운드/명칭)만 100% 자체 제작. 최종 ip-license-guard 스킬로 점검.

## Puyo Puyo (1991)
**왜 많이 플레이됐나:** 테트리스식 '2개 짝 블록 낙하 + 회전 배치'라는 익숙한 조작 위에, '같은 색 4개 인접 소거 → 위가 무너지며 또 소거되는 연쇄(체인)'라는 단 하나의 폭발적 메카닉을 얹어, 직접 짠 체인이 한 수에 우르르 터질 때의 도파민이 코어다. 규칙은 1분이면 배우지만 '체인을 미리 설계해 한 번에 터뜨리는' 숙련 천장이 매우 높고, 짧은 한 판·즉시 재시작·점수 갱신 구조가 캐주얼부터 고수까지 모두를 끌어들였다. 원작의 대전(상대에게 방해뿌요를 떨어뜨림)은 e스포츠급 깊이를 만들었으나, 단일 플레이 점수/내림(endurance) 모드만으로도 중독성이 충분하다.
**장르 / 시점:** 색 매치 낙하 퍼즐 (falling-block color-match puzzle) / 연쇄(체인) 빌더 / 정면 2D 세로 그리드 고정 뷰. 표준 보드는 6열 x 12행(상단에 약간의 여유 행). 2개 짝 뿌요가 보드 상단에서 아래로 수직 낙하, 회전으로 짝의 방향을 바꿔 배치.
**코어 루프:** 상단에서 떨어지는 2개 짝 색 뿌요를 좌우 이동·회전으로 원하는 위치에 떨어뜨려 같은 색 4개 이상을 인접(상하좌우) 연결시킨다. 4개가 모이면 소거되고, 위에 있던 뿌요가 중력으로 무너져 내리며 또 다른 4-연결을 만들면 연쇄(체인)가 자동으로 터져 점수가 폭증한다 — 보드가 천장에 닿기 전까지 '미리 체인을 쌓고 한 번에 터뜨리는' 판단을 반복한다.
**핵심 재미요소:**
- `FE-COMBO` 연쇄·콤보 — 이 게임의 심장. 한 번의 배치가 소거→낙하→재소거로 캐스케이드되며, 직접 의도하고 쌓아둔 2단·3단·...n단 체인이 한 수에 우르르 터질 때 점수가 기하급수로 불어난다. Candy Crush의 우연한 캐스케이드와 달리 '내가 설계한' 연쇄라 통제감 있는 콤보 쾌감이 극대화.
- `FE-MASTERY` 선계획·멀티스텝 숙련 — 고수 플레이의 본질이자 높은 실력 천장. 지금 4개를 바로 안 터뜨리고 '계단식/끼움식' 형태로 색을 미리 쌓아, 마지막 한 뿌요가 1단을 터뜨리면 그 위가 무너져 2단·3단이 연쇄 발화하도록 여러 수 앞을 설계한다. next 뿌요 미리보기를 보며 색 배치를 역산하는 사고가 핵심으로, 반복할수록 더 긴 체인을 짜게 돼 자기 최고 연쇄 단수 경신이 동기가 된다.
- `FE-AHA` 공간 추론·해법 읽기 — 2개 짝 뿌요의 회전 상태(4방향)와 낙하 위치를 머릿속으로 시뮬레이션해 어느 열에 어떤 색이 쌓일지, 무너진 뒤 어떤 인접이 생길지를 공간적으로 예측하고 '이 한 수가 연쇄를 여는가'를 읽어내는 통찰. 테트리스식 회전·끼워넣기 감각 + 색 인접 판단의 결합.
- `FE-RISK-REWARD` 위험-보상 — 체인을 길게 쌓을수록 보상(점수·대전 시 방해뿌요)은 폭발하지만, 그동안 보드가 차올라 천장에 닿을 위험이 커진다. '한 단 더 길게 vs 지금 터뜨려 안전 확보'의 긴장된 욕심 관리가 매 판의 드라마.
- `FE-JUICE` 감각 피드백 — 4-연결이 톡 터지며 사라지고 위가 와르르 무너져 다음 소거가 연쇄로 이어지는 시각·청각 리듬. 연쇄 단계가 올라갈수록 음 높이가 상승하는 SFX 스택과 화면 셰이크·파티클이 '연쇄가 굴러간다'는 손맛을 만든다.
**핵심 메카닉:**
- 보드 모델: board[row][col] 2D 배열(6열x12행+상단 버퍼 1~2행)이 유일 상태원. 0=빈칸, 1~N=색 인덱스. 렌더는 상태 변경 시점에만 renderBoard()로 Phaser Rectangle/Image 갱신(puzzle-game 보드모델/렌더 분리 원칙).
- 낙하 피스: 현재 조각은 '축 뿌요 + 짝 뿌요' 두 셀의 색·좌표·회전상태(0/90/180/270)로 표현. Tetris 레시피처럼 레벨별 스텝 딜레이마다 1칸 하강, 좌우 이동·회전(짝을 축 기준 4방향 스냅, 벽/블록에 막히면 kick으로 보정), 바닥/블록 충돌 시 board에 두 셀 고정.
- 개별 중력: 고정 직후 각 열을 독립적으로 정렬 — 짝 뿌요는 한 덩어리가 아니라 셀 단위라, 한쪽만 공중에 뜨면 그 셀만 아래로 떨어진다(열별 compact). 이 셀 단위 중력이 테트리스와 결정적으로 다른 지점이자 무너짐 연쇄의 원천.
- 소거 판정(flood fill): 매 정착·낙하 후 보드 전체를 BFS/DFS로 스캔, 같은 색 상하좌우 인접 그룹 크기가 4 이상이면 그 그룹을 소거 대상으로 마크. 모든 4+ 그룹을 동시에 비운다.
- 연쇄(체인) 루프: 소거 → 위 셀 중력 낙하 → 다시 소거 판정 → 또 4+가 생기면 재소거, 더 이상 소거가 없을 때까지 반복. 반복 횟수를 chainCount로 누적해 점수에 연쇄 배수 가산(단계가 오를수록 배수 급증).
- 점수: (소거된 뿌요 수 x 10) x (연쇄 보너스 + 색 종류 보너스 + 그룹 크기 보너스). 연쇄 단계별 가중 테이블을 두어 긴 체인이 짧은 체인 여러 번보다 압도적으로 높게.
- 게임오버: 보드 특정 스폰 열(보통 3번째 열 최상단)이 막혀 새 짝을 못 놓으면 종료. 점수·최고기록은 localStorage 저장.
- 입력: 키보드(← → 이동, ↑/Z 회전, ↓ 소프트드롭, Space 하드드롭) + 모바일 스와이프(좌우 이동)·탭(회전)·아래 스와이프(드롭). MobileHarness 스케일·DOM 가드.
- 연출: juice-fx로 소거 파티클·연쇄 단계별 음 높이 상승 SFX 스택(ChipAudio)·체인 단계 텍스트 팝업·셰이크. next 뿌요 미리보기 HUD(game-ui-hud).
**난이도·진행 곡선:** 단일 무한 모드(endurance) 중심. 누적 소거량으로 레벨이 오르고 레벨↑마다 낙하 스텝 딜레이 단축(예: 700ms→점차 100ms대)으로 FE-ESCALATION. 초반은 색 2~3종으로 4-연결·기초 무너짐 학습, 중반에 색 4종으로 체인 설계 압박, 후반은 색 5종 + 빠른 낙하로 선계획과 손속을 동시에 시험. 추가 모드: (a) 정해진 패턴을 푸는 손제작 퍼즐 팩(level-designer로 'N단 체인 완성' 목표 10~20스테이지), (b) 시드 공유 챌린지(같은 뿌요 순서로 점수 경쟁, localStorage 베스트). 색 종류 수·낙하 속도·소거 임계(4)·보드 폭을 난도 파라미터로 노출.
**게임필·연출:** 소거의 손맛이 핵심 — 4-연결이 동시에 팝(scale yoyo + 파티클)하며 사라지고, 위 셀들이 열별로 와르르 떨어지는 낙하 트윈(Quad.out, 셀별 미세 시차), 그 직후 다음 소거가 연쇄로 이어지는 리듬. 연쇄 단계가 올라갈 때마다 음 높이가 한 단씩 상승하는 ChipAudio SFX 스택이 '체인이 살아 굴러간다'는 청각적 카타르시스를 만든다. 긴 체인 발화 시 체인 카운트 텍스트 팝업(Back.out)·점수 카운터 롤업·중간 강도 스크린셰이크(0.008~0.012). 짝 뿌요 고정은 짧은 bump, 게임오버는 보드 그레이아웃 + die 사운드. 회전·이동은 즉각 반응하되 소거/연쇄 연출은 100~150ms로 또박또박해 '내가 짠 연쇄가 펼쳐지는' 것을 눈으로 따라가게 한다.
**끈끈함(리텐션):** 실패 원인이 항상 '내 배치·욕심 관리'로 납득(FE-FAIRNESS)돼 즉시 재도전이 자연스럽고, 점수·최고 연쇄 단수가 명확한 자기 기록으로 남아 'just one more'를 부른다. 무엇보다 '머릿속으로 설계한 체인이 실제로 한 수에 터지는' 성취가 강한 보상이라, 더 긴 체인을 노리는 숙련 욕구(FE-MASTERY)가 장기 리텐션을 만든다. next 미리보기로 매 수가 작은 계획 퍼즐이 되고, 절차적 뿌요 순서로 매 판이 달라 질리지 않는다. 짧은 루프 + 즉시 재시작 + 시드 공유 비교가 반복 접속을 유도.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 board[row][col] 2D 배열 보드모델 + renderBoard() 분리, flood fill(BFS/DFS) 4-연결 소거 판정, 열별 개별 중력(셀 단위 compact), 연쇄 루프(소거→낙하→재판정 반복 + chainCount), Tetris식 낙하/회전/킥 + Space 하드드롭, PixelForge/VectorForge 색 뿌요 스프라이트(절차 생성), ChipAudio 연쇄 단계별 음높이 상승 SFX, juice-fx 소거 파티클·셰이크·체인 텍스트 팝업, game-ui-hud next 미리보기·점수·연쇄 카운터, MobileHarness 스와이프 이동·탭 회전, localStorage 최고점/시드 공유 — 순수 보드 로직이라 물리(Arcade/Matter) 불필요로 puzzle-game 스택과 정합도 최상. 사실 puzzle-game SKILL의 트리거에 '뿌요뿌요'가 이미 명시돼 있고, Match-3 레시피의 '매치 탐색→중력 낙하→연쇄 재탐색' 루프가 거의 그대로 재사용된다. Match-3 대비 3가지만 바꾸면 된다: (1) 입력 방식이 스왑이 아니라 'Tetris식 2개 짝 낙하+회전 배치'(falling-block 레시피 차용), (2) 매치 규칙이 '직선 3+'가 아니라 'flood fill 같은색 인접 4+'(BFS로 변경), (3) 리필이 없고 소거 후 '열별 개별 중력으로 무너짐'만 발생(빈칸 랜덤 채움 없음). 보드모델은 board[12][6] 정수 배열, 색은 PixelForge 단색 팔레트 4~5종. 핵심 난점은 '셀 단위 중력'(짝이 한 덩어리가 아니라 한쪽만 떨어질 수 있음)인데 열별 compact 함수로 단순 해결. 서버·멀티·대량 콘텐츠 불필요로 단일플레이 100% 충실 재현. 단순화/축소: 원작의 대전(상대에게 방해뿌요 전송)은 ❌ — 멀티 서버 필요하므로, 단일 플레이에서는 (a) 점수/내림 모드, (b) 더미 AI 봇 대전(같은 보드 로직 2개를 한 화면에 두고 방해뿌요를 로컬 큐로 주고받는 1인용 vs CPU)로 ⚠️ 근사 가능. 정확한 원작 연쇄 점수표·색 보너스 계수는 비공개이므로 체감상 유사하게 자체 튜닝.
**조합 훅:** topdown-shooter에 이식: 격자에 쌓이는 적/탄을 같은 색 4개 인접으로 묶어 소거하면 위가 무너지며 연쇄 폭발이 광역기로 발동하는 'flood-match 정리 슈터'(FE-COMBO+FE-AHA).; arcade-classic(Breakout)에 이식: 벽돌이 색을 갖고, 공으로 같은 색 4개를 인접시켜 깨면 위 벽돌이 무너져 연쇄로 와르르 부서지는 '체인 브레이크아웃'(FE-COMBO+FE-JUICE).; puzzle-game 내부 조합: Tetris의 줄맞춤 소거 대신 '색 flood 4+ 소거'를 얹은 하이브리드 — 모양 맞추기와 색 맞추기를 동시에 고려하는 이중 소거 압박(FE-AHA+FE-MASTERY).; endless-runner에 이식: 달리며 하단 미니 보드에 색 뿌요가 쌓이고, 좌우 입력으로 4-연결 체인을 터뜨릴 때마다 대시·실드가 발동하는 '연쇄로 가속하는 러너'(FE-COMBO+FE-TIMING).
**IP 안전 메모:** 금지: 'Puyo Puyo' 명칭·로고·서체, 원작 고유 뿌요 캐릭터 디자인(눈 달린 슬라임 형태와 각 색 캐릭터의 표정/얼굴)·고유 색상 코드 값, 캐릭터(아루루/카방클 등)·보이스('연쇄!' 등 원작 음성)·BGM·효과음, 원작 특정 스테이지/대전 연출, 정확한 연쇄 점수표·방해뿌요 환산식. 메카닉(2개 짝 낙하·회전 배치, 같은 색 4+ 인접 flood 소거, 무너짐 연쇄, 연쇄 점수 가중)은 게임 규칙이라 자유롭게 구현 가능. IP-safe 환기: 뿌요를 추상 보석/물방울/도형 등 자체 팔레트로 PixelForge/VectorForge 절차 생성(원작과 다른 색조합, 표정 없는 또는 완전 오리지널 마스코트), 소거·연쇄음은 ChipAudio 자체 8비트, 폰트는 오픈/자체. 장르명은 '색 매치 낙하 퍼즐'·'연쇄 소거 퍼즐'로 일반화하고 고유 타이틀(예: 'Chainfall', 'Bloomdrop', 'Cascade Color')을 새로 부여. 'Puyo Puyo'는 메카닉 설명 맥락에서만 표기. ip-license-guard 스킬로 최종 점검.

## Dr. Mario (1990)
**왜 많이 플레이됐나:** Tetris의 "낙하 블록"이라는 익숙한 손맛 위에, "병 속 바이러스를 모두 없애라"는 명확한 목표를 얹어 무한 점수 게임을 '풀 수 있는 스테이지'로 바꿨다. 2색 알약이라는 단 하나의 피스만 다루므로 5초면 규칙을 이해하지만, "같은 색 4개를 가로/세로로 잇는다 + 소거 후 알약 반쪽이 무너지며 연쇄가 터진다"는 두 규칙의 상호작용 덕에 선계획·콤보 천장이 매우 높다. 한 판이 짧고 실패가 '내 배치 실수'로 납득돼 즉시 재도전을 부르며, 바이러스 수가 늘어나는 레벨 진행이 가시적 성취를 준다.
**장르 / 시점:** 목표형 색매치 낙하 블록 퍼즐 (color-match falling-block / objective-clear puzzle) / 정면 고정 2D 세로 그리드 — 병(bottle)을 정면에서 본 약 8열 × 16행 셀 보드. 알약은 위에서 아래로 수직 낙하, 스크롤 없음.
**코어 루프:** 위에서 떨어지는 2색 알약을 좌우 이동·회전으로 놓아 병 속 바이러스(고정 타깃)와 같은 색을 가로/세로 4개 이상 일렬로 만들어 소거하고, 소거로 떠버린 알약 반쪽이 무너지며 일어나는 연쇄까지 노린다 — 알약이 천장에 막히기 전에 모든 바이러스를 지우면 클리어.
**핵심 재미요소:**
- `FE-SPATIAL` 공간 추론 — 2색 알약을 회전(가로↔세로, 색 순서 뒤집기)·좌우 배치해 목표 색 4연결 라인을 머릿속으로 시뮬레이션. 바이러스 색·위치가 고정돼 있어 '어느 칸에 무슨 색을 붙여야 4개가 차는가'를 매 알약마다 공간적으로 계산하는 게 핵심.
- `FE-PLANNING` 선계획·멀티스텝 — 한 알약으로 바로 4개를 못 채우면 1~2개를 '쌓아두고' 다음 알약으로 마저 채우는 멀티스텝 설계가 필수. 쓸데없는 색을 깔면 병이 막히므로 next 미리보기를 보며 몇 수 앞의 색 배치를 계획.
- `FE-COMBO` 연쇄·콤보 — 소거로 위쪽 알약 반쪽이 지지대를 잃고 한 칸 아래로 떨어지면(split-half gravity) 새 4연결이 자동 성립해 캐스케이드. 한 알약으로 여러 색을 연쇄 소거하는 멀티 클리어가 이 게임의 최고 쾌감이자 점수원.
- `FE-ESCALATION` 점증 압박 — 레벨이 오르면 바이러스 수↑ + 낙하 속도(LOW/MED/HI 스텝 딜레이)↑로 판단 시간이 줄어든다. 병이 차오를수록 운신 폭이 좁아지는 자가 압박도 동시에 작동.
- `FE-JUICE` 감각 피드백 — 4연결 색이 번쩍이며 소거되는 플래시, 알약 반쪽이 또르륵 무너지는 낙하, 연쇄가 연달아 터지는 콤보 사운드 상승, 마지막 바이러스 제거 시의 클리어 팡파르가 손맛의 핵심.
**핵심 메카닉:**
- 보드 모델: board[row][col] 2D 배열(약 8열×16행)이 유일 상태원. 각 셀은 빈칸/바이러스(색)/알약반쪽(색 + 연결정보 left·right·up·down·single) 중 하나. 렌더는 상태 변경 시점에만 renderBoard()로 갱신(puzzle-game 보드모델/렌더 분리 원칙).
- 피스 = 2칸 알약(capsule): 두 셀이 각각 독립 색(3색 중)을 가지며 가로 또는 세로로 인접한 한 쌍. Tetris의 7 테트로미노 대신 '도미노형 듀얼 셀' 단일 피스로 falling-block 레시피를 단순화.
- 낙하·회전: 레벨별 스텝 딜레이마다 1칸 하강, 바닥/기존 셀 충돌 시 board에 고정. 회전은 가로↔세로 전환 + 두 색의 순서 스왑(시계/반시계 90도), 벽·셀 충돌 시 wall-kick으로 좌우 1칸 보정.
- 소거 규칙(핵심 차별점): 고정 직후 가로행·세로열을 스캔해 '같은 색 4개 이상 연속' 런(run)을 찾아 전부 제거. Tetris의 '행이 꽉 참'이 아니라 '동일 색 N연결'이며, 바이러스도 알약반쪽도 동일하게 색매치 대상이 됨.
- split-half gravity(연쇄의 엔진): 소거 후 지지대를 잃은 알약 반쪽을 한 칸씩 아래로 낙하(바이러스는 절대 안 움직임). 낙하 안정화 후 다시 색매치 스캔 → 또 소거 → 또 낙하의 캐스케이드 루프. Match-3의 중력+재매치와 구조 동일하나 리필 없음.
- 목표·승패: 보드 초기화 시 하단부에 바이러스를 색별 랜덤 시드 배치(레벨×난도로 개수 결정). 모든 바이러스 제거 = 클리어(목표형). 새 알약 스폰 지점(상단 중앙)이 막히면 게임오버.
- 입력: 키보드(← → 이동, ↑ 회전, ↓ 소프트드롭) + 모바일 스와이프(좌우 이동/아래 드롭)·탭(회전). MobileHarness 스케일·DOM 가드.
- 점수/연쇄 보너스: 동시 소거 바이러스 수·연쇄 단계에 가중 점수. localStorage로 best-score·도달 레벨 영속화.
**난이도·진행 곡선:** 레벨(스테이지) 기반 진행. 각 레벨은 바이러스 개수(예: 초반 4개 → 후반 80+개 상당)와 낙하 속도(LOW/MED/HI)로 난도 결정. 초반은 적은 바이러스 + 느린 낙하로 색매치 기본기를 가르치고, 레벨↑마다 바이러스 밀도↑·낙하 스텝 딜레이 단축으로 선계획 시간을 압박. 바이러스가 병 상단까지 깊게 깔리는 후반 레벨은 막히기 전에 위쪽부터 정리하는 운영을 요구. 우리 재현은 12~20개 손제작/파라미터 레벨(보드 크기·바이러스 수·색 종류·속도 곡선) + 속도 옵션 3단으로 축소.
**게임필·연출:** 알약 낙하·이동은 또박또박한 그리드 스냅, 고정 시 짧은 'bump'. 4연결 성립 순간 해당 셀이 번쩍이며(플래시) 축소 트윈으로 소거되고 'coin'류 상승 SFX. 핵심 손맛은 split-half gravity — 소거로 떠버린 알약 반쪽이 또르륵 한 칸씩 떨어지고, 그게 새 4연결을 만들어 연쇄가 연달아 터질 때 콤보 사운드 피치가 단계적으로 올라가는 리듬. 바이러스가 소거될 때는 살짝 더 화려한 파티클, 마지막 바이러스 제거 시 클리어 팡파르 + 보드 반짝임. 게임오버는 보드 그레이아웃 + 'die' 사운드. juice-fx로 소거 플래시·연쇄 셰이크(약하게)·점수 롤업을 깔되 낙하 흐름은 끊지 않게.
**끈끈함(리텐션):** 레벨이 '풀 수 있는 목표'라 클리어 시 명확한 성취감을 주고, 실패는 '내가 엉뚱한 색을 깔아 막혔다'는 자기 책임 귀인이라 즉시 재도전을 부른다(FE-FAIRNESS 성격). 한 알약으로 큰 연쇄를 터뜨렸을 때의 도파민과 '다음엔 더 깔끔하게 풀겠다'는 욕구가 결합. 바이러스 시드가 랜덤이라 같은 레벨도 매번 배치가 달라 질리지 않고, 도달 레벨·best-score가 가시적 진행 지표로 남아 'just one more'를 만든다.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 board[row][col] 2D 배열 보드모델 + renderBoard() 분리, falling-block 낙하/고정/스폰 루프(스텝 타이머, time-and-timers), 듀얼 셀 알약 회전(가로↔세로 + 색 스왑) + wall-kick, 색매치 런 스캔(가로/세로 4+ 연속) 소거, split-half gravity 캐스케이드(소거→낙하→재스캔), PixelForge/VectorForge 절차 생성 알약·바이러스 스프라이트, ChipAudio SFX(bump/소거/연쇄 피치 상승/클리어/die), MobileHarness 스케일·스와이프/탭 입력, juice-fx 소거 플래시·연쇄 연출·점수 롤업, game-ui-hud(점수·레벨·바이러스 잔여 수·next 미리보기), level-designer 레벨 파라미터(바이러스 수·색·속도) 테이블, localStorage best-score·도달 레벨 — 물리 불필요한 순수 그리드 로직이라 충실 재현 가능. puzzle-game의 Tetris(falling-block) 레시피를 베이스로 세 가지를 바꾼다: (1) 7 테트로미노를 '2색 듀얼 셀 알약' 단일 피스로 교체(회전=가로↔세로 전환 + 두 셀 색 순서 스왑). (2) '행 꽉 참' 라인클리어를 '같은 색 4+ 연속 런 스캔'으로 교체 — 매 고정 후 가로행·세로열을 훑어 동일 색 연속 길이 4 이상이면 제거(바이러스·알약반쪽 동일 취급). (3) Match-3식 중력+재매치 캐스케이드를 얹되 리필 없이 'split-half gravity'로 구현: 소거 후 지지대 없는 알약 반쪽만 한 칸씩 낙하(바이러스 고정), 안정화 후 재스캔 반복. 보드 셀은 {kind:'virus'|'pill', color, link} 구조로 두어 알약 반쪽의 짝(left/right/up/down) 끊김을 추적해 분리 낙하를 판정. 초기 바이러스 시드는 하단부 랜덤 배치(생성 직후 4연결이 미리 성립하지 않도록 검증). 승패: virusCount===0이면 클리어, 스폰 칸 막힘이면 게임오버. 단순화: 원작의 정확한 점수표·바이러스 배치 알고리즘·속도 프레임값은 비공개이므로 체감 유사하게 자체 튜닝. 서버·멀티(대전 가비지)·대량 라이브 콘텐츠는 ❌ — 단일플레이 레벨 클리어 + 로컬 best-score로 축소.
**조합 훅:** topdown-shooter에 이식: 적 처치 시 색 블록이 격자에 쌓이고, 같은 색 4연결로 줄맞춰 일괄 소거하는 '색매치 정리 슈터'(FE-COMBO + FE-SPATIAL).; arcade-classic(브레이크아웃)에 이식: 벽돌이 색을 갖고, 공으로 같은 색 4개를 한 줄로 정렬·소거해야 깨지는 색매치 벽돌깨기(FE-PLANNING).; puzzle-game 내 Tetris와 결합: 낙하 피스를 테트로미노로 두되 소거 규칙을 '행 꽉 참'이 아닌 '같은 색 4연결'로 바꿔 색-테트리스 하이브리드(FE-SPATIAL + FE-COMBO).; endless-runner에 이식: 달리며 떨어지는 2색 캡슐을 좌우 레인에 정렬해 색 4연결로 장애물을 부수는 리듬형 색매치 러너(FE-TIMING + FE-COMBO).
**IP 안전 메모:** 금지: 'Dr. Mario' 명칭·로고, 닥터 복장의 Mario 캐릭터·바이러스 캐릭터(Fever/Chill/Weird 등 원작 고유 디자인과 이름), 원작 BGM('Fever'·'Chill' 곡)·효과음, 원작 알약/바이러스 픽셀 스프라이트와 폰트, 특정 레벨 바이러스 배치. 메카닉(2색 알약 낙하, 같은 색 4연결 소거, 고정 타깃 전멸 목표, 소거 후 반쪽 낙하 연쇄)은 게임 규칙이라 자유롭게 구현 가능. IP-safe 환기: 알약→추상 2색 캡슐/보석/캔디, 바이러스→자체 마스코트 슬라임/세균 도형을 PixelForge/VectorForge로 절차 생성(원작과 다른 색조합·디자인), 사운드는 ChipAudio 자체 8비트, 폰트는 오픈/자체. 장르를 '목표형 색매치 낙하 퍼즐'로 일반 명사화하고 고유 타이틀(예: 'Capsule Clinic', 'Bug Blaster', 'Pillfall')을 새로 부여. ip-license-guard 스킬로 최종 점검.

## Lumines (2004)
**왜 많이 플레이됐나:** "테트리스를 음악과 결합했다"는 한 줄 콘셉트가 즉시 이해되면서도, 좌→우로 지나가는 타임라인(스윕)이라는 단 하나의 신선한 소거 메커니즘이 기존 낙하 퍼즐을 전혀 다른 리듬 게임으로 바꿔놨기 때문. 블록을 즉시 지우지 않고 '스윕이 닿을 때까지 모아둔다'는 지연 소거가 한 번의 스윕으로 보드 절반을 쓸어담는 카타르시스를 만들고, 비주얼·BGM·스윕 속도가 한 덩어리로 묶인 시청각적 몰입(스킨이 바뀔 때마다 음악·색·비트가 통째로 갈리는 연출)이 "그냥 퍼즐"을 넘어선 분위기 상품으로 각인됐다. 한 판이 짧고 점수 갱신이 즉각적이라 한 판 더 욕구도 강하다.
**장르 / 시점:** 낙하 블록 + 리듬 소거 퍼즐 (falling-block rhythm puzzle). 2x2 블록을 쌓아 같은 색 2x2 사각형을 만들고, 주기적으로 지나가는 타임라인이 닿을 때 소거하는 하이브리드. / 고정 화면 정면 2D 그리드 뷰. 가로로 넓은 보드(원작 16열×10행 = COLS=16, ROWS=10, 가로가 세로보다 넓음 — 타임라인이 가로로 쓸고 지나가야 하므로 가로폭 확보가 중요)를 위에서 내려다보는 정적 카메라. 블록은 위→아래 수직 낙하, 타임라인은 좌→우 수평 이동.
**코어 루프:** 위에서 떨어지는 2x2(상하 좌우 4칸이 두 색으로 칠해진) 블록을 좌우 이동·회전으로 쌓아 같은 색 4칸이 정사각형(2x2)을 이루도록 배치하고, 좌→우로 주기적으로 지나가는 타임라인(스윕)이 그 사각형에 닿는 순간 소거 → 위 블록이 중력으로 내려앉는다. 이 '쌓기-정렬-스윕 대기' 판단을 스윕 주기에 맞춰 반복한다.
**핵심 재미요소:**
- `FE-TIMING` 타이밍·리듬 — 소거가 입력 즉시가 아니라 좌→우 타임라인이 닿는 순간에만 일어난다. 스윕 주기(=BGM 비트)에 맞춰 '지우기 전에 한 덩어리 더 붙일까'를 저울질하는 박자 감각이 코어. 스윕이 곧 지나갈 자리에 막판 한 블록을 끼워 사각형을 키우는 순간 타이밍 입력이 곧 점수가 된다.
- `FE-PLANNING` 공간·시퀀스 계획 — 2x2 사각형을 산발적으로 만들지 말고 같은 색 군집이 가로로 인접해 이어지도록 '어디에 모을지'를 미리 설계해야 스윕 한 번에 거대 영역을 동시 소거할 수 있다. 다음 피스 미리보기와 현재 스윕 위치를 보고 '이번 스윕 전에 이 열을, 다음 스윕엔 저 열을' 식으로 배치 순서를 계획하는 공간 플래닝이 점수를 가른다.
- `FE-FLOW` 몰입 흐름 — 낙하-이동-회전-착지가 끊김 없이 이어지는 테트리스류 리듬 위에, 스윕이 일정 박자로 화면을 쓸어주며 시청각 메트로놈 역할을 해 손과 음악이 한 몸이 되는 무아지경 흐름을 만든다.
- `FE-RISK-REWARD` 위험-보상 — 스윕이 지나가기 전에 인접 사각형을 계속 이어붙이면 한 번의 스윕으로 거대한 영역을 동시 소거해 점수가 폭증한다(욕심). 하지만 모으는 동안 보드가 높이 차올라 천장 도달·정렬 붕괴 위험이 커지는 푸시-유어-럭 구조.
- `FE-COMBO` 연쇄·콤보 — 한 번의 스윕이 인접해 연결된 같은 색 사각형 군집을 한꺼번에 쓸고, 소거 후 낙하로 새 사각형이 생기면 다음 스윕에서 또 터지는 연쇄. 단일 스윕 동시 소거 칸 수에 점수 가중을 줘 '큰 덩어리 한 방'을 노리게 한다.
- `FE-ESCALATION` 점증 압박 — 진행할수록 블록 낙하 속도가 빨라지고(레벨/스킨 전환), 정렬할 시간이 줄어 보드가 차오른다. 후반엔 스윕 주기보다 블록이 빨리 쌓여 천장에 닿는 긴장으로 무너진다.
- `FE-JUST-ONE-MORE` 한 판 더 — 한 판이 짧고 점수가 단일 지표로 즉시 갱신되며 즉시 재시작 가능해, 'best score 한 번만 더'가 끝없이 이어진다.
**핵심 메카닉:**
- 보드모델: board[row][col] 2D 배열(예 ROWS=10, COLS=16, 가로가 넓음)이 유일 상태원. 각 셀 값은 0(빈칸) 또는 색 ID(예 1,2 — 두 색). 렌더는 상태 변경 시점에만 renderBoard()로 Phaser Rectangle/Image 갱신(update 루프에서 직접 그리지 않음).
- 낙하 피스: 2x2 블록 = 4칸이 두 색으로 칠해진 작은 행렬 piece=[[c00,c01],[c10,c11]]. 보드 상단 중앙에서 스폰, 레벨별 스텝 딜레이마다 1칸 하강. 좌우 이동·회전(2x2 행렬 시계방향 회전=네 칸 값 순환)·소프트드롭/하드드롭 지원.
- 착지·고정: 바닥/기존 블록 충돌 시 4칸을 board에 기록. 단 2x2가 통째로 쌓이지 않고 '한 칸씩 독립적으로 떨어진다'(원작 핵심) — 착지 후 각 열에서 떠 있는 칸이 있으면 중력 적용해 빈칸 위 블록을 아래로 내려 settle.
- 사각형 매칭 판정: 매 변경 후 보드 전체를 스캔해 board[r][c]==board[r][c+1]==board[r+1][c]==board[r+1][c+1] (네 칸 같은 색≠0)인 2x2 좌상단 셀을 markedSquares 집합에 표시. 즉시 소거하지 않고 '소거 예약' 상태로만 둔다(이 지연이 Lumines의 정체성).
- 타임라인(스윕): 좌→우로 일정 주기(sweepInterval ms, BGM 비트와 동기)로 1열씩 이동하는 sweepCol 인덱스. Phaser TimerEvent(loop:true, delay=한 열 이동 시간) 또는 Timeline으로 구동. 사각형은 두 열(c, c+1)에 걸쳐 있으므로 스윕이 사각형을 완전히 통과(좌상단 c와 우측 c+1 모두 경과)할 때 소거 확정 — 원작 동작과 동일. 스윕이 우측으로 진행하는 동안 새로 인접한 markedSquares가 붙으면 같은 스윕 패스에서 함께 소거.
- 소거·중력·점수: 스윕에 걸린 사각형 칸을 0으로 비우고, 그 위 칸을 중력으로 낙하시킨 뒤 매칭 재스캔. 한 번의 스윕 패스에서 소거된 총 칸 수로 점수 가중(연결 군집 클수록 보너스). sweepCol이 우측 끝 도달 시 좌측으로 리셋해 다음 스윕 사이클.
- 게임오버: 스폰 위치(상단 중앙)가 막혀 새 피스를 놓을 수 없으면 종료. 점수·best score는 localStorage 저장.
- 입력: 키보드(←→ 이동, ↑/Space 회전, ↓ 소프트드롭) + 모바일 스와이프(좌우=이동, 위 탭=회전, 아래 스와이프=드롭). MobileHarness 스케일·DOM 가드.
**난이도·진행 곡선:** 단일 무한 모드 + 점수가 유일 진행 지표. 초반은 느린 낙하·느린 스윕으로 사각형 만들기와 스윕 타이밍을 학습. 누적 소거(또는 시간)로 레벨이 오르며 낙하 스텝 딜레이가 단축돼 정렬 압박↑(FE-ESCALATION). '스킨 팩' 개념을 가벼운 단계 전환으로 차용 — 일정 점수/시간마다 팔레트·BGM 멜로디·스윕 속도가 통째로 바뀌어 변주와 분위기 전환을 준다(원작 스킨 셔플의 IP-safe 축소판). 스윕 주기 자체는 비트에 묶어두되 후반 팩에서 BPM을 올려 난도와 분위기를 동시에 점증. 별도 손제작 스테이지 없이 파라미터 곡선(낙하속도/BPM/색 수)으로 난이도 조절.
**게임필·연출:** 손맛의 핵심은 '지연된 일괄 소거'의 카타르시스. 스윕 라인은 화면 높이 전체를 가르는 반투명 세로 빛줄기로 좌→우 등속 이동(juice-fx 글로우 + 잔상). 사각형이 완성되면 즉시 소거 대신 해당 2x2를 살짝 밝게/테두리 글로우로 '예약됨'을 표시(곧 지워질 것이라는 기대감 형성). 스윕이 닿는 순간 그 칸들이 동시에 스케일 팝+파티클로 사라지고, 위 블록이 Quad.out 트윈으로 쏟아져 내린다. ChipAudio로 스윕 통과음(짧은 휙)·소거음(피치가 군집 크기에 비례해 상승)·착지 bump를 비트에 정렬해 재생. 대형 동시 소거 시 스크린 셰이크(≤120ms)+밝은 플래시. BGM은 스텝 시퀀서 비트와 스윕 주기를 같은 클록으로 묶어 '음악이 곧 게임 진행'인 일체감을 만든다(FE-JUICE+FE-TIMING).
**끈끈함(리텐션):** 짧은 루프 + 단일 점수 지표 + '내 정렬·타이밍 실수'라는 명확한 자기 귀인(FE-FAIRNESS적 납득)이 즉시 재도전을 부른다. 지연 소거 구조가 '한 번만 더 붙이면 스윕이 다 쓸어준다'는 욕심(FE-RISK-REWARD)을 매 스윕마다 자극해 멈추기 어렵게 만든다. 스킨/BGM/스윕 속도가 단계마다 바뀌는 시청각 변주가 '다음 팩은 어떤 느낌일까' 호기심을 더해 한 판을 길게 끌고, best score 갱신이 끝없는 목표로 남는다.
**우리 엔진 재현도:** ✅ · 스킬 `puzzle-game` · 엔진 board[row][col] 2D 배열 보드모델 + renderBoard() 분리(상태 변경 시점에만 렌더), Phaser TimerEvent(loop:true) 또는 Timeline으로 좌→우 스윕 컬럼 인덱스 구동, ChipAudio 스텝 시퀀서 BGM의 비트 클록 = 스윕 주기 동기(FE-TIMING), juice-fx 스윕 글로우/잔상·소거 파티클·스크린 셰이크·점수 팝업, PixelForge(픽셀) 또는 VectorForge(스무스) 2색 블록 + 팔레트 교체로 스킨 팩, game-ui-hud 점수·best·다음 피스 미리보기·현재 팩/속도 표시, MobileHarness 스케일·DOM 가드 + 스와이프(이동)·탭(회전)·아래 스와이프(드롭), localStorage best score 영속화 — 순수 그리드 로직이라 물리 엔진(Arcade/Matter) 불필요로 우리 puzzle-game 스택과 정합도 최상. 보드모델: board[row][col] 2D 배열(빈칸 0 / 색 ID), ROWS<COLS로 가로 넓은 보드(원작 16열×10행). puzzle-game Tetris 레시피(낙하·이동·회전·착지·중력)를 베이스로 두 가지를 추가하면 된다: (1) 2x2 같은 색 사각형 스캔(4칸 동일 색 좌상단 셀 markedSquares 집합) — 단, 즉시 소거가 아니라 '예약' 상태로만 표시(Lumines의 정체성), (2) 좌→우 스윕 컬럼 인덱스를 TimerEvent(loop:true, delay=한 열 이동 시간)로 전진시키며 스윕이 사각형을 완전히 통과(두 열 c·c+1 경과)할 때 실제 소거 후 중력+재스캔. 회전은 2x2라 네 칸 값 순환으로 간단(테트리스 4x4 전치보다 쉬움). 착지 시 '한 칸씩 독립 낙하'(2x2 통째 고정 아님)는 열별 settle 함수로 처리. 스윕 주기를 ChipAudio BGM 비트 클록과 같은 ms 단위로 묶어 음악-진행 일체감 구현(time.now 기반). 리듬·스윕·지연소거가 전부 결정론적 순수 JS라 서버·멀티·3D 전혀 불필요. 단순화/대체: 원작의 화려한 스킨 셔플(고유 BGM 트랙·아트)은 IP-safe하게 팔레트+ChipAudio 멜로디+BPM 파라미터 팩 3~5종으로 축소; 원작 정확한 점수표·스윕 속도 곡선은 비공개이므로 체감 유사하게 자체 튜닝; 글로벌 랭킹은 로컬 best score + 시드 공유로 축소.
**조합 훅:** topdown-shooter에 이식: 격자에 쌓이는 적/탄 잔해를 같은 색 2x2로 정렬하면 '예약'되고, 좌→우 정화 빔(스윕)이 주기적으로 지나며 예약된 군집을 일괄 폭파하는 리듬형 보드 정리 슈터(FE-TIMING+FE-COMBO).; arcade-classic에 이식: Breakout 벽돌을 색별로 두고, 같은 색 2x2 블록이 모이면 주기적 스캔 라인이 지나며 동시에 깨뜨려 한 번에 큰 점수를 주는 리듬 벽돌깨기(FE-TIMING+FE-RISK-REWARD).; endless-runner에 이식: 하단 미니 보드에 색 타일이 쌓이고, 비트마다 흐르는 스윕에 맞춰 2x2를 완성하면 그 순간 러너에게 대시/실드가 발동하는 '비트 소거로 가속하는' 리듬 러너(FE-TIMING+FE-FLOW).; puzzle-game 매치3와 결합: 즉시 소거하던 매치3를 '매치는 예약만, 주기적 스윕이 닿을 때 일괄 소거'로 바꿔 타이밍 축을 더한 변주 — 스윕 직전 막판 스왑으로 군집을 키우는 푸시-유어-럭 매치3(FE-COMBO+FE-RISK-REWARD).
**IP 안전 메모:** 금지: 'Lumines' 게임명·로고·서체, Q Entertainment/미즈구치 테츠야의 원작 스킨 고유 비주얼과 BGM 트랙(특히 'Shinin'' 등 라이선스 음악·보이스 샘플), 원작 특유의 스킨별 색 팔레트·블록 텍스처·UI 디자인, 원작 효과음(스윕음·소거 보이스)을 그대로 사용 금지. 특히 BGM은 절대 인용 금지 — Lumines 정체성의 핵심이 음악이라 모방 위험이 가장 큼. IP-safe 환기: 게임명을 'Sweepline', 'Beatfall', 'Pulse Grid' 같은 일반 명칭으로; 메카닉(2x2 같은 색 사각형 매칭 + 좌→우 타임라인 지연 소거 + 비트 동기)은 게임 시스템/규칙이라 자유롭게 구현 가능하므로 표현물만 100% 자체 제작하면 안전. 블록·스윕 비주얼은 PixelForge/VectorForge 자체 CC0 팔레트로, 모든 사운드·BGM은 ChipAudio로 완전 오리지널 8비트 멜로디만 합성(기존 게임 음악 멜로디·화음 진행 인용 금지). '스킨 팩'은 자체 디자인한 팔레트+오리지널 멜로디+BPM 조합으로 환기. 장르는 '리듬 소거 낙하 퍼즐'로 일반 명사화해 표기하고, 최종 ip-license-guard 스킬로 점검.

## Puzzle Bobble (Bust-a-Move) (1994)
**왜 많이 플레이됐나:** "조준해서 쏜다"는 직관적 동작 하나로 즉시 이해되지만, 벽 반사(bank shot)와 매달린 군집을 한 번에 떨어뜨리는 낙하 콤보가 깊은 실력 천장을 만든다. 한 발 한 발이 짧고 명확한 손맛(터짐+낙하)을 주며, 천장이 점점 내려오는 압박이 긴장을 끌어올려 "딱 한 발만 더"를 유발한다. 둘이서 화면을 나눠 방해 버블을 보내는 대전 모드가 캐주얼 파티성까지 더했다(원작 1편에도 2P 대전이 있으나 방해 버블 송신 대전을 본격적인 셀링포인트로 키운 것은 후속작들).
**장르 / 시점:** 조준 슈팅 매치 퍼즐 (aim-shooter match puzzle) — 버블 슈터(bubble shooter) 장르의 원형 / 정면 고정 2D 화면. 하단 중앙 회전 발사기 + 상단 천장에 매달린 버블 군집(offset/육각 그리드). 스크롤 없음, 천장이 일정 발사마다 한 줄씩 하강.
**코어 루프:** 발사기를 좌우로 조준(직선 또는 좌우 벽 반사 경로 예측)해 색 버블을 위쪽 군집에 쏘고, 같은 색 3개 이상이 인접해 모이면 그 묶음이 터지며, 천장과의 연결이 끊긴 군집은 통째로 낙하한다. 다음 버블 색을 보며 천장이 내려오기 전에 군집을 비워 나가는 것이 30초 루프.
**핵심 재미요소:**
- `FE-SPATIAL` 공간 추론(반사 조준) — 직선뿐 아니라 좌우 벽을 튕기는 bank shot 각도를 머릿속으로 시뮬레이션해, 직접 닿을 수 없는 구석/오버행 안쪽 버블에 같은 색을 박아 넣는 것이 이 게임 실력의 핵심. 발사 전 궤적 점선 가이드를 읽고 1~2번 반사 지점을 계산하는 공간 추론이 매 발 발생.
- `FE-COMBO` 연쇄 낙하 콤보 — 3+ 매치로 직접 터지는 버블보다, 그 위에 매달려 있던 다른 색 군집이 천장 연결이 끊겨 통째로 우수수 떨어지는 '낙하(drop)'가 점수의 심장. 한 발로 받침 색을 끊어 대량 낙하를 유도하는 한 수가 최고의 쾌감.
- `FE-ESCALATION` 내려오는 천장 압박 — 일정 발사 수마다 천장(군집 전체)이 한 줄씩 내려와 사선 한계선에 닿으면 게임오버. 시간이 갈수록 작업 공간이 좁아지고 실수 1발의 비용이 커져 긴장이 점증한다.
- `FE-JUICE` 터짐·낙하 손맛 — 같은 색이 맞물려 톡 터지는 팝과 파티클, 연결 끊긴 군집이 중력으로 바운스하며 쏟아지는 낙하 연출이 즉각적 감각 보상. 한 발의 결과가 시각·청각으로 확실히 체화된다.
- `FE-RISK-REWARD` 욕심 낸 대형 낙하 — 안전하게 작은 3매치를 칠지, 받침 색을 노려 한 발로 대량 낙하 콤보를 터뜨릴지의 선택. 큰 낙하를 노리다 빗맞으면 엉뚱한 색을 군집에 추가해 천장만 더 무겁게 만드는 위험이 공존.
**핵심 메카닉:**
- 보드 모델: offset(zig-zag) 육각 그리드를 grid[row][col]에 색 ID(0=빈칸)로 저장. 짝수 행/홀수 행이 반 칸씩 어긋나며, 인접 정의는 짝/홀 행에 따라 6방향 이웃 오프셋 테이블을 다르게 적용. 이 단일 배열이 유일 상태원, 변경 시점에만 renderBoard().
- 발사 궤적: Matter 미사용. 발사 버블을 짧은 스텝 적분(pos += vel*dt)으로 직진시키고 좌/우 벽 충돌 시 vx 반전(반사)만 처리하는 순수 키네마틱. 천장 또는 기존 버블과 충돌하면 가장 가까운 빈 셀에 스냅해 grid에 고정.
- 매치 판정: 착탄 셀에서 같은 색 인접 셀로 flood-fill(BFS/DFS). 모인 묶음이 3개 이상이면 전부 빈칸으로 제거.
- 낙하(부유) 판정: 매치 제거 후, 천장 행(row 0)에 연결된 모든 버블을 다시 flood-fill로 마킹. 마킹되지 않은(천장과 단절된) 버블은 전부 낙하 처리 → 추가 점수. 이것이 colored-blob 매치와 구분되는 핵심 규칙.
- 천장 하강: 발사 카운터가 임계치에 도달하면 grid를 한 행 아래로 shift(또는 행 오프셋 +1)하고 상단에 새 색 행 삽입. 하단 데드라인 행에 버블이 닿으면 게임오버.
- 다음 버블 미리보기 + 발사기 조준: 현재/다음 색 2개 노출. 키보드 ←→로 각도, Space 발사 / 모바일은 드래그로 조준 후 탭 발사. 발사 색은 보드에 남아 있는 색 중에서만 랜덤 선택(원작 동작 그대로 — 이미 소거된 색이 나오지 않아 막힘을 줄임; 장르 보편 규칙이라 자유 구현 가능).
**난이도·진행 곡선:** 레벨/팩 기반(level-designer로 초기 군집 배치 JSON 정의) + 무한 점수 모드 병행. 초반: 적은 색 수(3색)·널널한 천장 시작 높이·반사 없이 풀리는 직선 배치로 매치 기본기 학습. 중반: 색 4~5종, 천장 하강 주기 단축, 구석/오버행 배치로 bank shot 강제. 후반: 색 6종, 시작부터 깊은 군집, 하강 빨라짐, 한 색만 외딴 곳에 박힌 까다로운 배치. 난도 파라미터는 색 종류 수·천장 시작 행·하강 주기(발사 N회마다)·초기 군집 밀도. 별 1~3개(남은 발사 수/낙하 콤보 크기 기준)로 수집 동기 부여.
**게임필·연출:** 조준 단계의 점선 궤적 가이드(반사점 포함)가 공간 추론의 캔버스. 착탄 순간 스냅 후 매치되면 버블 스케일 팝 + spark 파티클 burst(juice-fx burst), 짧은 상승음(ChipAudio coin류). 낙하 군집은 중력 트윈으로 아래로 쏟아지며 가벼운 바운스 + 셰이크(shake 80~120, 0.004~0.008), 대량 낙하일수록 콤보 카운트 팝업과 음 높이 상승 스택. 천장 하강 시 전체 군집이 한 칸 또박 내려오는 묵직한 트윈 + 경고음. 발사기 회전은 즉각 반응, 발사 시 반동 스쿼시. 게임오버는 데드라인 플래시 + die음. 손맛의 핵심은 '한 발 → 터짐 → 끊긴 군집 우수수'의 인과가 선명하게 체화되는 것.
**끈끈함(리텐션):** 한 발이 1~2초로 짧고 결과가 즉각적이라 실패 직후 바로 재시도(FE-JUST-ONE-MORE). 빗맞음이 항상 '내 조준 실수'로 납득돼(FE-FAIRNESS) 자기 책임 귀인이 재도전을 부르고, 반사 각도와 낙하 콤보라는 높은 숙련 천장이 점수 경신 동기를 무한히 공급. 천장 하강의 시간 압박이 긴장 곡선을 만들어 '아슬아슬하게 비워낸' 회생의 쾌감을 남긴다. 레벨 별점·팩 진행이 가시적 수집 목표.
**우리 엔진 재현도:** ⚠️ · 스킬 `puzzle-game` · 엔진 PixelForge(또는 VectorForge) 버블 스프라이트, ChipAudio(발사/터짐/낙하/하강 경고 SFX), MobileHarness(드래그 조준+탭 발사, 스케일·DOM 가드), juice-fx(터짐 파티클·낙하 트윈·셰이크·콤보 팝업), game-ui-hud(점수·남은 발사·현재/다음 색 미리보기), level-designer(초기 군집 배치·난도 파라미터 JSON) — 핵심은 전부 순수 로직이라 Matter 불필요 — 그래서 ❌가 아닌 ⚠️다. 보드 모델: 정사각 grid가 아닌 offset(zig-zag) 육각 grid[row][col]을 색 ID로 두고, 짝/홀 행별 6방향 이웃 오프셋 테이블로 인접을 정의(puzzle-game의 square Match-3 인접 로직을 hex offset으로 확장). 매치=착탄점 flood-fill 3+, 낙하=천장(row0) 연결 flood-fill 후 미연결 군집 제거. 발사는 Matter 강체가 아니라 직진 적분 + 좌우 벽 vx 반전(반사)만 하는 키네마틱 + 충돌 시 최근접 빈 셀 스냅으로 충분(슈팅 요소는 있으나 물리엔진 없이 근사). 단순화/대체: (1) 원작 대량 아케이드 레벨·캐릭터·BGM은 콘텐츠 축소 → level-designer로 15~30개 자작 레벨 + 난도 파라미터 곡선, (2) 2인 분할 대전·방해 버블 송신은 서버/멀티라 ❌ → 단일플레이 점수/레벨 모드 또는 로컬 시드 공유 챌린지로 축소, (3) 글로벌 랭킹은 localStorage best score로 축소, (4) 궤적 점선 가이드·반사점 미리보기는 발사 전 동일 키네마틱을 미리 한 번 시뮬레이션해 점 찍기, (5) 발사 색은 보드 잔존 색 풀에서 선택(원작 동작 그대로, 자체 발명 아님). 주의: hex 인접 오프셋 부호 실수와 천장 연결 flood-fill 누락이 흔한 버그 → 상태 변경 시점에만 renderBoard() 원칙으로 디버그 용이하게.
**조합 훅:** topdown-shooter에 이식: 위에서 밀려 내려오는 색 적 군집을 색 탄으로 조준 발사해 3+ 매치로 소거하고 받침을 끊어 대량 낙하시키는 '매치 슈터'(FE-SPATIAL+FE-COMBO).; arcade-classic(Breakout)에 이식: 패들 대신 하단 발사기로 색 공을 쏘고, 벽 반사로 같은 색 벽돌 군집을 매치 소거해 천장 붕괴를 노리는 반사 조준 벽돌깨기.; endless-runner에 이식: 달리는 레인 위로 흘러오는 색 군집에 좌우 조준 발사로 같은 색을 맞춰 길을 뚫는 리듬형 버블 슈터(FE-TIMING+FE-ESCALATION).; puzzle-game Match-3와 결합: 스왑 대신 '조준 발사로 타일 주입'하는 입력 변주 — 발사 각도와 반사로 원하는 칸에 색을 꽂아 캐스케이드를 설계하는 하이브리드.
**IP 안전 메모:** 금지: 'Puzzle Bobble'·'Bust-a-Move' 명칭/로고/서체, 원작 마스코트(Bub/Bob 공룡)와 그 스프라이트, 원작 버블 디자인·색 배열·UI, 오리지널 BGM/효과음, 원작의 특정 스테이지 레이아웃 카피. 메카닉(조준 발사, 벽 반사, 같은 색 3+ 매치 소거, 천장 연결 끊긴 군집 낙하, 천장 하강, 육각 offset 그리드, 잔존 색 풀 발사)은 장르 보편 규칙이라 자유롭게 구현 가능.
