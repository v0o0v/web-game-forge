Runeburst — 별무리 사가 / 크레딧 · 라이선스
==================================================

■ 게임
- 제목: Runeburst — 별무리 사가
- 장르: 매치3 스왑 캐스케이드 퍼즐 (콤보 배율 도박 + 캔디크러시류 기믹 확장)
- 제작: web-game-builder 스킬 데모 (Phaser 4 기반)

■ 사용 라이브러리
- Phaser 4.1.0 — MIT License (engine/phaser.min.js, engine/phaser.LICENSE.txt 참조)
- VectorForge / ChipAudio / MobileHarness — 본 플러그인 엔진 (절차적 생성, 외부 에셋 0)

■ 에셋
- 모든 그래픽: VectorForge 절차적 벡터 생성 (네온 글로우 룬 6색·컬러 코어·암흑물질·별조각·
  성운 배경, 외부 이미지 0) — CC0
- 모든 사운드: ChipAudio 절차적 합성 (Web Audio, 오디오 파일 0, BGM/SFX·콤보 피치 스택 오리지널) — CC0
- 폰트: 시스템 폰트(Segoe UI / Arial / sans-serif) 폴백만 사용, 폰트 파일 미포함

■ IP 안전
- 매치3 장르 메카닉(인접 스왑·가로/세로 3+ 매치·중력 낙하·리필·캐스케이드·특수 타일
  [4매치=라인 소거 / 5매치=색 전체 소거 / L·T자=포장 폭발]·특수끼리 조합 폭발·제한 이동 수·
  별점·비정형 보드 마스크·젤리/얼음/번식 장애물·재료 내리기·색 수집 목표)은 게임 시스템/
  아이디어로서 자유롭게 차용했습니다. 게임 메카닉은 저작권 보호 대상이 아닙니다.
- 'Bejeweled'(PopCap)·'Candy Crush'(King) 등의 게임명·로고·서체·고유 보석/캔디 스프라이트·
  보이스라인·시그니처 BGM/SFX·특정 레벨 레이아웃은 일절 사용하지 않았습니다.
- 룬 6색(홍/금/녹/청/남/자성 별자리 심볼)·특수 타일('라인 블래스터'/'컬러 코어'/'포장')·
  장애물(성운 젤리/얼음/암흑물질)·별조각·과부하 셀·보드 모양·12개 레벨·데일리 보드는 모두
  오리지널 자작이며, 모든 표현물은 VectorForge/ChipAudio로 절차 생성되었습니다.

■ 재미 요소 조합 (사용자 주도 청사진 + 캔디크러시 기믹 확장)
- FE-COMBO (캐스케이드) + FE-RISK-REWARD (콤보 배율 도박·정산/BUST·과부하 셀) +
  FE-CONSTRAINT/FE-OPTIMIZE (제한 이동 수·목표 4종·별점) + FE-PLANNING (특수 타일 설계·조합) +
  FE-JUST-ONE-MORE (데일리 시드·결과 공유·localStorage 베스트)
- 캔디크러시류 기믹: 비정형 보드(십자·다이아·모래시계·하트·별·링) · 목표 4종(점수/성운 젤리/
  색 수집/별조각 내리기) · 장애물 3종(성운 젤리·얼음·번식 암흑물질) · 특수 조합 폭발 · 과부하 셀.
- 아이템/부스터 4종: 룬 파괴 망치 · 별 셔플 · 컬러 코어 소환 · 자유 스왑 (충전 수 제한, 이동 무소모).
- 스테이지별 배경 성운 테마(보드 모양에 맞춰 색·별빛 변화) + 교착(가능한 수 없음) 시 자동 셔플.
  아이템 버튼 아이콘은 시스템 이모지(외부 에셋 0), 배경 성운은 VectorForge 절차 그라데이션.
