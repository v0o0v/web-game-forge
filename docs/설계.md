# web-game-builder 설계 명세

> 클로드 코드 플러그인 — 자연어 게임 제작 요청을 감지해 브라우저/모바일 웹뷰용 완성도 높은
> 2D 웹 게임을 Phaser 4(4.1.0) 기반으로 자동 생성한다.

## 1. 목표와 범위

- **문제:** 클로드 코드에 "웹 게임 만들어줘"라고 하면 바닐라 JS 수준의 투박한 결과가 나온다.
- **해결:** 게임 제작 의도를 자동 감지 → 검증된 엔진 스택과 템플릿으로 스프라이트 애니메이션·
  HUD·모바일 터치·오디오까지 갖춘 결과를 산출.
- **범위(현재):** **2D 전용.** 플래그십 데모는 슈퍼마리오류 플랫포머(`games/super-runner/`).
- **비범위:** 3D, 멀티플레이어 서버, 네이티브 앱 패키징(향후 과제).

## 2. 기술 선택과 근거

| 결정 | 선택 | 근거 |
|------|------|------|
| 게임 엔진 | **Phaser 4 (v4.1.0, MIT, vendored)** | 후보 7종(Phaser/Kaplay/PixiJS/melonJS/Excalibur/LittleJS/Cocos) 비교. 플랫포머 필수요소(Arcade 물리·타일맵·스프라이트 애니메이션·카메라·HUD)가 전부 1급 API로 내장 + 예제 코퍼스 최다 → LLM 코드생성 신뢰도 최고. |
| 엔진 버전 | **Phaser 4.1.0 (MIT, vendored)** | Phaser 4가 정식 출시되며 **공식 에이전트용 스킬 문서 28종**을 제공. 이를 플러그인에 레퍼런스로 벤더링해 LLM 코드생성의 v4 정확도를 확보. 우리 엔진 코드(PixelForge/VectorForge/ChipAudio/MobileHarness)는 v4에서 변경 없이 동작 확인(addCanvas·Phaser.Class·generateTexture·파티클·입력 API 모두 유지). |
| 물리 | **Arcade (Matter 아님)** | AABB 기반으로 모바일에서 훨씬 경량 + 플랫포머 표준 튜토리얼 스택이라 코드생성 신뢰도 높음. |
| 에셋 | **CC0 우선 + 절차적 생성 폴백** | 데모는 외부 다운로드 0, `PixelForge`로 코드 생성(CC0·IP-safe). CC0 팩은 `assets.json` 게이트로 CC0만 허용. |
| 사운드 | **절차적 합성(ChipAudio + SoundForge)** | `ChipAudio`는 Web Audio로 8비트 SFX/BGM(경량 레인), `SoundForge`는 vendored Tone.js v15 래퍼로 ADSR·필터·FM·적응형 레이어드 BGM(8비트 너머). 둘 다 오디오 파일 0, 오리지널. |
| 자동 실행 | **Hook + Skill 둘 다** | description 의미 기반(1차) + UserPromptSubmit 훅 결정론적 감지(2차) + 슬래시 커맨드(3차). |
| 모바일 | **MobileHarness + JoystickKit** | Scale.FIT+CENTER_BOTH, Tap-to-start 오디오 언락, 멀티터치 디지털 D-패드(`MobileHarness`) + 아날로그/트윈스틱 가상조이스틱(`JoystickKit`, 장르별 선택), 뷰포트/CSS 가드. |
| 결과물 | **웹뷰 최적화 HTML/JS 폴더** | 바로 브라우저·인앱 웹뷰에서 실행. 네이티브 래퍼는 향후. |

## 3. 전체 아키텍처

```
┌─ 트리거 계층 (플러그인) ──────────────────────────────┐
│  1차 SKILL.md description  (의미 기반 자동 트리거)       │
│  2차 hooks.json + detect-game-intent.* (결정론적 넛지)  │
│  3차 commands/make-game.md (명시적 슬래시 폴백)         │
└───────────────────────────────────────────────────────┘
            │ 스킬 발동
            ▼
┌─ 엔진 계층 (engine/) — 라이브러리 12종 + vendored ─────┐
│  phaser.min.js   Phaser 4.1.0 (MIT, vendored)          │
│  pixelforge.js   PixelForge   — 절차적 픽셀아트         │
│  vectorforge.js  VectorForge  — 절차적 스무스/벡터      │
│  audio.js        ChipAudio    — 8비트 사운드(경량)      │
│  soundforge.js   SoundForge   — Tone.js 래퍼(8비트 너머)│
│  tone.js         Tone.js v15 (MIT, vendored)           │
│  mobile.js       MobileHarness— 모바일 하니스+D-패드    │
│  tiled.js        TiledForge   — Tiled(.tmj) 로더/베이커 │
│  abilitykit.js   AbilityKit   — 능력 런타임(쿨다운·자원·콤보·게이트)│
│  ─ 선택 킷(고급·입력) ─────────────────────────────────│
│  matterkit·screenfx·lightingkit·pathkit·joystickkit    │
└───────────────────────────────────────────────────────┘
            │ 사용
            ▼
┌─ 게임 계층 (games/<slug>/) ───────────────────────────┐
│  index.html  뷰포트 meta + CSS 리셋 + 스크립트 로드     │
│  game.js     Boot→Title→Game + UI + TouchControls 씬   │
│  CREDITS.txt 라이선스 고지                              │
└───────────────────────────────────────────────────────┘
            ▲
┌─ 에셋 파이프라인 ─────────────────────────────────────┐
│  assets.json  CC0 라이선스 게이트 (CC0만 허용)          │
│  폴백: PixelForge 절차적 생성                           │
└───────────────────────────────────────────────────────┘
```

## 4. 컴포넌트별 책임

- **`.claude-plugin/plugin.json`** — 플러그인 매니페스트(name 필수, version/description/keywords).
  컴포넌트 경로 필드는 생략(기본 디렉터리 자동 탐색).
- **`.claude-plugin/marketplace.json`** — 마켓플레이스 등록(설치 진입점).
- **`skills/` (29종)** — 메인 + 전문 28. 메인 `web-game-builder`가 오케스트레이션하고, 전문
  스킬이 관련 요청에 자동 발동한다(독립 자동발동 + 메인 조율 구조).
  - **`web-game-builder/SKILL.md`** — 자동 트리거의 핵심. 한/영 고밀도 `description`(1차
    트리거 표면) + 빌드 워크플로 + 전문 스킬 라우팅. `reference/`에 엔진 API·모바일 체크리스트.
  - **장르(5):** `platformer-game` `topdown-shooter` `arcade-classic` `puzzle-game`
    `endless-runner` — 장르별 스캐폴드(지침형, 엔진 활용).
  - **제작요소(13):** `sprite-picker`(실제 에셋 시각 선택·소싱·캐싱) `sprite-forge`(픽셀 절차)
    `vector-graphics`(미려한 스무스/벡터 절차) `sound-architect`(SoundForge 사운드 디렉터·설계)
    `chip-sound`(ChipAudio 8비트) `world-map-architect`(진행 맵 위상) `level-architect`(레벨 설계)
    `story-architect`(서사 설계·STORY.md) `ability-architect`(캐릭터 능력/스킬 시스템 설계·abilities.json·abilitykit)
    `item-architect`(아이템 설계·items.json) `level-designer`
    (레벨/타일맵 빌드) `game-ui-hud` `juice-fx`.
  - **Phaser 고급·입력 킷(5):** `matter-physics`(Matter 강체 물리) `screen-fx`(포스트FX) `lighting-mood`
    (동적 라이팅) `path-motion`(경로·탄막) `virtual-joystick`(아날로그/트윈스틱 조이스틱) — 각 `engine/*kit.js`와 1:1.
  - **품질·운영(5):** `mobile-webview-tune` `game-qa` `ip-license-guard` `perf-60fps`
    `sprite-catalog-refresh`(sprite-picker CC0 카탈로그 웹 재조사·갱신).
  - 각 전문 스킬은 tight한 description으로 관련 요청에만 발동 → 스킬 listing 예산(컨텍스트 ~1%)
    관리. 너무 많아 truncate 시 `/doctor` 확인 + `skillListingBudgetFraction` 상향 또는 일부를
    name-only 로 조정.
- **`hooks/hooks.json`** — UserPromptSubmit 이벤트에 의도 감지 스크립트 등록(matcher 없음, 매
  프롬프트 실행). `${CLAUDE_PLUGIN_ROOT}` 경로 사용.
- **`scripts/detect-game-intent.js`** — Node(크로스플랫폼) 의도 감지기. stdin JSON `.prompt`를
  정규식 매칭 → `additionalContext` 출력. **두 갈래 넛지**: 게임 제작 의도 → `web-game-builder`,
  스프라이트/에셋 선택·적용 의도 → `sprite-picker`(둘 다면 둘 다 주입). `.ps1`/`.sh` 변형 동봉.
- **`skills/sprite-picker/`** — 실제 스프라이트 시각 선택 허브. `catalog/`(웹 조사·라이선스 적대
  검증으로 캐싱한 CC0 소스 `sources.json`·`packs.json`·썸네일), `picker/`(브라우저 갤러리 — 오프라인
  플레이스홀더 썸네일 + 클릭 선택 + localStorage 회수), `reference/`(인터뷰·소싱·프로토콜·라이브러리).
- **`assets-library/`** — 작업공간 로컬, 이전 사용 스프라이트 누적 보관(사용자 자산, `library.json`).
- **`commands/make-game.md`** — `/web-game-builder:make-game` 슬래시 커맨드(명시적 폴백).
- **`engine/`** — 재사용 런타임 12종 + vendored Phaser/Tone.js(아래 5절).
- **`games/`** — 데모 8종(super-runner·nocturne·runeburst·is-rule·style-preview·tiled-topdown·tiled-iso·tiled-pack). 플래그십 `super-runner`는 아래 6절.
- **`assets.json`** — 외부 에셋 라이선스 게이트. `policy.allow`에 CC0/허용 라이선스, CC-BY는
  attribution 표기 시에만. 데모는 entries 비어있음(전부 절차적 생성).

## 5. 엔진 계층 상세

### PixelForge (`engine/pixelforge.js`)
- 문자 그리드 프레임 → Phaser CanvasTexture(가로 스트립)로 굽기. 외부 이미지 0.
- **라가드 행 자동 패딩**: 행 길이를 안 맞춰도 가장 긴 행 기준 오른쪽 투명 패딩 → 픽셀 작업
  실수 최소화.
- `buildAll(scene)`로 내장 16종 + 애니메이션 등록. `bake()`로 게임별 커스텀.
- IP-safe: 주인공 '빨간 모자 러너'는 빨간 모자 색 단서 1개만 남기고 나머지(초록 멜빵·콧수염
  없음)를 바꾼 오리지널.

### VectorForge (`engine/vectorforge.js`)
- PixelForge의 비-픽셀 짝꿍. `drawFn(ctx,w,h,t,VF)`을 슈퍼샘플(기본 3x) 후 고품질 다운샘플 →
  매끄러운 안티앨리어스 텍스처. 헬퍼 `VF`(rr/circle/blob/star/lin/radial/glow/shadow/glass).
- 4가지 스타일 지원: 플랫/머티리얼+소프트섀도우, 그라데이션/글로우, 글래스모피즘, 카툰 벡터 캐릭터.
- **렌더 스타일은 게임당 하나**: 픽셀(`pixelArt:true`) ↔ 스무스(`pixelArt:false, antialias:true`).
- 외부 HD CC0 아트 로딩 경로도 지원(`this.load.svg`로 벡터를 임의 크기 또렷이 래스터화 +
  `assets.json` CC0 게이트). 쇼케이스: `games/style-preview/`.

### ChipAudio (`engine/audio.js`)
- Web Audio 오실레이터 + 포락선으로 SFX 합성, 스텝 시퀀서로 **오리지널** BGM 루프.
- 모바일 오디오 언락: `unlock()`(resume + iOS 무음버퍼), `resume()`(백그라운드 복귀).

### MobileHarness (`engine/mobile.js`)
- `scaleConfig()`(FIT+CENTER), `installDomGuards()`(iOS 줌/스크롤 차단),
  `TouchControlsClass()`(멀티터치 D-패드+점프, 매 프레임 포인터 위치 재계산으로 견고).

### SoundForge (`engine/soundforge.js` + vendored `tone.js`)
- vendored Tone.js v15(MIT) 래퍼. ADSR·필터·슈퍼소우·FM·노이즈 퍼커션·절차 IR 리버브/딜레이·
  **적응형 레이어드 BGM**(인텐시티별 수직 레이어 크로스페이드)·레이어드 SFX를 코드 합성. 오디오 파일 0.
- `ChipAudio`와 **동일 인터페이스**(`unlock/resume/suspend/toggleMute/startBgm/stopBgm/sfx`)라 `mobile.js`가
  무수정 동작. `audio.json`을 데이터로 로드, 디렉터 스킬 `sound-architect`가 무드 인터뷰로 설계.

### TiledForge (`engine/tiled.js`)
- Tiled `.tmj` 로더/베이커. `bakeTileset()`이 `PixelForge`/`VectorForge` 타일을 한 장의 아틀라스로 절차
  베이크(외부 PNG 0), `loadTiledMap()`이 타일 레이어 충돌·오브젝트 스포너·애니타일·iso/hex·`TilemapGPULayer`·
  `assets.json` 라이선스 게이트를 처리. 상세: [tiled-연동-설계.md](tiled-연동-설계.md).

### AbilityKit (`engine/abilitykit.js`)
- 디렉터 스킬 `ability-architect` 가 설계한 `games/<slug>/abilities.json` 을 로드해 **능력의 쿨다운·자원
  (마나/스태미나/기력)·충전(charges)·콤보 윈도·능력 게이트·스킬트리 해금**을 굴리는 데이터 구동 런타임.
  SoundForge 처럼 "스펙 → 실제 동작". 오디오 파일/외부 의존 0.
- **설계 분리:** AbilityKit 은 *기록·타이밍*만(쿨다운 틱·자원 리젠·콤보·해금). 능력의 *효과*(대미지·발사체·
  이동·CC)는 게임이 `onActivate(ability, ctx)` 에서 `ability.effect` 를 읽어 실행 → 효과를 코드에 중복 하드코딩하지 않음.
- 엔진 무관 코어 + 얇은 Phaser 어댑터(`AbilityKit.attach(scene, spec)` → 씬 update 에 `tick(dt)` 자동 훅). `tick` 은
  결정론적(Date.now 미사용)이라 Node 헤드리스(`require`)로 `use/tick/learn` 결정적 검증 가능(game-qa step 하니스 호환).
- 검수: `node skills/ability-architect/tools/lint-abilities.mjs games/<slug>/abilities.json`(죽은스킬·지배전략·
  곱연산폭발·무한콤보·자원지속성·스킬트리도달성·게이트softlock·버튼예산), 복잡한 킷은 `tools/sim-abilities.mjs`(DPS·자원 지속성).
- 단순 게임(능력 1~2개)은 abilitykit 없이 `game.js` 직접 코딩 — 과설계 금지.

### Phaser 고급·입력 킷 5종 (선택적 — `engine/*kit.js`)
게임이 필요할 때만 `index.html`에 phaser 다음·game 이전으로 추가한다(미사용 게임엔 부담 0). 각 킷은 대응 스킬과 1:1.
- **MatterKit (`matterkit.js`)** — 번들 Matter.js 래퍼(config·바디 팩토리·상자 스택·슬링샷). 강체 물리. → `matter-physics`
- **ScreenFX (`screenfx.js`)** — v4 Filter 포스트FX(블룸·비네트·CRT·글로우·컬러그레이딩). WebGL 전용, Canvas no-op. → `screen-fx`
- **LightingKit (`lightingkit.js`)** — PointLight·Simplex 안개·Gradient 밤하늘·앰비언트 어둠. WebGL 전용. → `lighting-mood`
- **PathKit (`pathkit.js`)** — Curves/Path/PathFollower 래퍼(스플라인 패트롤·방사 탄막·크립 경로). → `path-motion`
- **JoystickKit (`joystickkit.js`)** — 가상 조이스틱(싱글/트윈스틱). 멀티터치 포인터 → 360° 방향+세기 벡터(이동/조준
  분리), 플로팅/고정, `inject()` 헤드리스 검증 API. 디지털 D-패드(`MobileHarness`)와 장르별 공존. → `virtual-joystick`

### 5.x Phaser 4 API 레퍼런스 라이브러리 (`skills/web-game-builder/reference/phaser/`)
- Phaser 공식 v4 에이전트용 스킬 문서 **28종**을 `skills/web-game-builder/reference/phaser/`에
  벤더링하고 `INDEX.md`로 라우팅한다.
- 커버 영역: 씬 라이프사이클, Arcade/Matter 물리, ScaleManager, 입력 시스템, 파티클, 카메라,

  이 레퍼런스를 참조해 v4 API를 정확히 사용한다. v3/v4 혼용으로 인한 코드생성 오류 원천 차단.
- 출처: Phaser 공식 skills(MIT 라이선스). 버전 고정: Phaser 4.1.0.

### 5.y 게임 DNA 레퍼런스 라이브러리 (`skills/web-game-builder/reference/game-dna/`)
- 지난 10여 년간 많은 사람이 플레이한 **2D 게임 35종의 재미 요소·메카닉**을 분석한 온디맨드 레퍼런스.
  Phaser 레퍼런스와 같이 frontmatter 없는 순수 문서라 스킬 listing 예산을 먹지 않고, 필요할 때만 Read 한다.
- 구성: `INDEX.md`(색인·명확화 사용법·게임→스킬 라우팅·범위 밖 게임), `fun-elements.md`(재미요소 사전
  21종 + 검증된 조합 레시피 11종 + 안티패턴 6종 + 4단계 조합 설계법), 장르별 분석(`platformers`,
  `runners`, `arcade-casual`, `shooters-roguelite`, `physics-casual` + 퍼즐은 `puzzle/` 심화 서브라이브러리).
- 각 게임 분석 템플릿: 코어 루프 · 재미요소(`FE-*` 태그) · 메카닉 · 난이도 곡선 · 게임필 · 리텐션 이유 ·
  **우리 엔진 재현도(✅/⚠️/❌, 한계·단순화 명시)** · 조합 훅 · IP 안전 메모.
- **용도(핵심):** `web-game-builder/SKILL.md`의 "0) 요청 명확화"와 `commands/make-game.md`에서, 사용자에게
  "어떤 게임을 만들지" 물을 때 이 자료로 (1) 템플릿 아키타입 제시 → (2) 강조할 재미요소 선택(안티패턴 가드) →
  (3) 조합 설계 → (4) 장르 스킬 라우팅으로 잇는다. 여러 게임의 재미를 조합해 새 게임에 녹이는 것이 목표.
- **IP 안전:** 메카닉·재미만 분석한다. 이름·캐릭터·스프라이트·음악 등 저작물은 미사용, 전부 `PixelForge`/
  `VectorForge`/`ChipAudio` 절차 생성으로 환기(각 파일 IP 안전 메모 + `ip-license-guard` 연계).

## 6. 게임 계층 상세 (super-runner)
- 씬: `Boot`(에셋 생성) → `Title`(Tap to start, 오디오 언락) → `Game`(플레이) + `UI`(HUD,
  스크롤 X) + `TouchControls`(최상단).
- 디자인 해상도 384×224(≈16:9), TILE 16, `pixelArt:true`.
- 레벨: 바닥 자동 생성 + 피처 목록(코인/블록/적/돌계단) + 파이프/깃발 별도. 폭 132타일.
- 메카닉: 가변 점프(코요테 110ms·버퍼 120ms), 적 밟기/대미지, 코인, 벽돌(큰 상태 파괴)·
  물음표(코인/버섯), 초록 버섯 파워업, 구덩이 추락, 깃발 골인, 목숨·타임·점수, 패럴랙스 배경.

## 7. 자동 트리거 메커니즘 상세

1. **1차 — SKILL.md description (의미 기반):** 세션 시작 시 description이 시스템 프롬프트에
   주입(progressive disclosure). 모델이 요청 의미와 매칭해 스킬 호출. 한/영 키워드 고밀도로
   recall 극대화(1,536자 캡 내). 다국어/패러프레이즈에 강함, 단 비결정적.
2. **2차 — UserPromptSubmit 훅 (결정론적 안전망):** 매 프롬프트에서 정규식 감지 → 매치 시
   `additionalContext`를 `<system-reminder>`로 주입해 스킬 호출을 **넛지**.
   - **왜 `decision:block`이 아닌가:** block은 프롬프트 자체를 컨텍스트에서 지운다. 우리는
     "스킬을 켜라"고 살짝 밀어줄 뿐, 사용자 입력을 취소하면 안 된다.
   - 1차의 recall 공백(특정 어휘 미스)을 결정론적으로 메움.
3. **3차 — 슬래시 커맨드 (명시적 폴백):** 사용자가 직접 `/web-game-builder:make-game`.
   100% 결정론적이지만 자연어로는 발동 안 됨 → 보조 진입점.

두 자동 경로(의미 미스 vs 어휘 미스)의 실패 모드가 상보적이라 함께 쓴다.

## 10. 검증 전략과 결과
- chrome-devtools MCP로 실제 실행 검증: 타이틀/게임 렌더, HUD, 이동/물리/가변점프/카메라/
  애니메이션 정상. 코인(+100)·적 밟기(+100)·물음표블록→코인팝(+200) 메카닉 결정적 검증 통과.
  콘솔 에러 0.
- 검증 중 TouchControls의 `this.input.pointers`(undefined) 버그 발견 → `this.input.manager
  .pointers`로 수정.
- 헤드리스 캡처 한계: WebGL `preserveDrawingBuffer:false` + 비가시 탭 rAF 정지로 라이브
  프레임 캡처가 불안정. `?autostart=1` + `window.SuperRunner.game.step(t,dt)` 수동 전진으로
  결정적 검증을 수행. 실기기/포그라운드 브라우저에서는 60fps로 정상 구동.
- **Phaser 4.1.0 업그레이드 검증 (2026-06-06):** vendored 엔진을 v3.90 → **v4.1.0** 으로 교체 후
  chrome-devtools MCP 실측. `super-runner`(PixelForge): WebGL+Web Audio 부팅, 전 스프라이트/HUD
  렌더 정상(스프라이트 상하 정위치 — v4 GL Y축 변경이 `addCanvas` 텍스처에 영향 없음), 키 입력→이동
  +201px·`hero-run` 애니·카메라 추적·Arcade 물리·적 AI 동작, 콘솔 에러 0. `style-preview`(VectorForge):
  4개 스무스 스타일 전부 렌더 정상(투명 캔버스+안티앨리어스), 에러 0.
- **유일한 v4 회귀 수정:** v3 `Phaser.Struct.Set` → v4 네이티브 `Set` 전환으로 `Group.children.iterate()`
  가 제거됨. `game.js` 2곳을 `getChildren().forEach()`(+순회 중 destroy 안전용 `slice()`)로 교정.
  그 외 엔진/데모 코드는 무변경(`addCanvas`·`Phaser.Class`·`generateTexture`·파티클·입력 API 모두 v4 유지).
